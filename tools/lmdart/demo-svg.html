Chapter 03 · Dart + browser APIs

Data becomes retained SVG.

Load rectangles, circles, lines, polylines, and text from JSON. A JavaScript palette handler drives a Dart SVG redraw.

Loading the Dart application…

How it works

The HTML is a static template. JSON supplies values or drawing data. Dart owns rendering and browser events; boot.js registers small JavaScript handlers through LMDart.register.

final data = await fetchJson('data/svg.json');
drawSvg(container, data);
final color = bridge.call('svg.palette', context) as JSString;
drawSvg(container, data, palette: color.toDart);
