Tools

Small command-line tools from lmctl. Each tool has a skill page for LLM agents and documentation for the tasks it supports.

  • cpp-dsl-sdk — Experimental. cpp-dsl-sdk is a C++17, standard-library-only header for loading, verifying and executing lmscript bytecode inside a host application.
  • lmcad — lmcad is an experimental native CAD host that models OpenCASCADE solids, renders PNG and APNG images, and exports STL and OBJ meshes.
  • lmhtml — lmhtml is a native host for auditing links and CSS names, comparing HTML documents, extracting templates, and applying shared-page edits.
  • lmscript — lmscript is an experimental scripting language and CLI for file operations, structured data, subprocesses, and agent workflows.

Pages are plain HTML. Source: github.com/lmctl-ai/lmctl/tools.
