lmoffice reference

Complete CLI subcommands, flags, Word/Excel/PowerPoint schema types and methods, standard lmcode_std_v3 catalog functions, and exit codes for lmoffice.

CLI subcommands and flags

Command or flagArgumentsDescription
lmoffice --versionnonePrint the lmoffice version string and exit 0.
lmoffice docx--help | --lmcode-schema [--json] | --lmcode-signatures | --lmcode FILEWord (.docx) host route: inspect embedded schema, print canonical signatures, or execute compiled bytecode.
lmoffice xlsx--help | --lmcode-schema [--json] | --lmcode-signatures | --lmcode FILEExcel (.xlsx) host route: inspect embedded schema, print canonical signatures, or execute compiled bytecode.
lmoffice pptx--help | --lmcode-schema [--json] | --lmcode-signatures | --lmcode FILEPowerPoint (.pptx) host route: inspect embedded schema, print canonical signatures, or execute compiled bytecode.
lmoffice inspectFILE [--markdown]Validate a .docx, .xlsx, or .pptx file with OpenXmlValidator and print a JSON summary (or extracted Markdown with --markdown).

Exit codes

Exit codePhaseMeaning
0successCommand, inspection, or _lmcode_ document generation succeeded.
2cliInvalid command-line flags, unknown subcommand, or malformed invocation manifest.
3load / runBytecode loading failure, schema mismatch, or unhandled VM/runtime error.
4appDocument validation failure, invalid table/cell coordinate, missing input file, or Open XML package write error.
