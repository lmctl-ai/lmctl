lmcode-scala-sample

lmcode-scala-sample is the Scala 3 reference Shop and Ledger host compiling against the vendored lmcode-java SDK and passing the canonical sample suite. It uses Scala 3 SAM lambdas to bind the 45-signature Shop domain, preserves raw byte strings in VmString, dispatches R49 rule entries, and frames results.

Quick reference

git clone https://github.com/lmctl-ai/lmcode-scala-sample.git
cd lmcode-scala-sample
python3 scripts/sync.py check
./test.sh
