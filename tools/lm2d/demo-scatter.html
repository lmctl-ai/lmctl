How it works

ScatterPlot uses exactly the same Series and scales as LineChart. Swap SvgGraphics for CanvasGraphics without changing the data or chart object.

ScatterPlot plot = new ScatterPlot(
    "Throughput samples", series);
plot.render(new CanvasGraphics(canvasElement));
