Get started with lmdraw quickruns

These two downloadable lmscript programs seed a named lmdraw team, ask its Lead to make a small drawing, then leave the Lead's terminal ready for your next request.

Overview

A quickrun is a reusable lmscript file. It writes a uniquely numbered teamfile in your current directory, seeds the requested provider sessions, and then runs the drawing task.

Choose a team

  • lmdraw_solo.lms seeds one Lead using Claude Sonnet 5.5.
  • lmdraw_trio.lms seeds a Lead, a Gemini Coder, and a Codex Reviewer. The quickrun passes the Lead's assignment to the Coder, the Coder's result to the Reviewer, then returns both to the Lead for a report.

Install lmctl and configure the providers in your local profile before running a quickrun. Each run writes a new numbered teamfile in the current directory, seeds the sessions, and opens a terminal unless you pass the global non-interactive option.

Run a quickrun

From a terminal in a directory where you want the teamfile to live, run one of these commands:

lmctl quickrun https://lmctl.com/tools/lmdraw/lmdraw_solo.lms
lmctl quickrun https://lmctl.com/tools/lmdraw/lmdraw_trio.lms

The Lead receives a drawing task and the reference links below. When the terminal opens, talk to the Lead as you would in a normal lmctl team session. Use the generated Prompt command to continue later or Resume to reopen the same Lead.

Test without sending a task

Append --seed-only to seed the team and skip all agent prompts. This is useful for checking provider setup without asking the agents to do drawing work.

lmctl --non-interactive quickrun https://lmctl.com/tools/lmdraw/lmdraw_solo.lms --seed-only
