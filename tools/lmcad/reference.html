lmcad reference

Command-line flags, exit codes, host types, methods, functions, limits and standard-library signatures of lmcad 0.1.5, generated from the release binary (lmcad --lmcode-schema and lmcad --lmcode-signatures) and the repository README. Types in signatures are int, float, string, bool and the host or standard types named here.

Command line

CommandEffect
lmcad --versionPrints lmcad X.Y.Z. The release tag vX.Y.Z and the binary version must agree for install="github:lmctl-ai/lmcad@latest".
lmcad --lmcode-schemaPrints a compact summary: the context line, then free functions, then members grouped by type.
lmcad --lmcode-schema --jsonPrints the embedded schema bytes exactly (dsl.schema 2, name lmcad). This is the compiler input.
lmcad --lmcode-signaturesPrints the canonical signature list of the host registry, host and standard: 271 lines in 0.1.5.
lmcad --lmcode FILE [FILE ...]Runs compiled program files in argument order. Objects and scene state persist between files; locals are fresh for each file. The first failure stops execution.

With no arguments or an unknown flag the host prints its usage line and exits 2. Failures also print a JSON result between the lines LMCODE_RETURN_BEGIN and LMCODE_RETURN_END.

Exit codes

CodeMeaning
0Success; one JSON result line per completed block.
2Invalid command line. The host prints its usage line and a CLI_USAGE result (phase cli).
3Program file load failure or a block or host run failure.
4Another application failure.

Used from lmscript

FormMeaning
p = _lmcode_ cli="lmcad" install="github:lmctl-ai/lmcad@latest"; ... end _lmcode_Declares a block compiled against the schema the lmcad binary reports. install lets lmscript download the released binary when needed.
r = run_lmcode(p)Runs the block on the host and returns a result with ok and result; the repository examples print r.stderr and r.stdout on failure.
lmscript --check FILE.lmsCompiles every block against the host schema without running it.
lmctl autorun URLDownloads and runs an example .lms, fetching the released lmcad.
