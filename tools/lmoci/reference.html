lmoci reference

Reference tables for lmoci CLI flags, environment variables, shared Cloud methods, direct OCI CLI subcommands, standard lmcode_std_v3 REST and CLI interfaces, and exit codes.

CLI flags

Flag or subcommand Description
[cloud] --version, -V Print lmoci version string (for example lmoci 0.2.0).
[cloud] --help, -h Print usage, endpoint resolution order, and simulator environment variables.
[cloud] --notices Print embedded third-party notices for lmcode-go, lmcloud, and OCI Go SDK request signing.
[cloud] --lmcode-schema [--json] Emit raw embedded schema JSON bytes for lmscript compilation.
[cloud] --lmcode-signatures [--without-std] Print sorted canonical DSL signatures with or without the 226 lmcode_std_v3 standard signatures.
[cloud] [--lmcode|--first|--last] FILE ... Execute compiled bytecode files under the validated invocation manifest.
cred | inventory | os | iam | queue | stream | vault Direct CLI subcommands emitting deterministic JSON envelopes ({ok, area, action, profile, endpoint, data, error}).
--sweep <ledger_dir> --older-than-hours N Sweep aged run-owned sandbox resources recorded in persistent JSON ledgers.

Environment variables

Variable Default Purpose
LMCLOUD_ENDPOINT, LMOCI_ENDPOINT, OCI_ENDPOINT unset (in-process fake) Loopback HTTP emulator origin (such as http://127.0.0.1:4599 for ocisim).
OCI_OBJECT_STORAGE_ENDPOINT, OCI_QUEUE_ENDPOINT unset Service-specific loopback endpoint overrides for Object Storage or Queue.
LMOCI_SIM_KEY_ID synthetic open-mode keyId OCI signing keyId (<tenancy>/<user>/<fingerprint>) for ocisim requests.
LMOCI_SIM_PRIVATE_KEY_PATH ephemeral RSA-2048 key Path to RSA private key PEM file for ocisim --auth enforce verification.
LMOCI_SIM_NAMESPACE auto-discovered via GET /n/ Explicit Object Storage namespace override for loopback simulator runs.
LMOCI_SIM_COMPARTMENT_ID tenancy OCID from keyId Compartment OCID used for bucket and queue creation on loopback endpoints.
LMOCI_MAX_MEMORY_MB 4096 Process memory ceiling in whole MiB; invalid values exit 2, breaches exit 3.

Shared Cloud methods and OCI mappings

Slice Methods on cloud (type Cloud) OCI wire mapping
Object storage bucket_create, bucket_delete, bucket_exists, bucket_list, object_put, object_get, object_head, object_delete, object_list, object_list_all OCI Object Storage REST API (/n/{namespace}/b/{bucket} and /n/{namespace}/b/{bucket}/o/{object}).
Queues queue_create, queue_delete, queue_exists, queue_list, queue_send, queue_receive, queue_ack, queue_nack OCI Queue control plane (/20210201/queues) and data plane (/20210201/queues/{id}/messages).
Permissions, functions, userpools, cost, metrics policy_*, function_*, userpool_*, user_*, group_*, cost_*, metrics*, last_error Portable IAM policy linting/evaluation, Functions lifecycle, identity pools, cost cap reservations, and latency quantiles.

Standard lmcode_std_v3 REST and CLI interfaces

Symbol Signature Purpose
RestGet .. RestOptions, RestHandler fn h(x: RestExchange) -> void implements RestGet .. RestHandler HTTP route handler interfaces supporting @"/path/:param" route bindings.
CliCommand, CliOption fn c(x: RestExchange) -> void implements CliCommand | CliOption CLI subcommands (@"cmd") and options (@"--flag").
rest_config, rest_route, rest_serve, rest_stop, rest_cli rest_config(string, string) -> void; rest_route(string, string, string) -> void; rest_serve() -> void; rest_stop() -> void; rest_cli(StrList) -> string Configure routes, run embedded HTTP servers, or dispatch CLI/REST calls in-process.

Exit codes

Code Meaning
0 Execution completed successfully.
2 Invalid CLI flags, malformed invocation manifest, or invalid LMOCI_MAX_MEMORY_MB setting.
3 Runtime cloud error, 401/403 simulator auth rejection, cost cap exceeded, or memory ceiling breach.
4 Bytecode file or schema contract loading failure.
