Starting with lmctl autorun

Declare a provider role in comments and let lmctl autorun prepare a local script before starting the session.

The role comment is machine-readable. The script uses @role(Lead.provider) and @role(Lead.model) placeholders, which autorun resolves from the installed provider mapping before checking and running the script.

lmctl autorun is available in the next lmctl release.

Script: autorun-entry.lms

// autorun-role: Lead provider=claude model=claude-sonnet-5-5
provider = "@role(Lead.provider)";
model = "@role(Lead.model)";
println(f"Autorun role: {provider} / {model}");
println("Add your task here, then run this file with lmctl autorun.");

Run it

lmctl autorun https://lmctl.com/lmscript/examples/autorun-entry.lms

Output

Autorun role: @role(Lead.provider) / @role(Lead.model)
Add your task here, then run this file with lmctl autorun.
