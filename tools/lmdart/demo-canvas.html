Chapter 04 · Dart + browser APIs

Immediate pixels from the same data idea.

Draw JSON commands through CanvasRenderingContext2D. Pointer coordinates pass through a JavaScript validator before Dart redraws the canvas.

Canvas 2D is required.

How it works

The HTML is a static template. JSON supplies values or drawing data. Dart owns rendering and browser events; boot.js registers small JavaScript handlers through LMDart.register.

final data = await fetchJson('data/canvas.json');
drawCanvas(canvas, data);
canvas.onClick.listen((event) {
  final accepted = bridge.call('canvas.point', point);
  if (accepted) drawCanvas(canvas, data, marks: marks);
});
