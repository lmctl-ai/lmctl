lmfinance reference

Complete reference for lmfinance 0.1.4: command-line flags, exit codes, environment, the seven context objects, every host type and method of the embedded schema, and the standard lmcode_std_v3 library the host vendors. Signatures are taken from schema/lmfinance.dsl.json in the repository.

Command line

FlagBehavior
--versionPrint lmfinance X.Y.Z
--noticesPrint the embedded third-party notices
--lmcode-schema --jsonPrint the embedded effective schema as JSON (host declarations merged with the standard library)
--lmcode-schemaPrint the registry signatures as text
--lmcode-signaturesPrint the registry signatures as text: context, method and function lines
--lmcode FILE [FILE ...]Load and verify every compiled program, run them in order, stop at the first failure, write one result frame to standard output
--dry-run --lmcode FILE [FILE ...]Load and verify every program without running any; must come first; contradicting real-mode invocation metadata is a usage error

Exit codes

CodeMeaning
0Success
2Command-line or invocation metadata error (failure phase cli, code CLI_USAGE); usage text on stderr
3Program load error (phase load) or run error (phase run), including failed assertions, QuantLib errors and an exceeded memory budget
4Application failure (phase app, code APP_FAIL) or failure writing output

Environment

Host types and methods

The host schema declares 19 types with 107 method signatures and no free functions. Float parameters must be finite. Objects live until the host exits; at most 4000000 objects of each kind can be created.

Standard library (lmcode_std_v3)

lmfinance 0.1.4 vendors the lmcode_std_v3 schema from lmcode-cpp at the commit pinned in sdk.lock. That vendored catalog has 206 canonical signatures: 83 function signatures and 123 method signatures on 16 standard types. They are available in every lmfinance block without declaration, next to the host types above. The file functions are unrestricted byte operations relative to the working directory.

Standard REST and CLI interfaces (current catalog, not yet in this host)

The current lmcode_std_v3 catalog in lmcode-cpp has 226 canonical signatures. The 20 signatures beyond the 206 that lmfinance vendors are the former lmcode_std_rest_v1 module: 5 functions and 15 RestExchange methods, together with 10 standard interfaces. lmfinance does not ship them yet; it picks them up when it syncs its pinned lmcode-cpp SDK and publishes a release. Until then a lmfinance program that calls rest_route or declares a RestGet handler does not compile against the lmfinance schema.
