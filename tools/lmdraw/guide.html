lmdraw API and SVG guide

Overview

lmdraw is a native host for retained 2D scenes. Its schema creates vector and text nodes, loads a restricted SVG subset, updates SVG-style attributes and writes PNG files. The bytecode VM is version 5 and the schema is version 2.

Coordinates use CSS pixels with the origin at the upper left, x increasing right and y increasing down. Text y coordinates are baselines. A scene starts with scene.canvas(width, height, background) or scene.load_svg(path, id).

CLI

lmdraw --schema
lmdraw --schema --json
lmdraw --dsl-signatures
lmdraw --dsl FILE.dslb [FILE.dslb ...]

The short schema output is generated from the host registry. JSON output is the exact embedded schema bytes used by lmscript. Multiple bytecode files are validated before execution, then run in order.

Retained nodes and attributes

Constructors return Node, Group or Gradient handles. Node.set_attr(name, value) updates a node using SVG attribute names. Group.add attaches a node or group. A node or group may have only one parent, and group cycles are rejected.

Paintfill and stroke accept named colors, hex colors, none, or a same-scene linear-gradient reference such as url(#warm).
Opacityopacity, fill-opacity and stroke-opacity accept values from 0 to 1.

Imagehref accepts embedded PNG data URIs only. File and network references are refused.

Text and gradients

Noto Sans Regular and Bold are embedded. Text uses UTF-8 and supports basic measurement; complex-script shaping and bidirectional layout are not implemented. scene.measure_text(text, size, bold) returns a width in pixels. Custom TrueType fonts can be loaded from assets/fonts/.

scene.linear_gradient creates a linear gradient, then Gradient.stop adds color stops. Script-created gradient coordinates are fractions of the painted object's bounds from 0 to 1. Assign a gradient with a local url(#id) fill or stroke.

SVG input subset

SVG input files must be direct children of assets/ and no larger than 2 MiB. Loading a document returns the requested id as a retained handle; another call for the same document can return another id without replacing the scene.

The host refuses CSS classes and stylesheets, script and event handlers, DTDs and entities, SMIL animation, foreignObject, filters, and external URLs or files. Renderer support for uncommon SVG forms can vary; inspect imported output. Embedded data images are not accepted from SVG input.

Frames and animation

Use ordinary lmscript loops to update retained attributes and write numbered PNG files. Convert numeric values to strings before passing them to set_attr. A fixed ffmpeg frame rate, codec and pixel format make the video encoding repeatable within the same toolchain.

for (i in range(0, 24)) {
  let t = float(i) / 23.0;
  marker.set_attr("cx", str(lerp(140.0, 500.0, ease(t))));
  scene.render_png("build/rendered/frame-" + str(i) + ".png", 640, 360, 1);
}

Limits and errors

  • At most 10,000 nodes and 1,024 gradients, with at most 128 stops per gradient.
  • SVG input is at most 2 MiB; custom font input is a TrueType file below assets/fonts/ and at most 8 MiB.
  • Bytecode files are at most 16 MiB. Every file passed to one --dsl call is verified before any script runs.
  • Image dimensions are limited to 4,096 per side and 8,000,000 total pixels. Render scale is from 1 to 4 within that total.
  • PNG output must be a direct child of build/rendered/. Symlink escapes and traversal are rejected; writes are atomic and respect the process umask.
  • Exit 2 indicates invalid arguments, exit 3 a bytecode or host error, and exit 4 another application failure.

The host performs no network access and imposes no VM instruction budget. Bytecode should be trusted. Fix host errors by using valid dimensions, supported SVG features and output paths within the allowed directory.
