lminstall

lminstall is a static Go CLI and GitHub Action to install, verify, upgrade, configure, run, and uninstall coding provider CLIs without shelling out.

Quick reference

lmscript install github:lmctl-ai/lminstall@v0.1.22
lminstall list
lminstall install claude codex kimi
lminstall status --json
lminstall upgrade codex
lminstall uninstall codex
ItemKindPurpose
list [--json]SubcommandList all 15 coding providers and their official distribution channels.
install / upgrade / uninstallSubcommandsManage provider binaries under an owned root prefix with SHA-256/SHA-512 verification.
status [--json]SubcommandInspect installed, broken, incomplete, absent, or unavailable status (exits 0).
configure <provider> ...SubcommandWrite an isolated launch profile for mock or ollama-cloud backends.
run <provider> --profile-dir ABS -- ...SubcommandRun a provider in an ephemeral HOME with an in-memory credential redaction bridge.
env <provider> --profile-dir ABS --runtime-dir ABSSubcommandExport persistent mock-backend environment variables for orchestrators.
 
lminstall configure claude --backend mock --base-url http://127.0.0.1:8080 \
  --model mock-agent --credential-env MOCK_API_KEY --profile-dir /tmp/claude-profile
lminstall run claude --profile-dir /tmp/claude-profile -- -p "Hello" --tools ""
lminstall env claude --profile-dir /tmp/claude-profile --runtime-dir /tmp/claude-runtime --format sh
