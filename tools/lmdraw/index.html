lmdraw

lmdraw is a native host for retained 2D scenes written in lmscript. Build a scene from editable nodes or load a supported SVG, then render deterministic PNGs and numbered frames with real text and vector paths.

The schema uses a small, author-friendly API. Scripts create rectangles, circles, paths, text, groups and gradients; imported SVG elements become the same editable nodes. Loops can update attributes and write one PNG per frame for later encoding with ffmpeg.
