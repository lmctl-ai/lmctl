lmconn reference

Complete reference for lmconn global flags and all 56 cli.schema.v1 operations, environment variables, error codes, and exit codes.

Global CLI flags

FlagArgumentsDescription
--version / -vnonePrint the lmconn version string (0.2.0) and exit 0.
--help / -hnonePrint command usage summary and exit 0.
--cli-schema--jsonPrint the raw cli.schema.v1 JSON document declaring all 56 operations.
--input-json<json>Execute an operation from a JSON object {"op":"...","params":{...}} (used by lmscript schema imports).
--readonlynoneRefuse any operation whose schema access level is write (error code READONLY, exit code 1).

Environment variables and exit codes

Variable or exit codeDefault / valueDescription
LMCONN_DB~/.lmconn/creds.dbOverride the SQLite credential database file location.
LMCONN_STORE_MODEstandard (or broker)Set to broker to enforce nonexportable, origin-bound credential storage and receipt-only HTTP responses.
DEEPSEEK_API_KEY / OPENROUTER_API_KEY / OLLAMA_API_KEYunsetFallback environment variables for API LLM providers when no SQLite credential is stored.
GITHUB_TOKEN / GH_TOKENunsetFallback environment variables for GitHub API authentication.
<SERVICE>_API_KEYunsetFallback bearer token environment variable for lmconn http request --auth <service>.
Exit code 0SuccessOperation completed and printed {"ok":true,"result":...} (or raw schema JSON for --cli-schema --json).
Exit code 1Runtime / connector errorNetwork failure, timeout, missing credential, authentication rejection, or remote protocol error.
Exit code 2Usage / policy errorUnknown command or flag, missing positional argument, or invalid JSON input.
