lmpy examples

lmpy is a native numerical host for LMScript with linear algebra, statistics, optimisation, signal processing, tables, and machine learning. Browse example previews and run each source as an autorun script. These pages are regenerated from the public lmpy repository at a23339e18b.

Start with get started to learn how solo and trio provider runs work.

  • Normal Quantile: Compute and check the 97.5th percentile of a standard normal distribution. Autorun source
  • Least Squares Line: Fit a straight line and check its intercept and slope. Autorun source
  • Matrix Solve: Solve a small linear system and check its known solution. Autorun source

Source and releases: github.com/lmctl-ai/lmpy.
