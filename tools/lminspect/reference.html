lminspect reference

Complete command-line subcommand and flag reference, host schema contexts, hook interfaces, Flow/Request/Response methods, standard lmcode_std_v3 REST and CLI interfaces, and exit codes for lminspect v0.1.0.

Host and CLI commands and flags

Command or flagArgumentsDescription
--versionnonePrint the lminspect version string (lminspect 0.1.0) and exit 0.
--lmcode-schema / --dsl-schema[--json]Write the exact embedded schema/lminspect.dsl.json bytes to stdout and exit 0.
--lmcode-signatures / --dsl-signaturesnonePrint all canonical host and 226 standard lmcode_std_v3 signatures and exit 0.
--lmcode / --dsl<file.dslb> [file...] [--save <out.dslb>]Execute one or more compiled LMScript bytecode files offline, optionally saving the bytecode artifact to --save.
run / proxy[proxy flags]Start the HTTP/HTTPS proxy server with the configured mode, TLS settings, declarative rules, and DSL addon script.
run --listen / --bind / --port--listen <addr> | --bind <ip> | --port <int>Configure proxy bind address and port (default 127.0.0.1:8080).
run --moderegular | reverse:<target_url> | transparentSelect forward proxy mode (regular), reverse proxy mode to an upstream origin, or transparent mode.
run --ssl-bump / --ca-cert / --ca-key[--ssl-bump] [--ca-cert <path>] [--ca-key <path>]Enable dynamic TLS MITM decryption using leaf certificates signed by the specified or ephemeral Root CA.
run --insecure[true|false]Skip TLS certificate verification on upstream server connections (default true).
run --tap / --record / --replay-server[--tap] [--record <file.jsonl>] [--replay-server <file.jsonl>]Stream sanitized flow summaries to stderr, append sanitized flows to a JSONL file, or serve recorded responses from JSONL.
run --script<file.dslb>Load a compiled _lmcode_ bytecode addon implementing RequestHook, ResponseHook, or FlowHook into the proxy pipeline.
run --redirect / --route / --header / --mock<pattern=value> (repeatable)Apply declarative URL redirects, host:port routing overrides, key:val header injections, or status_code:body mock responses.
replay--client <file.jsonl> [--target <host:port>]Replay recorded client requests from a JSONL file, optionally overriding destination host:port, and log sanitized status lines.
certgen[--cert <ca.crt>] [--key <ca.key>]Generate and save a local Root CA certificate and private key for SSL-Bump TLS interception.

Host contexts, hook interfaces, and Flow methods

Type / context / interfaceSignatureDescription
context inspect: Inspectorinspect.new_flow(method: string, url: string) -> FlowConstruct a new synthetic HTTP Flow with the given HTTP method and full URL.
Inspectorinspect.parse_flow(json_str: string) -> FlowReconstitute a Flow object from its serialized JSON representation.
context flow: FlowflowReference the currently active Flow during hook execution.
interface RequestHook@request fn h(flow: Flow) -> void implements RequestHookHook invoked on each incoming HTTP request before forwarding to the upstream server.
interface ResponseHook@response fn h(flow: Flow) -> void implements ResponseHookHook invoked after receiving an upstream response (or synthetic mock) before returning to the client.
interface FlowHookfn h(flow: Flow) -> void implements FlowHookGeneral flow lifecycle hook invoked on a Flow object.
Flowf.id() -> string | f.client_addr() -> string | f.duration_ms() -> intReturn the 16-character hex flow ID, client IP:port address, or elapsed request duration in milliseconds.
Flowf.request() -> Request | f.response() -> Response | f.has_response() -> bool | f.error() -> stringAccess the mutable Request and Response objects, check whether a response exists, or read any flow error string.
Flowf.respond(status_code: int, body: string, content_type: string) -> voidAttach a synthetic HTTP response directly from the proxy and skip upstream forwarding.
Flowf.intercept() -> void | f.is_intercepted() -> bool | f.resume() -> voidPause a flow for inspection, check interception state, or resume a paused flow.
Flowf.kill() -> void | f.is_killed() -> boolImmediately drop the connection and mark the flow as killed, or check killed status.
Flowf.to_json() -> stringSerialize the flow to a credential-sanitized JSON string.
global functionsassert(cond: bool, msg: string) -> void | println(msg: string) -> voidAssert a boolean invariant (aborting with an error if false) or print a credential-sanitized line to stdout.

Exit codes

Exit codeCategoryMeaning
0SuccessProxy exited cleanly, CA generation or flow replay completed, or _lmcode_ bytecode program succeeded.
1Operation errorProxy startup, CA generation, addon initialization, or JSONL replay file open failed.
2Usage errorMissing or invalid CLI command, unknown flag, or unreadable program path under LMCODE_INVOCATION_FILE.
3Host / VM errorBytecode load failure, schema mismatch, or runtime execution failure in standalone --lmcode / --dsl mode.
4Application failureHost or application assertion failure reported through the LMCODE_INVOCATION_FILE manifest v1 result contract.
