lmr examples

lmr is a native statistics host for LMScript, with regression, distributions, time series, tests, and optimization. Browse example results and run each source as an autorun script. These pages are regenerated from the public lmr repository at d015a13bf5.

Start with get started to learn how solo and trio quickruns work.

  • Normal Quantile: Find the standard-normal 97.5% quantile and check the known textbook result. Quickrun source
  • Linear Fit: Fit an exact straight line and check its intercept and slope. Quickrun source
  • Rosenbrock Minimum: Minimize Rosenbrock's function with BFGS and check the known minimum. Quickrun source

Source and releases: github.com/lmctl-ai/lmr.
