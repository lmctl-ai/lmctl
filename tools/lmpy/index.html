lmpy

lmpy is a native numerical host for LMScript: linear algebra, statistics, tables, optimisation, differential equations, signal processing, graphs, statistical models and machine learning in one executable, with no Python, R or Docker at run time. A program is an LMScript _lmcode_ block that lmscript type-checks against the lmpy schema and run_lmcode executes, returning checked JSON values.

Install and run

Install the LMScript compiler once; the block declaration downloads the lmpy release binary for your platform (Linux x64 and arm64, macOS x64 and arm64, Windows x64) into the lmscript tool cache and verifies its SHA-256 digest.

npm i -g @lmctl-ai/lmctl
lmscript --check program.lms
lmscript program.lms

The repository examples need lmscript 0.2.460 or newer. This page describes lmpy 0.1.46, the release that install="github:lmctl-ai/lmpy@latest" resolved to when it was written.

Minimal program

p = _lmcode_ cli="lmpy" install="github:lmctl-ai/lmpy@latest";
let q = dist("norm").ppf(0.975);
out.close("normal 97.5% quantile", q, 1.959963984540054, 0.00000000000001);
let x = mat("1 2 3; 0 1 4; 5 6 0").solve(vec(14.0, 14.0, 17.0));
out.close("known linear-system solution", x, vec(1.0, 2.0, 3.0), 0.000000000001);
out.put("quantile", q);
out.put("solution", x);
end _lmcode_

r = run_lmcode(p);
require(r.ok, json_stringify(r));
println(json_stringify(r.result));
lmscript quick.lms
{"values":{"quantile":1.959963984540054,"solution":[1,2,3]},"checks":{"passed":2,"failed":0,"failures":[]}}
