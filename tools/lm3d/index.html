lm3d

Quick reference for building browser 3D applications with a Three.js-inspired Java scene graph, TeaVM, and WebGL, without a JavaScript 3D library.

Open the interactive WebGL demo or clone lmctl-ai/lm3d. Version 0.1.0 is MIT licensed; TeaVM uses Apache-2.0, and the licenses are compatible.

Build and run

Install Java 21 and Maven. Node 24.15 or newer is required only for browser integration tests. No LMCode runtime or JavaScript package is used by the application.

git clone https://github.com/lmctl-ai/lm3d.git
cd lm3d
mvn clean package

The build compiles Java to target/demo/teavm.js and copies demo.html, demo.css, boot.js, and the favicon. boot.js contains only main(); it is not a rendering library. To generate assets directly into another static site, use an absolute output directory:

mvn -Ddemo.output=/absolute/site/path clean package

Create a scene

Construct the scene and camera, add meshes and lights, then render with a canvas obtained through TeaVM JSO. Java fields are intentionally public and mutable, matching the direct manipulation style familiar to Three.js users.

HTMLCanvasElement canvas =
    (HTMLCanvasElement) document.getElementById("scene");
Scene scene = new Scene();
PerspectiveCamera camera =
    new PerspectiveCamera(48, 16f / 9, 0.1f, 100);
camera.position.set(5, 4, 7);
camera.lookAt(0, 1, 0);

Mesh cube = new Mesh(
    new BoxGeometry(2, 2, 2),
    new MeshPhongMaterial("#61d6c5"));
cube.position.y = 1.25f;
scene.add(cube);
scene.add(new AmbientLight("#ffffff", 0.4f));
DirectionalLight sun = new DirectionalLight("#ffffff", 1);
sun.position.set(4, 7, 5);
scene.add(sun);

WebGLRenderer renderer = new WebGLRenderer(canvas);
renderer.setSize(960, 540);
renderer.render(scene, camera);

Add the imports shown in the repository README. The renderer updates scene world matrices and the camera view on every render. Set renderer dimensions and camera aspect together when resizing.

Hierarchy and transforms

Object3D owns position, rotation, scale, matrix, matrixWorld, visible, name, and a child list. Add children with parent.add(child), not scene.add(parent).add(child): add returns the receiver, so the chained form adds both nodes to the scene. Euler rotation is expressed in radians. Geometry uses a right-handed coordinate system and cameras look at their target.

Group group = new Group();
group.position.set(2, 0, 0);
group.rotation.y = (float) Math.PI / 4;
Mesh mesh = new Mesh(new BoxGeometry(1, 1, 1), material);
mesh.position.set(1, 1, 0);
scene.add(group);
group.add(mesh);

Geometry contract

BufferGeometry accepts float positions, matching float normals, and char triangle indices. Arrays are cloned on input and output. Every three positions form one vertex, every three indices form one triangle, and indices must reference existing vertices. WebGL 1 limits an indexed geometry to 65,536 vertices.

float[] positions = {0, 0, 0, 1, 0, 0, 0, 1, 0};
float[] normals = {0, 0, 1, 0, 0, 1, 0, 0, 1};
char[] indices = {0, 1, 2};
BufferGeometry triangle =
    new BufferGeometry(positions, normals, indices);

BoxGeometry takes width, height, and depth. SphereGeometry takes radius, width segments, and height segments. PlaneGeometry takes width and height in the XY plane. TorusGeometry takes major radius, tube radius, radial segments, and tubular segments.

Animate and orbit

Use TeaVM's Window.requestAnimationFrame. Update object transforms in Java and call render again. Cancel or gate updates when leaving a scene. The demo continues rendering while paused so orbit controls remain responsive, but stops changing object transforms.

OrbitControls controls = new OrbitControls(camera, canvas);
controls.minRadius = 2;
controls.maxRadius = 30;

Window.requestAnimationFrame(timestamp -> {
    cube.rotation.y += 0.01f;
    renderer.render(scene, camera);
});

The one-argument renderer uses a normal non-preserved drawing buffer. Use new WebGLRenderer(canvas, true) when canvas.toDataURL or gl.readPixels must inspect frames after rendering.

Scope and limits

  • lm3d is a focused Three.js-inspired subset, not API-compatible with Three.js and not a port of its source.
  • No Three.js code, external JavaScript library, texture loader, model loader, shadow map, post-processing, quaternion animation, or transparent-object sorting is included.
  • Meshes render double-sided. All visible ambient lights are accumulated; the first visible directional and point lights are used.
  • BufferGeometry is immutable and uploaded once per renderer. Replacing a mesh geometry creates a new cached GPU entry; renderer.dispose releases all cached buffers and the shader program.
  • WebGL 1 and GLSL support are required. Display initialization errors through accessible page status rather than failing silently.

Verify an application

mvn clean verify
npm ci
npx playwright install --with-deps chromium
npm test

The JVM suite tests math, cameras, hierarchy, colors, geometry counts, normals, defensive copies, and invalid inputs. The browser suite checks real WebGL pixels, all three demo geometries, animation, pause/resume, keyboard input, orbit, zoom, reset, mobile overflow, local-only runtime resources, and browser errors. Set DEMO_URL to run the same suite against a deployed page.
