lmproxy reference

Complete command-line subcommands and flags, Proxy, Url, and Message host methods, standard lmcode_std_v3 REST and CLI interfaces, and exit codes for lmproxy v0.1.1.

Host and CLI subcommands

Command or flagArgumentsDescription
--versionnonePrint lmproxy 0.1.1 and exit 0.
--lmcode-schema[--json]Print human-readable signatures summary, or exact embedded host schema JSON bytes when --json is passed.
--lmcode-signaturesnonePrint all canonical context, function, and method signatures (host + 226 standard library signatures).
--lmcode<file.dslb>...Load and execute compiled LMScript bytecode files against the embedded lmproxy schema.
parse-url<URL>...Parse one or more URLs with Squid 7 and print one JSON object per line ({valid,scheme,host,host_is_ip,userinfo,port,path,error}).
parse-request<FILE | ->Parse a raw HTTP/1.x request from FILE or stdin (-) and print JSON ({kind,complete,version,method,target,headers,error}).
parse-response<FILE | ->Parse a raw HTTP/1.x response from FILE or stdin (-) and print JSON ({kind,complete,version,status,reason,headers,error}).
forward[--port P] [--bind ADDR] [proxy-flags]Start the embedded Squid 7 forward proxy daemon (default port 3128, default bind 127.0.0.1).
intercept[--port P] [--bind ADDR] [proxy-flags]Start the embedded Squid 7 transparent interception proxy daemon (default port 3129, default bind 127.0.0.1).
run--config <file.conf> [--debug N]Run the embedded Squid 7 engine directly using a custom Squid configuration file.
certgen[security_file_certgen-args]Internal subcommand invoking the embedded Squid dynamic SSL certificate generator helper.
--port / -p<port>Listening TCP port for forward (default 3128) or intercept (default 3129).
--bind / -b<address>Bind IP address for forward or intercept (default 127.0.0.1).
--ssl-bumpnoneEnable dynamic SSL-bump TLS decryption and on-the-fly host certificate generation.
--ca-cert / --ca-key<path>Custom PEM Root CA certificate and private key for --ssl-bump (auto-generated if omitted).
--tapnonePrint real-time intercepted HTTP/HTTPS request and response summaries to stderr.
--record<file.jsonl>Append structured JSONL traffic records ({timestamp,client,method,url,status,bytes,duration_ms}) to FILE.
--route<PATTERN=HOST:PORT>Transparently route requests matching domain or regex PATTERN to an alternate backend origin HOST:PORT.
--redirect<PATTERN=URL>Intercept requests matching PATTERN and respond with an HTTP 307 Temporary Redirect to URL.
--debug / -d<level>Set Squid debug logging verbosity level.

Exit codes

Exit codeCategoryMeaning
0SuccessCLI parser, proxy daemon execution, or _lmcode_ program completed and all assertions passed.
2Usage errorInvalid command-line flag, malformed --route or --redirect argument, or invocation metadata error.
3Host / load errorUnreadable input file in parse-request/parse-response, bytecode load failure, arena limit exceeded, or unhandled VM error.
4Contract / output failureAn assertion (assert, assert_eq) or result schema contract failed, or stdout write failed.
