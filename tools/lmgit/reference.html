lmgit reference

CLI flags, Git and Repo methods, domain types, standard REST and CLI interfaces, and exit codes for lmgit.

CLI flags and environment

Flag or variableDescription
--versionPrint the exact lmgit build version.
--lmcode-schema [--json]Print the embedded schema/lmgit.dsl.json bytes.
--lmcode-signaturesPrint sorted SDK and domain registry signatures.
--lmcode FILEExecute a compiled DSLB v6 bytecode file (repeatable for builder invocations).
LMGIT_GITEnvironment variable selecting a specific git executable (requires Git >= 2.20).
LMCODE_INVOCATION_FILEOptional version-1 JSON invocation descriptor requiring boolean dry.

Git context and Repo methods (lmgit)

SignatureReturn typeDescription
Git.dry_run(enabled: bool) / Git.is_dry_run()Git / boolSet or query operation-level dry-run mode on the git context.
Git.version()stringReturn the version string reported by the underlying Git executable.
Git.open(path: string)RepoOpen an existing local Git repository at path.
Git.clone(url: string, dest: string)RepoClone a repository from url into dest and return its Repo handle.
Repo.path() / Repo.current_branch() / Repo.is_clean()string / string / boolRepository root path, active branch name, and clean working-tree/index status.
Repo.status()StatusListList modified, staged, or untracked working-tree and index entries.
Repo.branches()BranchListList local branches and identify the current checked-out branch.
Repo.log(limit: int)CommitListReturn up to limit commits from HEAD in reverse chronological order.
Repo.tags() / Repo.remote_names()StringsList repository tag names or configured remote names.
Repo.remote_url(name: string) / Repo.config(key: string)stringRead the URL of remote name or the value of a Git configuration key.

Repo.checkout(ref: string) / Repo.branch_create(name: string)stringCheck out ref or create a new branch (honors git.dry_run).
Repo.commit(message: string) / Repo.push(remote: string, ref: string) / Repo.tag_create(name: string, message: string)stringCreate a commit, push ref to remote, or create an annotated tag (honors git.dry_run).

Exit codes

CodeMeaning
0Execution or introspection succeeded.
2CLI flag usage error or malformed LMCODE_INVOCATION_FILE metadata.
3Bytecode load failure, schema mismatch, or runtime Git subprocess error.
4Application failure, including report.fail_if_any() with non-empty findings or unreadable bytecode files.
