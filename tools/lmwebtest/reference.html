lmwebtest reference

Complete reference for lmwebtest command-line subcommands and flags, environment variables, Web DSL types and methods, Playwright host handle types, and exit codes.

Command-line subcommands and flags

Command or flag Purpose
lmwebtest --version | -v Print lmwebtest X.Y.Z to stdout and exit 0
lmwebtest --lmcode-schema [--json] Print human-readable Web DSL schema summary or exact lmwebtest.dsl.json bytes (--json) and exit 0
lmwebtest --lmcode-signatures Print canonical sorted Web DSL method and function signatures and exit 0
lmwebtest [--dry-run] --lmcode FILE Execute (or validate in dry-run mode) a compiled Web DSL bytecode file
lmwebtest playwright --lmcode-schema [--json] Print human-readable signatures or exact JSON schema (--json) for the full Playwright lmcode host
lmwebtest playwright --lmcode-signatures Print canonical sorted signatures for the full Playwright lmcode host
lmwebtest playwright --lmcode FILE [--lmcode FILE2 ...] Execute one or more compiled Playwright host bytecode files in a synchronous worker-bridged session
lmwebtest test <url> [--status 200] [--title TEXT] [--selector CSS] [--timeout 10000] Load url in Chromium, check status, title, visible selectors, console/page/network errors, and broken images, and output JSON
lmwebtest screenshot <url> --out <file.png> [--no-js] [--timeout 10000] Capture a full-page PNG screenshot of url (optionally with JavaScript disabled via --no-js) and output JSON
lmwebtest init <site-name> [--url <url>] Create a starter Playwright site test configuration under sites/<site-name>
lmwebtest run [site-id|file|dir] [options] Run Playwright test suites for a specific site directory or spec file (checkout mode only)
lmwebtest batch | lmwebtest run --all Run Playwright test suites across all configured directories under sites/ (checkout mode only)

Environment variables

Variable Default Description
LMCODE_HEADED unset (0) Set to 1 to launch Playwright Chromium in headed (visible window) mode during lmwebtest playwright runs
LMCODE_JS vendored Optional filesystem path to an external lmcode-js checkout overriding the vendored runtime
LMCODE_INVOCATION_FILE unset Internal SDK invocation envelope path supplied automatically by run_lmcode

Web DSL context objects (cli="lmwebtest")

Name Type Description
web Web Root browser session controller for navigating to pages and configuring viewport, headers, user agent, and timeouts
report Report Structured finding collector for recording assertion failures and exporting JSON or text reports

Playwright host handle types (cli="lmwebtest playwright")

Handle type Representative methods Description
Playwright (context pw) launch, connect, env, call Root entry point for launching or connecting to browsers and reading environment variables
Browser new_context, new_page, contexts_count, version, is_connected, close Browser process handle supporting isolated contexts and direct pages
BrowserContext new_page, add_cookies, storage_state, route_fulfill, tracing_start, tracing_stop, close Isolated browser profile managing cookies, storage state, network routing, and tracing
Page goto, locator, click, fill, press, set_input_files, click_response, click_download, click_popup, screenshot, evaluate, close Browser tab supporting navigation, input actions, file uploads, event-synchronized clicks, and assertions
Frame goto, locator, click, fill, text_content, evaluate, url, name Iframe or main frame execution target
Locator locator, first, nth, count, click, fill, set_input_files, text_content, get_attribute Auto-waiting Playwright locator for resilient element interactions and retrying assertions
Request / Response url, method, status, text, json Captured network request and response handles
Download / FileChooser / Dialog suggested_filename, save_as, set_files, message, accept, dismiss Handles for browser downloads, file-chooser interceptions, and alert/confirm/prompt dialogs
ApiContext / ApiResponse get, post, put, delete, fetch, status, text, dispose Direct HTTP client sharing or testing endpoints alongside browser contexts
Object (all handles) id() -> int, call(path: string, argsJson: string) -> string, call_id(path: string, argsJson: string) -> int, release() -> void Universal handle reflection reaching any Playwright method or nested object by dotted path

Exit codes

Exit code Mode Meaning
0 All modes All checks, screenshots, or bytecode programs completed without error
1 CLI (test / screenshot / run / batch) Page check failed (status mismatch, console/page/network error, missing selector, broken image) or Playwright test suite failed
2 All modes Invalid command-line arguments, unknown subcommand, or malformed URL/timeout/status option
3 lmcode hosts (--lmcode / playwright --lmcode) Bytecode load error, schema mismatch, Playwright browser/action failure, or report.fail_if_any() triggered
4 lmcode hosts Application error raised with code APP_FAIL
