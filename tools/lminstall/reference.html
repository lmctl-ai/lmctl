lminstall reference

CLI subcommands, flags, supported provider IDs, launch backends, environment variables, and exit codes for lminstall.

CLI subcommands and flags

Subcommand or flagDescription
lminstall list [--json]List all supported coding providers, binaries, and official channel sources.
lminstall install <provider...> [--root DIR] [--json]Install and verify one or more providers under the owned root prefix.
lminstall status [<provider...>] [--root DIR] [--json]Report installation state (absent, incomplete, broken, installed, unavailable) and exit 0.
lminstall upgrade <provider...> [--root DIR] [--json]Upgrade managed providers from their official channel and verify --version.
lminstall uninstall <provider...> [--root DIR] [--json]Remove the owned prefix directory for each specified provider.
lminstall configure <provider> [FLAGS]Create an owned launch profile under --profile-dir ABS without reading secrets.
lminstall run <provider> --profile-dir ABS -- [ARGS...]Run a provider in an ephemeral isolated HOME with an in-memory credential bridge.
lminstall env <provider> --profile-dir ABS --runtime-dir ABSRender a persistent mock-backend runtime directory and print environment exports.
lminstall lmctl --root DIR [--release TAG|latest] [--candidate FILE]Install the aggregate lmctl and lmscript package tree from GitHub releases.
--root DIR / LMINSTALL_ROOTSelect the owned installation root prefix.
--manifest FILEReplace the embedded provider catalog with a trusted custom JSON manifest.
--backend mock|ollama-cloud|ollama-localTarget model backend for lminstall configure (ollama-local is accepted by the parser but returns an explicit unsupported error).
--base-url URL / --model IDUpstream base URL and model identifier for lminstall configure.
--credential-env NAMEEnvironment variable name read at lminstall run time by the loopback bridge.
--format plan|github-env|shOutput format for configure (plan, github-env) and env (plan, github-env, sh).

Exit codes

CodeMeaning
0Command succeeded (or status query completed).
1Operation failure (download, checksum verification, --version check, or runtime launch error; or preserved non-zero child exit in run).
2Invalid CLI arguments or invalid manifest/profile data.
3Requested provider distribution is declared unavailable (for example claudemock).
