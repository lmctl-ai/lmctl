lmpy

lmpy is a native numerical host for LMScript programs. It provides linear algebra, statistics, optimisation, signal processing, tables, time series and machine learning in one executable.

Start with the quickstart, browse the example book, or read the API guide.

Install from LMScript

Declare lmpy with cli and install in an LMScript LMCode block. The compiler downloads the matching release binary when it is not already installed, verifies the release asset digest, and compiles against that binary's embedded schema.

p = _lmcode_ cli="lmpy" install="github:lmctl-ai/lmpy@latest";

What it can do

  • Fit and solve linear systems, least-squares models and sparse problems.
  • Run distributions, optimisation, root finding, quadrature and differential equations.
  • Analyze tables, time series, signals, spatial data, graphs and machine-learning models.

Source and releases: github.com/lmctl-ai/lmpy.
