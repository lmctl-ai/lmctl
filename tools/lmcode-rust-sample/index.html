lmcode-rust-sample

lmcode-rust-sample is the native Rust reference Shop and Ledger host embedding the vendored dslvm crate and passing the 123-case canonical sample suite. It verifies all 206 standard and 45 host signatures with zero unsafe blocks, multi-part builder slots, dry-mode sentinels, and LMCODE_RETURN framing.

Quick reference

git clone https://github.com/lmctl-ai/lmcode-rust-sample.git
cd lmcode-rust-sample
python3 scripts/sync.py check
cargo build --release
./test.sh
