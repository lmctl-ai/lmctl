lmcode-cpp

Overview

Experimental. lmcode-cpp is a C++17, standard-library-only header for loading, verifying and executing lmscript bytecode inside a host application.

Start with the tutorial, use the user guide for API and format details, or give the skill page to an assistant writing host bindings.

Install by copying include/dslvm.hpp into your project or pinning the SDK source commit. There is no compiled library or third-party dependency. Each default Registry provides the 72 standard signatures, so hosts do not register those functions. See the guide for the standard schema and compiler input.

LMCode SDK family

lmcode-cpp is the C++ entry in a five-language SDK family. Each runtime provides the same schema-bound bytecode model and its language's host API.
