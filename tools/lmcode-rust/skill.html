lmcode-rust skill

Embed the dslvm Rust crate into a native binary to expose typed Rust domain objects, lmcode_std_v3, and REST/CLI endpoints to compiled lmcode bytecode.

Purpose

Build dependency-free Rust host executables that verify and run DSLB v6 bytecode, dispatch R49 rule entries and REST/CLI routes, and emit LMCODE_RETURN result envelopes.

When to use it

Use lmcode-rust when authoring or maintaining a Rust CLI or service host that executes schema-bound lmcode chunks with zero external crates.

Install

Add the dslvm crate from lmctl-ai/lmcode-rust as a path or git dependency in Cargo.toml using a stable Rust toolchain.

Commands

cargo build --release
cargo test
cargo run --bin dsl-conformance -- conformance/vectors
cargo run --bin dsl-conformance -- --std conformance/stdlib-vectors
cargo run -p dslvm --bin rest-serve -- app.dslb host.schema.json

Inputs and outputs

  • Input: compiled DSLB v6 bytecode slice, embedded dsl.schema: 2 JSON bytes, and optional LMCODE_INVOCATION_FILE manifest.
  • Output: host mutations on Context arena objects, HTTP/1.1 responses on stdout in rest_serve mode, or a terminal LMCODE_RETURN frame.
  • Strings: ByteString values preserve arbitrary raw bytes including interior NUL and invalid UTF-8.

Safety rules

  • Embed the exact schema JSON bytes with include_bytes! so Program::load verifies the compile-time SHA-256 hash.
  • Use wrapping i64 arithmetic (wrapping_add, wrapping_sub, wrapping_mul, wrapping_neg) in host callbacks to match VM integer semantics.
  • Use function_with_dry or method_with_dry so dry-mode invocations skip mutating callbacks unless an explicit preview closure is supplied.

Worked examples

use dslvm::{Context, InvocationResults, Program, Registry, ResultContract, Value};

let mut reg = Registry::new();
reg.function("double_it", &["int"], "int", |_ctx, args| {
    Ok(Value::Int(args[0].as_int().wrapping_mul(2)))
})?;
let files = vec!["chunk.dslb".to_string()];
let mut results = InvocationResults::from_command(&files)?;
let mut ctx = Context::new();
ctx.set_dry(results.dry());
let prog = Program::load(&bytecode, schema_bytes, &reg)?;
let contract = ResultContract::from_schema(std::str::from_utf8(schema_bytes)?)?;
results.select(0, &reg, &mut ctx, contract)?;
prog.run(&mut ctx, &reg)?;
results.complete(0)?;
let code = results.write_frame(&mut std::io::stdout().lock());
std::process::exit(code);
