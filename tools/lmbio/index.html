lmbio

lmbio is an LMCode host that simulates gene circuits, enzymes, drugs, epidemics and molecular noise as reaction networks: stiff ODEs with CVODE, steady states with KINSOL, Gillespie SSA, and SBML in and out. You build a model with the bio context inside an _lmcode_ block, check the numbers and save CSV for lmplot and lmdraw.

Install and run

npm install -g @lmctl-ai/lmctl
mkdir try-lmbio && cd try-lmbio
lmctl https://raw.githubusercontent.com/lmctl-ai/lmbio/main/examples/toggle_switch.lms

The example downloads the lmbio, lmplot and lmdraw release binaries on first use (Linux needs dynamic glibc 2.35 or newer). The animated examples also write a GIF when ffmpeg is on PATH.

Release status, checked with lmscript 0.2.482: the main branch of the repository (version 0.1.3 in CMakeLists.txt) answers the --lmcode-schema, --lmcode-signatures and --lmcode flags, but the v0.1.3 release binary that install="github:lmctl-ai/lmbio@latest" downloaded on the day this page was written still printed a usage line with the older --dsl-schema, --dsl-signatures and --dsl flags, so current lmscript stopped with a schema host exited 2 error. Until a release built from main is published, build the host from source and put it first on PATH.

Minimal runnable example

prog = _lmcode_ cli="lmbio" install="github:lmctl-ai/lmbio@latest";
let m = bio.model("conversion").compartment("cell", 1.0);
m.species("A", "cell", 1.0).species("B", "cell", 0.0);
m.param("k", 0.7).reaction("convert", "A -> B", "k*A");
let result = m.simulate(0.0, 4.0, 41);
bio.assert_close(result.final("A"), 0.060810062625, 0.000001);
bio.assert_close(result.final("A") + result.final("B"), 1.0, 0.000001);
result.save_csv("conversion.csv");
lmcode_return_put("A", result.final("A"));
lmcode_return_put("rows", result.rows());
end _lmcode_
r = run_lmcode(prog);
println(json_stringify(r));
require(r.ok, "conversion failed");

Host CLI and protocol

usage: lmbio --version | --notices | --lmcode-schema [--json] | --lmcode-signatures | [--dry-run] --lmcode FILE [FILE ...]
FlagBehavior
--versionPrint the version
--noticesPrint the embedded third-party notices (SUNDIALS, pugixml, toolchain runtimes)
--lmcode-schemaPrint the schema; with --json print the embedded schema JSON. Any other extra argument is a usage error, exit 2
--lmcode-signaturesPrint the callable signatures
--lmcode FILE [FILE ...]Load every compiled .dslb program, then run them in order, stopping at the first failure
--dry-run --lmcode FILE ...Check bytecode without running the model or writing files
ItemValue
Schemaschema/lmbio.dsl.json, dsl.schema 2, name lmbio, context bio of type Bio, 3 host types, 37 host methods
Standard librarylmcode_std_v3 with 206 signatures vendored at main (the current catalog in lmcode-cpp has 226)
Exit codes0 success, 2 usage error, 3 bytecode load or run error
Memory budgetLMBIO_MAX_MEMORY_MB, default 4096 MiB on 64-bit
