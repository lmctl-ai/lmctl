miniplayer reference

Reference tables for miniplayer CLI subcommands, flags, configuration properties, environment variables, and exit codes.

CLI subcommands and flags

Subcommand Flags Description
miniplayer --version, -v, -V, version none Print miniplayer semantic version (plus git commit on dev builds).
miniplayer run -m <model>, --file <path>, --system <text>, --system-file <path>, --session <new|id>, --json, --wrapup Execute a pure one-shot prompt without tools, cwd preamble, or context files.
miniplayer classify -m <model>, --file <path>, --system <text>, --system-file <path> Classify input from stdin or --file into compact JSON {"label","reason","confidence"}.
miniplayer chat -m <model>, --no-context-files, --no-wrapup, --system <text>, --system-file <path> Start the interactive REPL (/exit, /help, /compact, Ctrl-C turn cancellation).
miniplayer acp -m <model>, --no-context-files, --system <text>, --system-file <path> Run the Agent Client Protocol JSON-RPC daemon over stdin/stdout (supports session/load and session/resume).
miniplayer models --routed, --provider <name>, --source <name>, --max-input-price <usd>, --json List catalog models, filter by provider or price, and report API key availability.
miniplayer providers --json List all routed providers, SDK types, base URLs, key_env names, and key_set boolean status.

Configuration keys (~/.config/miniplayer/config.json)

Key Type and default Description
model string Default model selector when -m is omitted.
pool, poolOrdered string[], boolean (false) Candidate model pool tried in random order or strict order when poolOrdered is true.
requestTimeoutMs integer (60000) Timeout in milliseconds for one-shot requests.
wrapUp boolean (true) Whether interactive REPL exit triggers a durable-memory summary turn.
contextFiles boolean (true) Whether chat and acp sessions include AGENTS.md and durable-memory/index.md.
compact {thresholdRatio: 0.7, thresholdTokens: 100000} Context window fraction or token count that triggers automatic conversation compaction.
tools Array<string | {name, command, brief}> ([]) External tool executables exposed in interactive chat and acp sessions.
provider Record<string, {baseURL?, apiKey?}> Per-provider baseURL overrides (such as loopback lmmock endpoints).

Environment variables

Variable Default Purpose
MINIPLAYER_CONFIG ~/.config/miniplayer/config.json Path to the JSON configuration file.
MINIPLAYER_CATALOG unset (uses ETag cache) Pin model resolution to a local model_list.json file and disable all catalog network requests.
MINIPLAYER_PRICE_TTL 21600 (6 hours) Catalog cache time-to-live in seconds (0 forces ETag revalidation).
OLLAMA_HOST http://localhost:11434/v1 Local Ollama server origin for keyless ollama/<model> selectors.
ANTHROPIC_API_KEY, OPENAI_API_KEY, GOOGLE_GENERATIVE_AI_API_KEY, DEEPSEEK_API_KEY, MOONSHOT_API_KEY, OPENROUTER_API_KEY, XAI_API_KEY, TOGETHER_API_KEY unset Provider API key environment variables discovered from catalog route key_env metadata.

Exit codes

Code Meaning
0 Prompt, classification, catalog query, or interactive session completed cleanly.
1 Missing API key, unknown provider selector, unavailable catalog without cache, or request timeout.
