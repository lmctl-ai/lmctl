lmssl reference

Complete command-line flag reference, host schema contexts and methods, X.509 and TLS types, standard lmcode_std_v3 REST and CLI interfaces, and exit codes for lmssl v0.2.1 (bundling OpenSSL 4.0.3).

Host and CLI flags

Flag or commandArgumentsDescription
--versionnonePrint the lmssl and embedded OpenSSL version string (lmssl 0.2.1 (OpenSSL 4.0.3 29 Sep 2026)) and exit 0.
--lmcode<file.dslb> [args...]Validate and execute a compiled LMScript bytecode part; repeatable for multi-part runs with per-part ssl.args().
--dry-run--lmcode <file.dslb>Validate bytecode loading and run in dry mode without key generation, file writes, or socket operations.
--json--lmcode <file.dslb>Compatibility flag accepted for _lmcode_ invocations (all _lmcode_ runs emit a terminal JSON SDK frame on stdout).
--lmcode-schema[--json]Print a human-readable schema summary, or exact embedded schema JSON bytes when --json is passed.
--lmcode-signaturesnonePrint all 360 canonical context, function, and method signatures (134 host + 226 standard library).
<openssl-cmd>[openssl-args...]Any other command (version, req, x509, ca, s_client, enc, dgst, pkcs12, cms, ocsp, ...) runs OpenSSL 4.0.3 directly.

Exit codes

Exit codeCategoryMeaning
0SuccessAll _lmcode_ bytecode parts or introspection commands succeeded and all assertions passed.
2CLI / metadata errorMalformed host command-line invocation or missing required --lmcode argument.
3Load / host run errorBytecode load failure, schema SHA-256 mismatch, or runtime host error (RUN_HOST, such as TLS handshake failure or invalid cipher input).
4Application failureScript called out.fail(msg) or failed an assertion contract (code APP_FAIL).
0..255Native OpenSSL CLI modeWhen invoked with an OpenSSL subcommand (req, x509, s_client, ...), returns OpenSSL 4.0.3's native exit code.
