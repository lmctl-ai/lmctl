lmweblab

lmweblab is a pictures-first cloud web stack integration benchmark and 12-scenario suite comparing native lmaws and OpenTofu-based lmcloud on AWS. Every stack provisions tagged S3, CloudFront, Route 53, ACM, EC2, or serverless resources, validates HTTP and p95 latency contracts with lmcurl, and proves zero leftovers on teardown.

Quick reference

npm i -g @lmctl-ai/lmctl
lmctl lmaws/web_stack.lms all --offline --phase2
lmctl lmaws/report.lms
lmctl lmcloud/all.lms
bash test.sh
Driver or recipe Invocation Summary
lmaws/web_stack.lms lmctl lmaws/web_stack.lms all --offline [--phase2] Run Part A (lmaws) up, HTTP test, optional Phase 2 HTTPS upgrade, and teardown
lmaws/down.lms lmctl lmaws/down.lms --run-id RUN_ID [--live] Perform reverse-order teardown of a tagged run and verify zero owned leftovers
lmaws/status.lms lmctl lmaws/status.lms --run-id RUN_ID [--live] Inspect masked run state and provider inventory without locking lifecycle state
lmaws/recipes/steps.lms import "./lmaws/recipes/steps.lms"; Import granular guarded step helpers (web_bucket, web_certificate, web_distribution, etc.)
lmcloud/all.lms lmctl lmcloud/all.lms [--live] Run Part B (lmcloud/OpenTofu) end-to-end lifecycle and render architecture/latency PNGs
lmcloud/validate.lms lmctl lmcloud/validate.lms Run offline OpenTofu fmt_check, init, validate, and Phase 1/Phase 2 mock plans
scenarios/NN-name/*/all.lms lmctl all.lms --offline Execute any of the 12 cloud web and serverless scenarios (up, test, down)
