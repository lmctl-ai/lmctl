lmplot

lmplot is gnuplot packaged as a single self-contained executable and LMScript host with embedded DejaVu fonts and a deterministic PNG/SVG rasterizer. It renders 2D and 3D plots, surfaces, contours, heat maps, fits, and dashboards without X11, Cairo, or libgd.

Quick reference

npm install -g @lmctl-ai/lmctl
lmplot --version
lmplot --lmcode-schema --json
lmplot gnuplot -e "set terminal png size 800,500; set output 'sin.png'; plot sin(x) lw 2"

plot.cmd("plot sin(x) lw 2, x - x**3/6.0 dt 2");
plot.close();
end _lmcode_
r = run_lmcode(p);
