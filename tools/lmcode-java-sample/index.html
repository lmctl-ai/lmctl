lmcode-java-sample

lmcode-java-sample is the Java 21 and GraalVM Native Image reference Shop and Ledger host embedding lmcode-java and passing the canonical sample suite. It compiles with zero external Maven dependencies, preserves raw byte strings in VmString, dispatches R49 rule entries, and frames LMCODE_RETURN results.

Quick reference

git clone https://github.com/lmctl-ai/lmcode-java-sample.git
cd lmcode-java-sample
python3 scripts/sync.py check
./build.sh
./test.sh
