lmazure reference

Reference tables for lmazure CLI options, environment variables, shared Cloud methods, ARM inventory session methods, standard lmcode_std_v3 REST and CLI interfaces, and exit codes.

CLI flags

Flag Description
--version, -V Print lmazure version string (for example lmazure 0.1.5).
--help, -h Print usage, endpoint precedence, and simulator environment variables.
--notices Print embedded third-party notices for lmcode-go, lmcloud, and Azure SDK for Go packages.
[cloud] --lmcode-schema [--json] Emit raw embedded schema JSON bytes for lmscript compilation.
[cloud] --lmcode-signatures [--without-std] Print sorted canonical signatures with or without the 226 lmcode_std_v3 standard signatures.
[cloud] [--lmcode|--first|--last] FILE ... Execute compiled .dslb bytecode files under the invocation manifest; dry runs come from the manifest written by lmscript --dry-run.
--sweep [RUN_ID] Run stale-prefix sweep and emit a JSON summary of swept resources.

Environment variables

Variable Default Purpose
LMCLOUD_ENDPOINT, LMAZURE_ENDPOINT, AZURE_STORAGE_ENDPOINT, AZURE_ENDPOINT unset (in-process fake) Loopback HTTP origin for azuresim (such as http://127.0.0.1:4577).
AZURE_STORAGE_BLOB_ENDPOINT, AZURE_STORAGE_QUEUE_ENDPOINT unset Service-specific loopback endpoint overrides for Blob or Queue Storage.
LMAZURE_SIM_ACCOUNT devstoreaccount1 Storage account name used in loopback azuresim URLs and SharedKey signing.
LMAZURE_SIM_KEY Azurite/azuresim dev key Base64 SharedKey used to sign loopback requests when LMAZURE_SIM_TOKEN is unset.
LMAZURE_SIM_TOKEN unset Bearer token override for testing azuresim --auth enforce Bearer rules.
LMAZURE_COMPAT_PROBE_EXISTENCE 1 Pre-operation existence probes for azuresim builds before 7903c9c; enabled by default.
LMAZURE_MAX_MEMORY_MB 4096 Memory ceiling in whole MiB; invalid values exit 2, breaches exit 3.

Shared Cloud and ARM gallery APIs

Surface Methods Description
Cloud object storage (Blob) bucket_create, bucket_delete, bucket_exists, bucket_list, object_put, object_get, object_head, object_delete, object_list, object_list_all Create and delete Blob containers and upload, download, head, list, or delete block blobs.
Cloud queues (Queue Storage) queue_create, queue_delete, queue_exists, queue_list, queue_send, queue_receive, queue_ack, queue_nack Create and delete Azure queues, enqueue messages, dequeue batches, delete by receipt, and update visibility timeout.
Cloud tables, permissions, functions, userpools table_*, item_*, policy_*, function_*, userpool_*, user_*, group_*, cost_*, metrics* Portable key-value tables, policy linting/attachment, serverless functions, user directories, cost caps, and latency metrics.
ARM inventory session mock(), live(), session.inventory(kind), session.find_prefix(prefix), session.readonly_cost_report(path), session.begin_run(path), run.container(suffix), run.queue(suffix), run.cost_cap(usd), run.cleanup() 72-example gallery surface for read-only ARM metadata tables and ledger-tracked container/queue sandboxes.

Standard lmcode_std_v3 REST and CLI interfaces

Interface or function Signature Purpose
RestGet .. RestOptions, RestHandler fn h(x: RestExchange) -> void implements RestGet .. RestHandler HTTP route handlers bound via @"/path/:param" annotations.
CliCommand, CliOption fn c(x: RestExchange) -> void implements CliCommand | CliOption CLI subcommands (@"cmd") and options (@"--flag").
rest_config, rest_route, rest_serve, rest_stop, rest_cli rest_config(k, v); rest_route(m, p, h); rest_serve(); rest_stop(); rest_cli(args) -> string Configure routes, serve HTTP, or dispatch CLI and REST requests in-process.

Exit codes

Code Meaning
0 Command or bytecode execution succeeded.
2 Invalid command-line flags or invalid LMAZURE_MAX_MEMORY_MB setting.
3 Cloud error, cost cap exceeded, assertion failure, or memory ceiling exceeded.
4 Bytecode file or schema contract loading failure.
