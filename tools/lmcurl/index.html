lmcurl

lmcurl is an HTTP, LDAPv3, and LLM contract testing CLI and LMScript host built on libcurl and a pure C++17 BER/ASN.1 LDAPv3 wire engine. It runs direct CLI requests, test suites, JSONPath and XPath queries, load checks, and standard REST and CLI interfaces.
