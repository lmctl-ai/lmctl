Sequential crew

Run a researcher, a writer and an editor in order, each task seeing the previous output.

Three agents run as a list of tasks. Each task receives the previous task output as its context, and every result is appended to crew-log.md so the whole run can be read afterwards. Only the editor output is printed.

What it maps to

Crew with a sequential process: a list of tasks and a for loop. Task context: the previous output is passed in the prompt. See the concept map.

Script: sequential-crew.lms

# Sequential crew: researcher, writer and editor run in order; each task sees the previous output.
import "agentic.lms";
topic = ARGV.get(0, "why short scripts are easier to review than agent frameworks");
tasks = [
  {who: agent("researcher", "collect concrete, checkable points"), todo: f"List 4 short points about: {topic}. One per line."},
  {who: agent("writer", "turn points into a clear paragraph"), todo: "Write one paragraph of at most 90 words from these points."},
  {who: agent("editor", "tighten prose without dropping points"), todo: "Edit this paragraph. Output only the final paragraph."}
];
context = "";
for (t in tasks) {
  context = ask(t.who, t.todo + "\n\n" + context);
  append_file("crew-log.md", f"## {t.who.role}\n{context}\n\n");
}
println(context);
