lmr — Native statistics for LMScript

lmr is a native LMScript host for distributions, statistical tests, regression, time series, clustering, smoothing, and numerical optimization. It runs without an R runtime and can be installed automatically by lmscript.

Start with the lmr skill for setup and verification, the API guide for operations, or the example book for runnable analyses.

Try a solo or trio lmr quickrun to ask a provider team to analyze a small data set.

Source and releases: github.com/lmctl-ai/lmr.
