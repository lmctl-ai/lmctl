ocisim

ocisim is a single-binary local Oracle Cloud Infrastructure (OCI) emulator on 127.0.0.1:4599 that runs Object Storage, IAM, Queue, Streaming, Vault, KMS, and Secrets in-process.

Quick reference

Start ocisim on loopback port 4599 in open mode or with two-layer RSA-SHA256 HTTP signature and OCI IAM policy enforcement, then connect lmoci or any OCI SDK.

ocisim --version
ocisim serve
ocisim serve --port 4599 --data-dir ./state
ocisim serve --auth enforce --auth-config ./auth.json
curl http://127.0.0.1:4599/_floci-oci/health
Command or option Default Purpose
ocisim serve | start 127.0.0.1:4599, in-memory Run the foreground loopback OCI emulator for Object Storage, IAM, Queue, Streaming, Vault, KMS, and Secrets.
--port <port> 4599 Override the loopback TCP listening port.
--data-dir <path> in-memory Persist buckets, objects, compartments, and queues across restarts.
--auth open | enforce open (OCISIM_AUTH / SIM_AUTH) Parse keyId for multi-tenancy isolation in open mode, or enforce RSA-SHA256 signatures and IAM policies.
--auth-config <file> OCISIM_AUTH_CONFIG / SIM_AUTH_CONFIG JSON file defining credentials (keyId, publicKeyFile, groups, statements, policy.Statement).
GET /_floci-oci/health anonymous Health endpoint available in both open and enforce modes.

Example driving a running ocisim on 127.0.0.1:4599 with lmoci in open mode:

curl http://127.0.0.1:4599/_floci-oci/health
lmoci os namespace --endpoint http://127.0.0.1:4599
lmoci os create-bucket demo-bucket --endpoint http://127.0.0.1:4599
lmoci os put-object demo-bucket hello.txt --content "hello from lmoci" --endpoint http://127.0.0.1:4599
lmoci os get-object demo-bucket hello.txt --endpoint http://127.0.0.1:4599
