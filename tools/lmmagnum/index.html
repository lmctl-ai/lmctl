lmmagnum

lmmagnum is a native lmcode host that builds a 3D scene from Magnum primitives, renders it with a built-in software rasterizer and exports PNG, PPM, STL, OBJ or PLY. It is one static executable with no GPU, window system or shared library requirement, and lmscript installs it automatically.

This page is the quick reference. The latest release checked here is lmmagnum 0.2.15; it ships the 206-signature lmcode_std_v3 standard library next to its 60 host signatures.

Install and run

npm install -g @lmctl-ai/lmctl
lmscript scene.lms             # downloads the lmmagnum release on first use
lmscript --check scene.lms     # compile the _lmcode_ block against the host schema

The install attribute github:lmctl-ai/lmmagnum@latest on the block makes lmscript download and cache the release binary. The current release lane publishes Linux x64 and arm64 binaries. Run a repository example straight from its URL (it writes images/primitives.png):

lmctl autorun https://raw.githubusercontent.com/lmctl-ai/lmmagnum/main/examples/primitives.lms

Minimal runnable example

prog = _lmcode_ cli="lmmagnum" install="github:lmctl-ai/lmmagnum@latest";
scene.background(0.08, 0.09, 0.12);
let m = material().color(0.85, 0.45, 0.2).specular(0.4);
scene.cube(1.0, m).translate(-1.5, 0.0, 0.0).rotate(20.0, 30.0, 0.0);
scene.sphere(0.6, m).translate(1.5, 0.0, 0.0);
scene.camera(40.0, 0.0, 1.5, 9.0, 0.0, -0.5, 0.0);
scene.directional_light(-0.5, -1.0, -0.4, 0.9);
scene.render_png("scene.png", 800, 400);
scene.export_obj("scene.obj");
lmcode_return_put("shapes", scene.shape_count());
lmcode_return_put("triangles", scene.triangle_count());
lmcode_return_put("magnum", magnum_version());
end _lmcode_
r = run_lmcode(prog);
println(json_stringify(r));
require(r.ok, "render failed");

Saved as scene.lms and run with lmscript scene.lms, the program writes scene.png and scene.obj and prints:

lmscript scene.lms
{"ok":true,"result":{"shapes":2,"triangles":2220,"magnum":"369e9620ab22"}}

Host API quick reference

The single context object is scene, of type Scene. Builder methods return their receiver so calls chain. Argument descriptions follow the usage in the repository examples.
