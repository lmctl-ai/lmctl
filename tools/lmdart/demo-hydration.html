How it works

The HTML is a static template. JSON supplies values or drawing data. Dart owns rendering and browser events; boot.js registers small JavaScript handlers through LMDart.register.

final data = await fetchJson('data/hydration.json');
hydrate(document.getElementById('hydration-card')!, data);
button.onClick.listen((_) {
  LMDart.call('hydrate.clicked', {'value': 'hydration'});
});
