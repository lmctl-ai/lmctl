Get started with lmblender quickruns

Overview

These lmscript files create a teamfile, seed provider sessions, and ask a Lead to make a rendered scene with lmblender. The trio script passes the Lead's task to a Coder, asks a Reviewer to check the result, then returns the findings to the Lead.

Choose a team

  • lmblender_solo.lms runs one Lead using Claude Sonnet 5.5.
  • lmblender_trio.lms runs a Claude Lead, Gemini Coder, and Codex Reviewer.

Install lmctl and configure the providers named in the selected script. Run the script from the working directory where you want the scene source and output files.

Run a quickrun

lmctl autorun https://lmctl.com/tools/lmblender/lmblender_solo.lms
lmctl autorun https://lmctl.com/tools/lmblender/lmblender_trio.lms

The examples ask for a camera, materials, lighting, a PNG render, and a concrete check. The installation is pinned to lmblender v0.3.6. Read the final report and inspect the generated files before using them in a project.
