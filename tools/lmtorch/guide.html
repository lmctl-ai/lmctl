lmtorch API guide

The lmtorch DSL host runs a compiled LMScript block in one native process. Tensor values and model state stay in memory until the block returns.

Overview

Start with a host block that declares the released executable and the operation to run.

Start a host block

Declare the released host with cli and install. LMScript asks that binary for its embedded DSL schema and uses the same executable to run the compiled block.

p = _lmcode_ cli="lmtorch" install="github:lmctl-ai/lmtorch@latest";
let x = torch.tensor("[1.0, 2.0, 3.0]");
out.set("sum", x.sum().item());
end _lmcode_

Use dsl_cli(p) as the command prefix when running the saved bytecode with --dsl. The host prints one JSON result containing values set through out.

Tensor creation and operations

Torch creates tensors from JSON arrays and provides zeros, ones, full, rand, randn, arange, linspace, eye, and scalar constructors. Tensor methods cover shape, indexing, arithmetic, matrix multiplication, reductions, reshaping, activations, comparisons, and file output.

let a = torch.tensor("[[1.0, 2.0], [3.0, 4.0]]");
let total = a.sum().item();
let product = a.matmul(a);
out.set("sum", total).set("product", product);

Automatic differentiation

Mark a tensor with requires_grad(true), build a scalar loss, and call backward. Read the derivative with grad. Gradients accumulate until zero_grad is called on the tensor or optimizer.

let x = torch.tensor("[1.0, -2.0, 3.0]").requires_grad(true);
let loss = x.square().sum();
loss.backward();
out.set("gradient", x.grad());

Models and optimizers

Build a sequential model by chaining layers such as linear, conv2d, relu, flatten, and dropout. Call forward to evaluate it. Create an SGD, Adam, or AdamW optimizer from the model, then zero gradients, backpropagate a loss, and take a step.

Files and runtime limits

Use Tensor.save and Torch.load for safetensors, read_csv for numeric CSV input, and write_csv for tabular predictions. Output paths must stay inside the current working directory. The public release is CPU-only and includes its native runtime dependencies.
