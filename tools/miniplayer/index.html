miniplayer

miniplayer is a fast, lightweight CLI harness for language models built on the principle of prompt in, text out, with zero built-in tool dependencies.

Quick reference

Run pure one-shot prompts, classify responses into compact JSON, inspect routed catalog models and providers, or start an interactive chat or ACP session.

miniplayer --version
miniplayer providers
miniplayer models --routed
miniplayer run -m ollama/qwen2.5:14b "Summarize this repository in three bullets"
printf '%s\n' "The fix is complete." | miniplayer classify -m claude-haiku-4-5
miniplayer chat -m ollama/qwen2.5:14b
miniplayer acp -m deepseek/deepseek-flash
Command Usage Purpose
miniplayer run miniplayer run -m <model> [--file F] [--system S] [--session new|ID] [prompt] Pure one-shot execution: sends zero tools, no cwd preamble, and no context files.
miniplayer classify miniplayer classify -m <model> [--file F] [--system S] Pure response classifier emitting {"label":"...","reason":"...","confidence":0.96}.
miniplayer chat miniplayer chat -m <model> [--no-context-files] [--no-wrapup] Interactive REPL with /exit, /help, /compact, Ctrl-C turn cancel, and optional external tools.
miniplayer acp miniplayer acp -m <model> [--no-context-files] [--system-file F] Agent Client Protocol JSON-RPC server over stdio for lmctl Teamfiles and IDEs.
miniplayer models miniplayer models [--routed] [--provider P] [--source S] [--max-input-price N] [--json] Query the ETag-cached lmctl.com model catalog and inspect API key readiness.
miniplayer providers miniplayer providers [--json] List every routed provider, its SDK type, base URL, key environment variable, and key_set status.

Runnable CLI example using miniplayer for pure one-shot interpretation and response classification:

export OLLAMA_HOST=http://127.0.0.1:11434
miniplayer run -m ollama/qwen2.5:14b --system "Reply in one line." "Explain prompt-in text-out"
printf '%s\n' "All unit tests passed; ready for review." | miniplayer classify -m ollama/qwen2.5:14b
