lmpdf reference

Complete CLI subcommands and flags, Docx and Pptx schema types and methods, standard lmcode_std_v3 catalog, and exit codes for lmpdf.

CLI subcommands and flags

Command or flagArgumentsDescription
lmpdf --versionnonePrint the lmpdf version string and exit 0.
lmpdf docx --lmcode-schema[--json]Print human-readable docx schema summary or exact embedded JSON schema bytes.
lmpdf docx --lmcode-signatures[--without-std]Print canonical signatures for the docx route (optionally excluding lmcode_std_v3).
lmpdf docx --lmcode[--no-tagged] FILE [--lmcode FILE ...]Execute one or more compiled bytecode files against the docx PDF layout route.
lmpdf docx --to-markdownFILE.pdfExtract Markdown text from a PDF document.
lmpdf pptx --lmcode-schema[--json]Print human-readable pptx schema summary or exact embedded JSON schema bytes.
lmpdf pptx --lmcode-signatures[--without-std]Print canonical signatures for the pptx route (optionally excluding lmcode_std_v3).
lmpdf pptx --lmcode[--no-tagged] FILE [--lmcode FILE ...]Execute one or more compiled bytecode files against the pptx 16:9 slide deck PDF route.
lmpdf inspectFILE.pdf [--markdown]Inspect a PDF file and return a JSON summary containing page, image, table, and link counts plus extracted text.

Exit codes

Exit codePhaseMeaning
0successPDF rendering, dry validation, or inspection succeeded and emitted an LMCODE_RETURN frame.
2cliInvalid CLI argument, retired flag (such as --first or --last), or malformed invocation manifest (such as missing/non-boolean dry).
3load / runBytecode load failure, schema mismatch, VM runtime error, or html_doc / html_xml dry validation failure.
4appApplication, Typst layout, missing input file, or output path write failure.
