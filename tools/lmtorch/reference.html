lmtorch reference

Command-line flags, exit codes, context objects, host types and methods, and standard-library signatures of lmtorch 0.5.1, generated from the repository schema (schema/lmtorch.host.json), the host source and the vendored lmcode std schema. The host schema declares 214 method signatures on 7 types. Parameter and return types are int, float, string, bool, void and the host or standard types named here.

Command line

CommandEffect
lmtorch --versionPrints lmtorch and the version number, exit 0.
lmtorch --lmcode-schemaPrints a readable summary of the host API grouped by type.
lmtorch --lmcode-schema --jsonPrints the exact embedded host schema bytes (schema 2, name lmtorch) that lmscript compiles against.
lmtorch --lmcode-signaturesPrints one canonical signature per line (context, function and method entries).
lmtorch --lmcode FILE.dslbRuns compiled bytecode under the v1 invocation manifest and prints one terminal return frame. Several files may follow one --lmcode.
--first FILE.dslb, --last FILE.dslbAdditional bytecode files ordered before or after the --lmcode files in the same invocation.

Exit codes

Exit codePhaseMeaning
0noneSuccess.
2cliUsage error (CLI_USAGE), retired or unknown flag, invalid invocation manifest, or a missing or nonboolean dry value; no host work is done.
3load or runBytecode failed verification against the embedded schema (for example LOAD_BAD_BYTECODE), or a program failed while running (host errors are reported as RUN_HOST).
4appApplication-phase failure, or the result could not be written to standard output.

Used from lmscript

p = _lmcode_ cli="lmtorch" install="github:lmctl-ai/lmtorch@latest";
let values = torch.tensor("[[1.0, 2.0], [3.0, 4.0]]");
let total = values.sum().item();
out.check(total == 10.0, "sum must be 10");
out.set("shape", values.shape()).set("sum", total);
end _lmcode_

run = run_lmcode(p);
if (!run.ok) { println(f"lmtorch {run.phase} error {run.code}: {run.message}"); exit(1); }
result = run.result;
println(f"shape {result.shape}, sum {result.sum}");

Standard library in lmtorch 0.5.1

lmtorch 0.5.1 vendors the lmcode_std_v3 catalog of the lmcode-cpp commit pinned in sdk.lock: 206 canonical signatures (83 functions and 123 methods on 16 standard types). The current lmcode_std_v3 catalog has 226 signatures, adding the REST and CLI interfaces; lmtorch picks those up when it syncs its SDK pin and releases. lmtorch implements none of it; the embedded VM registers it. Std file functions are not confined to the working directory.
