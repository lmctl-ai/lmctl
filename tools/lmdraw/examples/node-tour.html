Node Tour

Demonstrates retained nodes, groups, a linear gradient, path geometry, and text measurement. This page includes the render and a quickrun-ready lmscript source file.

Let an agent build from this example

Copy this prompt into your Lead's terminal to ask an agent to make a related drawing:

Create a drawing inspired by the Node Tour example. Use the lmdraw API and source links below, compile and render a PNG, and report the source and verification.
LMScript DSL: https://lmctl.com/tools/lmscript/skill.html
lmdraw API: https://lmctl.com/tools/lmdraw/guide.html
Example book: https://lmctl.com/tools/lmdraw/examples/node-tour.html

Run the example

lmctl quickrun https://lmctl.com/tools/lmdraw/examples/node-tour.lms

Read the quickrun source. See get started with quickrun teams.
