Check Links

Classify links and report broken local destinations in a synthetic site. This page includes the result and a quickrun-ready lmscript source file.

Let an agent build from this example

Copy this prompt into your Lead's terminal to ask an agent to make a related example:

Audit a small synthetic website for broken internal links, compare two
page revisions, and extract or apply one shared-page change. Use lmhtml
examples as a starting point, save the source and reports, and state the
checks that passed. Use the lmhtml API and the Check Links example
below. Report the source, output, and verification.
LMScript DSL: https://lmctl.com/tools/lmscript/skill.html
lmhtml API: https://lmctl.com/tools/lmhtml/guide.html
Broken-link audit example: https://lmctl.com/tools/lmhtml/examples/check-links.html

Run the example

lmctl autorun https://lmctl.com/tools/lmhtml/examples/check-links.lms

Read the quickrun source. See get started with quickrun teams.
