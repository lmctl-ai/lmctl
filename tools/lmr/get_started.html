Get started with lmr quickruns

These two LMScript programs seed provider sessions and ask an agent team to run a small statistical analysis with lmr.

Overview

A quickrun is an LMScript file that creates a teamfile in the current working directory, seeds the requested provider sessions, and sends a task to the team.

Choose a team

  • lmr_solo.lms seeds one Lead using Claude Sonnet 5.5.
  • lmr_trio.lms seeds a Lead, a Gemini Coder, and a Codex Reviewer. The Lead passes its assignment to the Coder, the Coder's result to the Reviewer, then returns both to the Lead for a report.

Install lmctl and configure each provider before running a quickrun. Each run writes a new numbered teamfile in the current directory and seeds its sessions.

Run a quickrun

lmctl autorun https://lmctl.com/tools/lmr/lmr_solo.lms
lmctl autorun https://lmctl.com/tools/lmr/lmr_trio.lms

The task asks the team to analyze a small data set, verify the result with lmr, and report the source and checks.

Seed without sending a task

Append --seed-only to check team creation and provider setup without asking the agents to do the analysis.

lmctl --non-interactive autorun \
  https://lmctl.com/tools/lmr/lmr_solo.lms \
  --seed-only
