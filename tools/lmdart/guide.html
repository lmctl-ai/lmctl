lmdart quick reference

lmdart compiles Dart to JavaScript and calls browser DOM, SVG, Canvas, and WebGL APIs directly. HTML remains a template, JSON supplies application data, and small JavaScript handlers register with the Dart runtime. No Flutter or heavyweight framework is used.

Overview

The demo book starts at the tool root. Its eight chapters are separate pages, not options in a selector.

  1. HTML hydration updates a static card from JSON and runs JavaScript and Dart handlers.
  2. JSON HTML tables bind columns and rows with pointer and keyboard selection.
  3. SVG drawing creates retained DOM from JSON commands.
  4. Canvas drawing renders immediate shapes and validated pointer marks.
  5. Charts render SVG bars and arc wedges.
  6. Plots render line and scatter series to Canvas.
  7. Animation tweens position, radius, opacity, and Canvas particles.
  8. WebGL compiles shaders and draws an animated 3D cube.

Build

The SDK installer supports Linux x64 and arm64. It downloads official Dart 3.14.1 and verifies a pinned SHA-256 checksum.

git clone https://github.com/lmctl-ai/lmdart.git
cd lmdart
bash scripts/build.sh

The static site is written to target/site. Pass an absolute output path to build directly into another site.

Runtime API

JavaScript APIPurpose
LMDart.versionRuntime version 0.1.0.
LMDart.register(name, handler)Register a JavaScript function taking one context object.
LMDart.call(name, context)Call a registered JavaScript or Dart handler and return its value.
LMDart.loadJson(path, success, failure)Fetch JSON and deliver converted values or an error.
LMDart.setText(selector, value)Set textContent on an existing element.
LMDart.setAttribute(selector, name, value)Set an attribute on an existing element.
LMDart.start()Dispatch the page after all handlers are registered.

Register a handler

LMDart.register('card.clicked', context => {
  const result = LMDart.call('dart.stamp', { value: context.value });
  LMDart.setText('#result', result);
  return true;
});
LMDart.start();

JavaScript and Dart handlers share one namespace. Empty, duplicate, and unknown names are errors. Context objects and return values use dart:js_interop conversions rather than serialized strings.

Verify

scripts/install-dart.sh
.tools/dart-sdk/bin/dart analyze
.tools/dart-sdk/bin/dart test -r expanded
bash scripts/build.sh
npm ci
npx playwright install --with-deps chromium
npm test

Twelve VM tests cover models, scales, tween math, and matrices. Browser integration covers all nine pages, real SVG and Canvas output, WebGL pixels, JSON requests, runtime handlers, keyboard events, and mobile layout. Set DEMO_URL to the deployed root URL for live verification.
