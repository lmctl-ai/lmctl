tree-sitter-lmscript

tree-sitter-lmscript is the Tree-sitter grammar, external scanner, and companion lmscript_lmcode injection parser for LMScript (.lms) files. It parses outer LMScript statements, command literals, queued data blocks, and _lmcode_ bodies with single-line f"..." template expansion.

Quick reference

git clone https://github.com/lmctl-ai/tree-sitter-lmscript.git
cd tree-sitter-lmscript
npm install --prefix /tmp/lmscript-tree-sitter tree-sitter-cli@0.27.1
export TREE_SITTER=/tmp/lmscript-tree-sitter/node_modules/.bin/tree-sitter
npm test
