lmblender

Overview

lmblender runs lmscript scene descriptions through a standalone CPU renderer based on Blender's Cycles engine. It builds the scene directly in C++; it does not launch Blender or execute Python. Render still images, image sequences and APNG animations, inspect mesh properties, and export common mesh formats.

The book pins lmblender v0.3.6, which includes the rendering fixes described in the current release notes. Linux arm64 preview renders on this page were produced with the v0.3.6 release binary on an AWS Graviton2 host. Denoising was enabled; the SVE denoiser crash in v0.3.4 and earlier is fixed in this release.
