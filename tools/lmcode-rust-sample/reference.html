lmcode-rust-sample reference

Reference tables for the lmcode-rust-sample (Rust (stable, zero crates.io dependencies)) type conversions, 45 Shop/Ledger domain signatures, CLI protocol flags, and exit codes.

Host language type conversions

lmcode typeHost representationBoundary rule
inti64 (Value::Int)Explicit wrapping_add, wrapping_sub, wrapping_mul, and wrapping_neg
floatf64 (Value::Float)IEEE-754 binary64 formatted with dslvm::format_g15
boolbool (Value::Bool)Strict boolean tag without integer coercion
stringByteString (Value::Str)Raw byte vector preserving embedded NUL and invalid UTF-8 bytes
Money / Items / Shop / LedgerObjRef in ContextArena-indexed Box<dyn Any> borrowed via Context::get and Context::get_mut
voidValue::NonePushes no value; fluent methods return the receiver ObjRef handle
