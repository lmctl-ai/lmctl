lmldap

lmldap is a single-executable OpenLDAP (slapd + LMDB) server with zero-config startup, an integrated HTTP/JSON REST server, and an embedded LMScript host. It serves native RFC 4511 LDAPv3 and HTTP REST against a unified directory while exposing context ldap: Ldap and standard REST and CLI interfaces.

assert_eq(ok, true);
assert_eq(ldap.exists("cn=Alice,dc=example,dc=com"), true);
