lmoci

lmoci is the Oracle Cloud Infrastructure scripting host for LMScript, providing both the shared lmcloud procedural schema and a 16-section OCI SDK and CLI surface.

Quick reference

Declare lmoci in an LMScript program or invoke its direct CLI subcommands against offline demo fixtures, the local ocisim emulator on 127.0.0.1:4599, or guarded live tenancies.

lmoci --version
lmoci --lmcode-schema --json
lmoci --lmcode-signatures
lmoci inventory all --demo
lmoci os namespace --endpoint http://127.0.0.1:4599
p = _lmcode_ cli="lmoci" install="github:lmctl-ai/lmoci@latest";
Surface Command or method Purpose
Shared cloud context context cloud: Cloud Provider-neutral OCI Object Storage, OCI Queue, tables, IAM permissions, Functions, user directories, cost caps, and metrics.
OCI SDK context context oci: Oci; oci.connect("demo"), oci.with_sandbox(name, fn) 16-section OCI inventory, Object Storage, Queue, Streaming cursors, Vault/KMS/Secrets metadata, IAM policy lint, and ledger-tracked sandboxes.
Direct CLI subcommands lmoci cred | inventory | os | iam | queue | stream | vault Deterministic JSON envelope commands for shell automation against --demo or --endpoint http://127.0.0.1:4599.
Standard REST and CLI rest_config, rest_route, rest_serve, rest_stop, rest_cli Expose OCI storage and queue workflows as HTTP routes (:param patterns) and CLI commands via lmcode_std_v3 interfaces.

Runnable LMScript example using lmoci with OCI Object Storage, OCI Queue, and standard REST/CLI routing:

p = _lmcode_ cli="lmoci" install="github:lmctl-ai/lmoci@latest";
  @"/os/:bucket/:object"
  fn get_os(x: RestExchange) -> void implements RestGet {
    x.send(cloud.object_get(x.param("bucket"), x.param("object")));
  }

  @"enqueue-work"
  fn cmd_work(x: RestExchange) -> void implements CliCommand {
    let id = cloud.queue_send("lmoci-work", x.body());
    x.send("msg:" + id);
  }

  rest_config("prefix", "/v1");
  cloud.set_cost_cap_usd(0.05);
  cloud.bucket_create("lmoci-bkt");
  cloud.object_put("lmoci-bkt", "readme.txt", "hello from lmoci");
  cloud.queue_create("lmoci-work");

  let w_out = rest_cli(str_split("enqueue-work -- job-99", " "));
  let o_out = rest_cli(str_split("/v1/os/lmoci-bkt/readme.txt", " "));
  print(w_out + " | " + o_out);
end _lmcode_
r = run_lmcode(p);
assert(r.ok, "lmoci workflow failed");
