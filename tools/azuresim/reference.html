azuresim reference

Reference tables for azuresim CLI flags, environment variables, HTTP storage endpoints, client LMScript standard REST/CLI interfaces, and exit codes.

CLI commands and flags

Command or flag Default Description
azuresim --version none Print azuresim version string (for example azuresim 0.2.1) and exit 0.
azuresim --help none Print usage instructions and exit 0.
azuresim serve | start foreground Run the local Azure Blob and Queue emulator on 127.0.0.1.
--port <port> 4577 Loopback TCP port for the HTTP listener.
--data-dir <path> in-memory Directory to persist Blob and Queue state across restarts.
--auth open | enforce open Select open mode or enforced SharedKey/Bearer and storage policy validation.
--auth-config <file> unset Path to the JSON authentication and policy configuration file for enforce mode.

Environment variables

Variable Default Purpose
AZURESIM_AUTH open Set to enforce to enable SharedKey/Bearer and policy checks (overridden by --auth).
AZURESIM_AUTH_CONFIG unset Path to the JSON auth configuration file (overridden by --auth-config).
FLOCI_AZ_* loopback defaults Upstream Floci-AZ service settings (CLI flags take precedence).

HTTP service endpoints

Service Path pattern on 127.0.0.1:4577 Operations
Blob containers /devstoreaccount1/<container>?restype=container PUT (create), GET/HEAD (properties and comp=list), DELETE (delete container).
Block blobs /devstoreaccount1/<container>/<blob> PUT (upload block blob and metadata), GET (download), HEAD (properties), DELETE (remove).
Queues /devstoreaccount1-queue/<queue> PUT (create queue), GET/HEAD (metadata), DELETE (delete queue).
Queue messages /devstoreaccount1-queue/<queue>/messages POST (send XML message), GET (receive or peekonly=true), DELETE /messages/<id>?popreceipt=..., PUT /messages/<id>?popreceipt=...&visibilitytimeout=... (update visibility).

Standard lmcode_std_v3 REST and CLI interfaces (client hosts)

Interface or function Signature Purpose
RestGet .. RestOptions, RestHandler fn h(x: RestExchange) -> void implements RestGet .. RestHandler HTTP route handler interfaces in lmazure client scripts bound via @"/path/:param".
CliCommand, CliOption fn c(x: RestExchange) -> void implements CliCommand | CliOption CLI subcommand (@"cmd") and flag (@"--opt") interfaces in client scripts.
rest_config, rest_route, rest_serve, rest_stop, rest_cli rest_config(string, string) -> void; rest_route(string, string, string) -> void; rest_serve() -> void; rest_stop() -> void; rest_cli(StrList) -> string Configure and invoke REST and CLI handlers driving azuresim storage workflows.

Exit codes

Code Meaning
0 Clean server exit or --version / --help completed.
2 Invalid command-line arguments or invalid auth configuration (including --auth-config supplied in open mode).
3 Emulator startup failure.
