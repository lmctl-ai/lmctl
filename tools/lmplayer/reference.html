lmplayer reference

Reference tables for lmplayer CLI commands, flags, configuration properties, built-in agent profiles, model-facing tools, and exit codes.

CLI subcommands and flags

Command Flags and arguments Description
lmplayer [prompt] positional prompt or piped stdin Run a non-interactive prompt with default settings; bare invocation on a TTY prints help.
lmplayer run --model <provider/model>, --effort <tier>, --agent <name>, --format json, --remote-poll Execute a single prompt non-interactively or poll an outbound HTTP operator mailbox.
lmplayer serve --hostname <addr>, --port <port> Start the single-user REST service with a process-wide FIFO execution gate.
lmplayer tui optional workspace path Launch the interactive terminal user interface (sidebar hidden by default).
lmplayer config get [key], set <key> <val>, unset <key>, verify Read, mutate, or validate configuration in ~/.config/lmplayer/opencode.json.
lmplayer models --json, --test <provider>, verify <provider/model> List available models and effort tiers, probe a provider live, or verify model resolution.
lmplayer providers login, list --json Configure provider credentials or list registered providers as JSON.
lmplayer session ls --json, tail <id>, report <id>, health <id> --json, metrics <id> --json Inspect session history, health diagnostics, and session-metrics/v1 usage and cost telemetry.

Configuration keys and environment variables

Key or variable Default Purpose
compaction.mode "organize" Select durable-memory Markdown organization ("organize") or summary compaction ("summary").
permission_ask "deny" Resolve residual ask permission rules automatically in non-interactive run/serve modes ("deny" or "allow").
tool_workdir.extra_roots unrestricted (omit) or [] List of allowed external working directory roots for structured Linux tools; [] confines to workspace.
OPENCODE_CONFIG ~/.config/lmplayer/opencode.json Explicit path to a JSON/JSONC configuration file override.
OLLAMA_HOST http://localhost:11434 Ollama server origin for zero-config ollama/<model> and ollama/<model>+tools selectors.
OPENCODE_DISABLE_AUTOUPDATE, OPENCODE_DISABLE_DEFAULT_PLUGINS unset Set to true in hermetic or mock E2E test runs to prevent external network traffic.

Agent profiles and model-facing tools

Profile or tool Scope Description
default agent full coding toolset Standard coding agent with filesystem, search, bash, job, cron, and subagent task tools.
lean agent bash-only provision Short system prompt and positive provisioning restricted to the bash tool.
secured agent structured Linux tools Restricted profile using operation-checked structured tools (git, gh, rg, find, tar, unzip).
bash & job tools run / serve runtime Execute commands synchronously or with background: true; inspect via job list, get, output, stop.
cron tool in-memory session schedule Create, list, or delete 5-field cron prompt schedules (recurring or one-shot, 7-day max lifetime).

Exit codes

Code Meaning
0 Prompt execution, configuration validation, or session command succeeded.
non-zero Runtime execution failure, provider error, or failed config/model verification.
