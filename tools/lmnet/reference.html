lmnet reference

Complete command-line subcommands and flags, Net context types and methods, standard lmcode_std_v3 REST and CLI interfaces, and exit codes for lmnet v0.1.1.

Host and CLI subcommands

Command or flagArgumentsDescription
--versionnonePrint the lmnet version string and exit 0.
--lmcode-schema[--json]Print a human-readable schema summary, or exact embedded host schema JSON bytes when --json is passed.
--lmcode-signaturesnonePrint all canonical context, function, and method signatures (host + 226 standard library signatures).
--lmcode[--dry-run] <file.dslb>...Load and execute (or dry-validate without network/file effects) compiled LMScript bytecode files.
ping<host> [iputils-options]Execute the embedded upstream iputils ping engine.
tracepath<host> [iputils-options]Execute the embedded upstream iputils tracepath engine.
iperf3[iperf3-options]Execute the embedded upstream iperf 3.22 throughput client or server engine.
dns<host>Resolve host addresses via getaddrinfo and print a JSON array of IP strings.
dig<name> [TYPE] [@server]Send an RFC 1035 UDP DNS query (3 s timeout) and print {"rcode":...,"answers":[{name,type,ttl,data}]}.
ifaddrsnonePrint address-bearing network interfaces as JSON [{name,addr,mtu,up,loopback}].
linknoneDump all link devices and 64-bit RX/TX counters over rtnetlink as JSON.
routenoneDump IPv4 and IPv6 kernel routing tables over rtnetlink as JSON [{dest,via,dev,proto,scope,metric,table,prefsrc}].
rulenoneDump policy routing rules over rtnetlink as JSON [{pref,family,table,action,from,to,fwmark,iif,oif,goto_target}].
neighnoneDump ARP/NDP neighbor cache over rtnetlink as JSON [{ip,dev,state,mac,family,router,proxy}].
countersnoneDump kernel protocol counters from /proc/net/{snmp,netstat,snmp6} as a flat sorted JSON object.
sockets[tcp|udp|unix] [--listen] [--summary]Dump /proc/net socket tables with PID/process attribution as JSON, or ss-style aggregate counts with --summary.
trace<host> [maxttl]Run an IPv4 UDP/ICMP traceroute (default 30 hops) and print {"dest_ip":...,"hops":[{ttl,from,rtt_ms,reached}]}.
scan<host> [--ports SPEC] [--timeout MS] [--concurrency N]Run a parallel TCP connect port scan (default top-15 ports, 750 ms timeout, 64 workers) and print JSON verdicts.
pipe<host> <port> | --listen <port> [--forever]Stream raw bytes between stdin/stdout and a TCP connection or listening port.

Route / RouteListr.dest() | r.via() | r.dev() | r.proto() | r.scope() | r.table() | r.prefsrc() -> string | r.metric() -> intInspect kernel routing table entry attributes (RouteList supports len() and at(int)).

Exit codes

Exit codeCategoryMeaning
0SuccessCLI diagnostic command, dry-run check, or _lmcode_ program succeeded and all assertions passed.
1Operation errorDirect CLI network operation failed (resolution error, unreachable endpoint, or insufficient raw socket privileges).
2Usage errorInvalid CLI flag, malformed port range or argument, retired flag name, or invocation metadata mismatch.
3Host / load errorBytecode format error, schema hash mismatch, or unhandled runtime error (such as socket bind/connect failure).
4Contract failureAn assertion (assert, assert_eq) or result schema contract failed during script execution.
