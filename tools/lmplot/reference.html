lmplot reference

Complete CLI flags, gnuplot passthrough usage, Plot schema methods, built-in terminals, standard lmcode_std_v3 catalog, and exit codes for lmplot.

CLI commands, flags, and environment variables

Command, flag, or variableArgumentsDescription
lmplot --versionnonePrint lmplot X.Y.Z and exit 0.
lmplot --noticesnonePrint gnuplot, DejaVu font, stb_truetype, stb_image, and runtime license notices.
lmplot --lmcode-schema[--json]Print the embedded JSON schema for the lmplot host (identical bytes with or without --json).
lmplot --lmcode-signaturesnonePrint canonical context, function, and method signatures registered in the host.
lmplot --lmcodeFILE [--lmcode FILE ...]Load and execute one or more compiled LMScript bytecode files in a shared gnuplot session.
lmplot gnuplot[gnuplot-options] [file.gp ...]Run the full headless gnuplot command-line interface (such as -e "commands" or script files).
LMPLOT_MAX_MEMORY_MBinteger (default 4096)Maximum total memory budget in MiB for gnuplot datablocks, arrays, voxel grids, and the PNG canvas.

Host schema methods (context plot: Plot)

Type / contextMethod signatureDescription
context plot: Plotplot.cmd(string) -> voidExecute a single gnuplot command line (semicolon-separated statements are supported).
Plotplot.script(string) -> voidWrite multi-line gnuplot text to a temporary file and execute it via load (supports inline datablocks and structured blocks).
Plotplot.load(string) -> voidExecute a gnuplot script file from disk (load "path").
Plotplot.data(string, string) -> voidDefine the in-memory gnuplot datablock $name (pass name without the leading $; must start with a letter).
Plotplot.png(string, int, int) -> voidSelect the deterministic built-in PNG terminal at width x height pixels and open the output file.
Plotplot.svg(string, int, int) -> voidSelect the SVG terminal at width x height pixels and open the output file.
Plotplot.close() -> voidRun set output to flush and close the current output file.
Plotplot.num(string) -> floatEvaluate a gnuplot numeric expression and return its float value (complex or array values fail with exit code 3; NaN returns NaN).
Plotplot.str(string) -> stringEvaluate a gnuplot expression and return its string value (numbers are formatted with %.15g).
Plotplot.terminals() -> stringReturn the space-separated list of built-in gnuplot terminals (GPVAL_TERMINALS).
Plotplot.echo(string) -> voidPrint a line to stdout.
Plotplot.version() -> stringReturn the lmplot version string (lmplot X.Y.Z).
Plotplot.assert_close(float, float, float) -> voidAssert |actual - expected| <= tol for finite numbers and non-negative tol; fails with exit code 3 on violation.

Exit codes

Exit codePhaseMeaning
0successPlotting script, expression evaluation, and assertions succeeded.
2cliInvalid CLI flags, retired flag (--first, --last, --dry-run), or malformed invocation manifest metadata.
3load / runBytecode load error, gnuplot command error (gnuplot: <GPVAL_ERRMSG>), failed assert_close, output write error, or exceeded LMPLOT_MAX_MEMORY_MB.
4appApplication failure or inability to write the terminal LMCODE_RETURN result frame.
