lmprobe

lmprobe is a one-shot, AST-aware structural code-search CLI and 63-operation lmcode host for symbol graphs, Git history, secret scans, and guarded edits.

Quick reference

npm install -g @lmctl-ai/lmprobe
lmprobe --version
lmprobe --lmcode-schema --json
lmprobe --lmcode-signatures
lmprobe find "\.rs$" . --json
lmprobe git status --json
ItemKindPurpose

git / history / secrets / awsCLI commandsRead-only Git records, commit churn/co-change history, secret scanning, and AWS queries.
