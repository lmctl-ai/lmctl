# lmctl disaster recovery

Retired compatibility page\. This URL remains available for existing links\.

The historical automatic file\-replay workflow is retired\. Preserve available copies and recover project files from version control or backups; no replay command is promised here\. Use `lmctl export --help` for supported transcript export, and [advanced administration](</skills/lmctl-team-lead-advanced-skill.md>) for deliberately replacing a session\.
