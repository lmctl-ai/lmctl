awssim reference

Reference tables for awssim CLI commands and flags, environment variables, enforced S3/DynamoDB/SQS operations, client LMScript standard REST/CLI interfaces, and exit codes.

CLI commands and flags

Command or flag Default Description
awssim --version none Print awssim version string and exit 0.
awssim --help, -h none Print command usage and options and exit 0.
awssim serve | start foreground Start the local AWS emulator on 127.0.0.1.
--port <port> 4566 TCP port on 127.0.0.1 for the HTTP listener.
--data-dir <dir> in-memory Directory for persistent S3, DynamoDB, and SQS state across restarts.
--auth open | enforce open Select permissive open mode or enforced SigV4 and IAM policy evaluation.
--auth-config <path> unset Path to the JSON credentials and IAM policy file required when --auth enforce is set.

Environment variables

Variable Default Purpose
SIM_AUTH open Set to enforce to enable SigV4 and IAM policy checks (overridden by --auth).
SIM_AUTH_CONFIG unset Path to the JSON auth configuration file (overridden by --auth-config).
FLOCI_SERVICES_EC2_ENABLED false Opt into upstream EC2 emulation (which binds an extra IMDS listener on port 9169).
FLOCI_DOCKER_RESOURCE_NAMESPACE awssim Docker container/resource namespace tag to avoid colliding with stock Floci deployments.

Enforced AWS service operations

Service Supported operations in --auth enforce mode Resource ARN pattern
S3 CreateBucket, DeleteBucket, ListBuckets, ListObjects/ListObjectsV2, HeadBucket, HeadObject, GetObject, PutObject, DeleteObject, GetBucketLocation, Get/Put/DeleteBucketTagging arn:aws:s3:::<bucket> and arn:aws:s3:::<bucket>/<key>
DynamoDB CreateTable, DescribeTable, DeleteTable, ListTables, PutItem, GetItem, DeleteItem, UpdateItem, Query, Scan, TagResource, UntagResource, ListTagsOfResource arn:aws:dynamodb:<region>:000000000000:table/<table>
SQS CreateQueue, DeleteQueue, GetQueueUrl, ListQueues, GetQueueAttributes, SetQueueAttributes, SendMessage, ReceiveMessage, DeleteMessage, ChangeMessageVisibility, PurgeQueue, TagQueue, UntagQueue, ListQueueTags arn:aws:sqs:<region>:000000000000:<queue>

Standard lmcode_std_v3 REST and CLI interfaces (client hosts)

Interface or function Signature Purpose
RestGet .. RestOptions, RestHandler fn h(x: RestExchange) -> void implements RestGet .. RestHandler HTTP route handlers in lmaws/lmcloud client programs annotated with @"/path/:param".
CliCommand, CliOption fn c(x: RestExchange) -> void implements CliCommand | CliOption CLI subcommand (@"cmd") and flag (@"--opt") interfaces in client programs.
rest_config, rest_route, rest_serve, rest_stop, rest_cli rest_config(string, string) -> void; rest_route(string, string, string) -> void; rest_serve() -> void; rest_stop() -> void; rest_cli(StrList) -> string Configure and invoke REST and CLI handlers driving awssim workflows.

Exit codes

Code Meaning
0 Clean shutdown or --version / --help printed.
2 Invalid CLI arguments or missing/malformed --auth-config file.
3 Server startup failure (such as bind address or port already in use).
