lmcloud reference

Reference tables for the shared lmcloud CLI contract, ErrorCode enumeration, Cloud context methods, result types, standard lmcode_std_v3 REST and CLI signatures, and process exit codes.

Host CLI flags

Flag or argument Description
[cloud] --version, -V Print the host binary name and semantic version string.
[cloud] --help, -h Print usage, endpoint precedence, live safety gates, and simulator environment variables.
[cloud] --notices Print embedded third-party software license notices.
[cloud] --lmcode-schema [--json] Emit the raw embedded schema/lmcloud.dsl.json bytes used by lmscript for SHA-256 schema binding.
[cloud] --lmcode-signatures Print all sorted canonical signatures (shared lmcloud host signatures plus 226 lmcode_std_v3 standard signatures).
[cloud] --lmcode-signatures --without-std Print only the shared lmcloud host signatures without standard library declarations.
[cloud] [--lmcode|--first|--last] FILE ... Execute one or more compiled .dslb bytecode files under the validated invocation manifest.
--sweep Host-provided extra flag (registered by a provider host, not by hostkit itself) to inspect or clean up run-owned resources recorded in durable recovery journals.

ErrorCode enumeration and CloudError methods

Member Signature or value Description
ErrorCode OK, INVALID_ARGUMENT, NOT_FOUND, CONFLICT, PRECONDITION_FAILED, UNAUTHENTICATED, PERMISSION_DENIED, COST_CAP_EXCEEDED, INTERNAL Normalized cross-provider status codes returned by CloudError.code().
CloudError.ok ok() -> bool True when the last operation succeeded (ErrorCode.OK).
CloudError.code code() -> ErrorCode Normalized ErrorCode value for the failure.
CloudError.http_status http_status() -> int Underlying HTTP status code (such as 400, 401, 403, 404, 409, 412, or 500), or 0 for local validation failures.
CloudError.provider_code provider_code() -> string Original provider or simulator error code string (such as NoSuchBucket, BlobNotFound, or NotAuthorizedOrNotFound).
CloudError.message message() -> string Secret-redacted diagnostic message.

Standard lmcode_std_v3 REST and CLI interfaces

Interface or function Signature Description
RestGet .. RestOptions, RestHandler fn handler(x: RestExchange) -> void implements RestGet | RestPost | RestPut | RestDelete | RestPatch | RestHead | RestOptions | RestHandler SAM interfaces for HTTP route handlers annotated with @"/route/:param".
CliCommand, CliOption fn cmd(x: RestExchange) -> void implements CliCommand | CliOption SAM interfaces for CLI subcommands (@"cmd") and options (@"--flag").
rest_config fn rest_config(key: string, value: string) -> void Configure REST/CLI dispatcher settings such as route prefix, host, or port.
rest_route fn rest_route(method: string, pattern: string, handler: string) -> void Register an HTTP method and URL pattern with a named handler function.
rest_serve, rest_stop fn rest_serve() -> void; fn rest_stop() -> void Start or stop the embedded HTTP server for registered routes.
rest_cli fn rest_cli(args: StrList) -> string Dispatch CLI arguments or synthetic route paths in-process and return the response string.
RestExchange method(), path(), body(), param(name), query(name), header(name), get(key), set(key, val), has_query(name), has_header(name), increment(key), status(code), send(text), json(payload), set_header(name, val) Request and response exchange methods available inside REST and CLI handlers.

Exit codes

Exit code Category Meaning
0 OK Command or bytecode execution succeeded and all assertions passed.
2 CLI_USAGE Invalid command-line flags, malformed invocation manifest, or invalid memory budget environment variable.
3 APP_FAIL / RUN_HOST Runtime cloud error (when abort_on_error is true), cost cap breach, assertion failure, or memory ceiling exceeded.
4 LOAD_FAIL Bytecode file read error, schema hash mismatch, or result contract decoding error.
