lmhtml recipes

Each recipe uses the synthetic pages under the tutorial scratch directory. Compile from the directory containing schema-lmhtml.json; the snippets save reports and outputs below build/ or output/.

Check broken links on a site

Walk each page and each link. Skip external, special and outside-root targets by policy, and ignore a generated noise pattern.

npx --yes --package=@lmctl-ai/lmctl -- lmscript build/check-links.lms
(no output; exit 0)
lmhtml --dsl build/check-links.dslb
{"ok": true, "result": null}
cat build/links.txt
broken-link site/index.html:0: missing.html not found

Find class and ID typos

Compare classes used in markup to CSS selectors and flag selectors that do not match a used ID. Suggestions help locate one-character spelling mistakes.

npx --yes --package=@lmctl-ai/lmctl -- lmscript build/check-classes.lms
(no output; exit 0)
lmhtml --dsl build/check-classes.dslb
{"ok": true, "result": null}
cat build/classes.txt
class-undefined site:0: heding (did you mean heading?)
id-unused site:0: teem (did you mean team?)

Diff two pages

Compare before and after snapshots. The host reports a changed paragraph and a newly added paragraph, ignoring incidental markup noise.

npx --yes --package=@lmctl-ai/lmctl -- lmscript build/diff.lms
(no output; exit 0)
lmhtml --dsl build/diff.dslb
{"ok": true, "result": null}
cat build/diff.txt
diff-changed compare/before/page.html:0: html > body:nth-child(2) > p.intro:nth-child(2): text differs
diff-added compare/after/page.html:0: html > body:nth-child(2) > p:nth-child(3)
summary page:0: 2 differences

Change a shared header or footer across pages

Apply one navigation and footer fragment to copies of all four pages. The source files remain untouched.

(no output; exit 0)

{"ok": true, "result": null}

Ignore generated noise with link_kind and str_match

Link checks should state what is deliberately outside scope. This version ignores external/special/outside-root targets and a synthetic noise-*.html pattern, while still reporting a missing local page.

npx --yes --package=@lmctl-ai/lmctl -- lmscript build/check-links.lms
(no output; exit 0)
lmhtml --dsl build/check-links.dslb
