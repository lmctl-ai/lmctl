lmazure

lmazure is the Azure scripting host for LMScript, providing the shared lmcloud procedural schema and a 72-example Azure metadata and owned-resource suite.

Quick reference

Bind lmazure in an LMScript program or run the binary directly against its in-process fake adapter, the local azuresim emulator on 127.0.0.1:4577, or Azure metadata APIs.

lmazure --version
lmazure --lmcode-schema --json
lmazure --lmcode-signatures
lmazure --sweep
p = _lmcode_ cli="lmazure" install="github:lmctl-ai/lmazure@latest";
Surface Command or method Purpose
Shared cloud context context cloud: Cloud Provider-neutral Azure Blob object storage, Queue Storage, tables, permissions, serverless functions, user directories, cost caps, and metrics.
Azure metadata session mock(), live(), session.inventory(kind), session.find_prefix(prefix), session.begin_run(path) Inspect 12 Azure ARM metadata domains, filter resources by prefix, and run ledger-guarded container and queue lifecycles.
Emulator endpoint cloud.set_endpoint("all", "http://127.0.0.1:4577") Target a local azuresim instance over loopback HTTP using devstoreaccount1 SharedKey or Bearer token credentials.
Standard REST and CLI rest_config, rest_route, rest_serve, rest_stop, rest_cli Expose Azure storage and queue workflows as HTTP endpoints (:param patterns) and CLI commands via lmcode_std_v3 interfaces.

Runnable LMScript example using lmazure with Azure Blob containers, Queue Storage, and standard REST/CLI dispatch:

p = _lmcode_ cli="lmazure" install="github:lmctl-ai/lmazure@latest";
  @"/blobs/:container/:blob"
  fn get_blob(x: RestExchange) -> void implements RestGet {
    x.send(cloud.object_get(x.param("container"), x.param("blob")));
  }

  @"push-job"
  fn cmd_push(x: RestExchange) -> void implements CliCommand {
    let id = cloud.queue_send("azure-jobs", x.body());
    x.send("queued:" + id);
  }

  rest_config("prefix", "/v1");
  cloud.set_cost_cap_usd(0.05);
  cloud.bucket_create("demo-container");
  cloud.object_put("demo-container", "hello.txt", "hello from lmazure");
  cloud.queue_create("azure-jobs");

  let q_out = rest_cli(str_split("push-job -- task-42", " "));
  let b_out = rest_cli(str_split("/v1/blobs/demo-container/hello.txt", " "));
  print(q_out + " | " + b_out);
end _lmcode_
r = run_lmcode(p);
assert(r.ok, "lmazure workflow failed");
