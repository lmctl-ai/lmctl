Get started with lmhtml

Use lmctl 0.2.378 or newer to run a provider-session task, inspect the generated files, and report the checks that passed. Confirm that lmctl help autorun is available before running the team scripts.

Getting started

The solo script asks one Lead to audit a small HTML site. It starts a tracked provider session; the assigned agent uses lmscript to install and run the released lmhtml host.

lmctl autorun https://lmctl.com/tools/lmhtml/lmhtml_solo.lms

Run with a Coder and Reviewer

The trio script passes the Lead's assignment to a Coder, sends the Coder's result to a Reviewer, and returns both responses to the Lead for a final report.

lmctl autorun https://lmctl.com/tools/lmhtml/lmhtml_trio.lms

Try one example

Run the broken-link audit directly to see one task and its expected report.

lmctl quickrun https://lmctl.com/tools/lmhtml/examples/check-links.lms

See the example book for the other lmhtml tasks and their quickrun sources.
