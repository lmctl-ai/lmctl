lmsaml

lmsaml is a single-binary SAML 2.0 Identity Provider, Service Provider, REST API server, and LMScript host built in pure Go. It generates RSA-2048 X.509 certificates, serves SAML 2.0 SSO/SLO and metadata endpoints, signs and verifies XML assertions, and runs _lmcode_ scripts.

Quick reference

npm install -g @lmctl-ai/lmctl@latest
lmsaml --version
lmsaml --lmcode-schema --json
lmsaml --lmcode-signatures

p = _lmcode_ cli="lmsaml" install="github:lmctl-ai/lmsaml@latest";
assert_eq(saml.ping(), "PONG");
assert_eq(saml.add_user("alice", "{\"email\":\"alice@example.com\",\"password\":\"secret123\"}"), true);
assert_eq(saml.authenticate("alice", "secret123"), true);

let issued = json_parse(saml.issue_assertion("alice", ""));
let verified = json_parse(saml.verify_assertion(issued.get("saml_response_b64").as_string()));
assert_eq(verified.get("valid").as_bool(), true);
