lmblender examples

lmblender runs lmscript scenes through a standalone CPU Cycles renderer and writes stills, sequences, and exports. Browse example previews and run each source as an autorun script. These pages are regenerated from the public lmblender repository at 302c526fad.

Start with get started to learn how solo and trio provider runs work.

  • Backlit Skin: Layer skin-like translucent shading, a rim light, and a dark studio backdrop. Autorun source
  • Bouncing Ball Strobe: Show a bouncing sphere at successive positions in a single strobe-style scene. Autorun source
  • Caffeine Molecule: Build and label a caffeine molecule from spheres, bonds, and color-coded atoms. Autorun source
  • Caustic Ball Lens: Render a glass sphere and lens with reflected caustic light on a floor. Autorun source
  • Cornell Box: Compare colored walls, a ceiling light, and two objects in a Cornell box. Autorun source
  • Dna Double Helix: Build a paired DNA helix with colored rails, rungs, and atom-like details. Autorun source
  • Gear Pair Render: Render interlocking gears with a machined metal finish and studio lighting. Autorun source
  • God Rays Window: Use a window, volumetric haze, and a directional light to reveal visible rays. Autorun source
  • Kepler Orbit: Stage a miniature planetary orbit and render one frame of its animation. Autorun source
  • Salt Crystal: Create a translucent salt crystal with faceted geometry and controlled highlights. Autorun source
  • Saturn Rings: Build a ringed planet with layered bands and a dark space background. Autorun source
  • Sunset Long Shadows: Use a low warm sun to cast long shadows across a simple landscape. Autorun source
