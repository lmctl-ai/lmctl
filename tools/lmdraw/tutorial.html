Render scenes and animation with lmdraw

These commands were run from the lmdraw source root with lmdraw v0.1.0 and lmscript 0.2.359. The SVG example uses the bundled homepage automation-ladder drawing. Paths are shown relative to that root.

1. Compile a title card

Compile the included title-card program against the schema path embedded in the script.

lmscript examples/title-card.lms build/title-card.dslb
wrote build/title-card.dslb

2. Render and inspect the still

The host writes PNG output below build/rendered/ and prints a success result.

./build/lmdraw --dsl build/title-card.dslb
{"ok": true, "result": null}
file build/rendered/title-card.png
build/rendered/title-card.png: PNG image data, 960 x 540, 8-bit/color RGBA, non-interlaced

3. Load an SVG and change an attribute

The included example loads the bundled homepage automation-ladder SVG fixture by id, changes opacity on the retained handle, and renders it. It also demonstrates loading multiple SVG assets in one program.

lmscript examples/render-assets.lms build/render-assets.dslb
wrote six SVG renders
./build/lmdraw --dsl build/render-assets.dslb
{"ok": true, "result": null}
file build/rendered/svg-automation-ladder.png
build/rendered/svg-automation-ladder.png: PNG image data, 960 x 360, 8-bit/color RGBA, non-interlaced

4. Render a 24-frame tween

The animation script updates an SVG opacity and a marker position in a range loop. It writes 24 numbered PNG frames.

lmscript examples/animated-ladder.lms build/animated-ladder.dslb
wrote 24 deterministic numbered frames
./build/lmdraw --dsl build/animated-ladder.dslb
wrote 24 deterministic numbered frames
ls build/rendered/ladder-*.png | wc -l
24

5. Encode the frames as MP4

ffmpeg combines the numbered PNGs into a one-second H.264 video at 24 frames per second. ffprobe confirms its codec and dimensions.

ffmpeg -hide_banner -loglevel error -framerate 24 -start_number 0 -i 'build/rendered/ladder-%d.png' -frames:v 24 -c:v libx264 -pix_fmt yuv420p -movflags +faststart -y build/animated-ladder.mp4
(no output; exit 0)
ffprobe -v error -select_streams v:0 -show_entries stream=codec_name,width,height,r_frame_rate -show_entries format=duration -of default=noprint_wrappers=1 build/animated-ladder.mp4
codec_name=h264
width=640
height=240
r_frame_rate=24/1
duration=1.000000

To run these commands with a release install, replace ./build/lmdraw with the path to the downloaded lmdraw executable. The example scripts and generated frames remain the same.

What you learned

Compile each scene against lmdraw's embedded schema, run the bytecode with the host, inspect the generated PNG, and use a deterministic numbered sequence as input to ffmpeg.

Source and releases: github.com/lmctl-ai/lmdraw.
