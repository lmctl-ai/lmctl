provider-mock-e2e

provider-mock-e2e runs unmodified coding agent CLIs installed by lminstall against a checksum-verified loopback lmmock server with zero vendor credentials.

Quick reference

Prepare the verified lmmock loopback fixture, run the end-to-end probe for any of the 13 qualified coding agent CLIs in an isolated temporary HOME, and verify the exact reply and request audit.

npm install --prefix /tmp/compiler --no-audit --no-fund @lmctl-ai/lmctl@0.2.448
export LMSCRIPT_JS=/tmp/compiler/node_modules/@lmctl-ai/lmctl/bin/lmscript
python3 scripts/prepare.py
python3 scripts/run.py claude --settings /tmp/provider-mock-tools/settings.json --out build/claude-result
python3 scripts/run.py miniplayer --settings /tmp/provider-mock-tools/settings.json --out build/miniplayer-result
python3 scripts/run.py lmplayer --settings /tmp/provider-mock-tools/settings.json --out build/lmplayer-result
