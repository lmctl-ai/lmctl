lmssh reference

Complete command-line flag reference, embedded OpenSSH client subcommands, host schema contexts and methods, standard lmcode_std_v3 REST and CLI interfaces, and exit codes for lmssh v0.1.1 (bundling OpenSSH 10.6p1).

Host and CLI flags

Flag or commandArgumentsDescription
--versionnonePrint the lmssh version string (lmssh 0.1.1) and exit 0.
--lmcode<file.dslb>... [-- args...]Load and execute one or more compiled LMScript bytecode files; arguments after -- are exposed via io.args().
--dry-run--lmcode <file.dslb>Print every ssh, sftp, scp, and ssh-keygen command to stderr as [dry-run] without spawning processes or modifying local files.
--lmcode-schema[--json]Print a human-readable schema signature summary, or exact embedded schema JSON bytes when --json is passed.
--lmcode-signaturesnonePrint all 334 canonical context, function, and method signatures (108 host + 226 standard library).
ssh[openssh-args...]Run the embedded OpenSSH 10.6p1 ssh client (also invoked when argv[0] is ssh or argv[1] starts with a single -).
sftp[openssh-args...]Run the embedded OpenSSH 10.6p1 sftp client using the lmssh binary as its underlying ssh transport.
scp[openssh-args...]Run the embedded OpenSSH 10.6p1 scp client using the lmssh binary as its underlying ssh transport.
ssh-keygen / keygen[openssh-args...]Run the embedded OpenSSH 10.6p1 ssh-keygen utility.

Exit codes

Exit codeCategoryMeaning
0SuccessBytecode program or introspection command succeeded and all assertions passed.
2Usage errorInvalid command-line flag, missing --lmcode file argument, or malformed invocation.
3Load / host run errorBytecode corrupt, schema hash mismatch, unbound import, or runtime host error (RUN_HOST).
4Application verdictScript explicitly failed via io.fail(msg), report.fail_if_any(), or an assertion failure (APP_FAIL).
0..255Direct OpenSSH modeWhen invoked as lmssh ssh|sftp|scp|ssh-keygen, returns the exact exit code of the OpenSSH client tool.
