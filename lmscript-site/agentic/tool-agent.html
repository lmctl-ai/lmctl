Tool agent

The model asks for built-in read-only tool calls in JSON; the script runs them and feeds the results back.

tool_specs lists the tools the grants allow; with no write or web grant that is list_files and read_file, and their JSON schemas go into the system prompt. The model may reply with one JSON object naming a tool and its arguments. tool_parse extracts it, also from a fenced or chatty reply, and tool_call runs it inside the workspace root. Every tool result, including a refused or invalid call, comes back as data in the next TOOL_RESULT message with the conversation history. The loop stops at the first plain-text answer or after five tool steps, and an empty reply is an error. Tool calls are traced on standard error.

What it maps to

Tools: the built-in tool_specs, tool_parse and tool_call with a JSON text protocol instead of provider tool calling, so it also works with small models. Permissions: the script grants root, write and web; the model cannot widen them. Short-term memory: the history option carries the conversation. See the concept map.

Script: tool-agent.lms

# Tool agent: the model calls built-in read-only tools by replying with JSON; the script runs them and feeds back results.
import "agentic.lms";
write_file("notes.txt", "Release 0.3 ships the agentic recipes.\nRelease 0.4 adds embeddings.\n");
analyst = agent("file analyst", "answer questions about files in the current directory");
question = ARGV.get(0, "Which release adds embeddings? Check notes.txt.");
grants = {root: ".", write: false, web: false};
prompt_system = system_for(analyst) + "\nTo use a tool, reply with ONLY one JSON object {\"tool\": NAME, \"args\": {...}} and no other text." +
  " Each result comes back as a TOOL_RESULT message. Answer in plain text when you are done.\nTools: " + json_stringify(tool_specs(grants));
history = [];
message = question;
for (step in range(0, 5)) {
  r = llm_prompt(analyst.model, message, {system: prompt_system, history: history, temperature: 0, max_tokens: 1000, retries: 2});
  if (r.dry_run) { exit(0); }
  if (!r.ok) {
    error(f"model call failed: {r.error.code}");
    exit(1);
  }
  trace(analyst.role, r);
  if (trim(r.text) == "") {
    error(f"model returned an empty reply (finish_reason={r.finish_reason})");
    exit(1);
  }
  push(history, {role: "user", content: message}, {role: "assistant", content: r.text});
  call = tool_parse(r.text);
  if (!call.ok) {
    println(trim(r.text));
    exit(0);
  }
  res = tool_call(call.name, call.args, grants);
  warning(f"[tool] {call.name} {json_stringify(call.args)} ok={res.ok}");
  message = f"TOOL_RESULT {call.name}\n{res.text}";
}
error("no final answer after 5 tool steps");
exit(1);
