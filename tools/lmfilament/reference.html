lmfilament reference

Every signature on this page was read from the output of lmfilament --lmcode-signatures and --lmcode-schema --json of the released lmfilament 0.3.21, which embeds Filament 1.78.1. Notes describe only what the repository README and examples state.

Standard library (lmcode_std_v3)

lmfilament 0.3.21 ships 206 standard signatures: 83 function signatures and 123 method signatures on 16 standard types. They need no import and are callable in any lmfilament block next to the fil context. The result sink functions fill the result field of the run_lmcode envelope.

Standard REST and CLI interfaces (current catalog, not yet in this host)

The current lmcode_std_v3 catalog in lmcode-cpp has 226 canonical signatures. The 20 signatures beyond the 206 that lmfilament vendors are the former lmcode_std_rest_v1 module: 5 functions and 15 RestExchange methods, together with 10 standard interfaces. lmfilament does not ship them yet; it picks them up when it syncs its lmcode-cpp SDK and publishes a release. Until then a lmfilament program that calls rest_route or declares a RestGet handler does not compile against the lmfilament schema.
