lmsearch reference

CLI subcommands, filter flags, domain types, SAM callback interfaces, standard REST and CLI interfaces, and exit codes for lmsearch.

CLI subcommands and options

Subcommand or flagDescription
lmsearch index <PATHS...> --output FILE.faiss [OPTIONS]Embed and index files or directories into a persistent FAISS index file.
lmsearch search --index FILE.faiss --query TEXT [-k K] [OPTIONS]Search a saved FAISS index with CLI metadata filters and optional --lmcode rules.
lmsearch serve <PATHS...> [--port P] [--timeout S] [--weights-only-cache]Start the single-user lazy in-memory REST server with auto-shutdown on idle timeout.
lmsearch client [--port P | --url URL] query|filter|requery|status|shutdown ...Drive a running lmsearch serve instance from the command line.
lmsearch run --program FILE.dslb [--dryrun] [--readonly]Execute or dry-validate a compiled DSLB v6 program via the cli.schema.v1 contract.
--ext / --path-prefix / --path-contains / --exclude-path / --contains / --fieldCommon file extension, path, substring, and key=value metadata filters.
--min-score / --max-distance / --min-size / --max-sizeNumeric score, distance, and file byte-size range filters.
--version / --schema [--json] / --lmcode-schema [--json] / --lmcode-signaturesInspect build version, CLI schema, embedded lmsearch.dsl.json schema, or the canonical signature list.

SAM callback interfaces and standard REST/CLI interfaces

InterfaceAnnotationSignatureRole
EmbeddingTransform@embed(vec: FloatList, dim: int) -> FloatListPost-process ONNX embeddings before indexing or search.
IndexPolicy@policy(plan: AutoPlan) -> stringSelect or override the AutoFaiss index factory key.
AuditRule@audit(metrics: IndexMetrics) -> voidValidate recall, latency, or compression metrics after evaluation.
FileFilter@file_filter(doc: Document) -> boolGate file ingestion and enrich document metadata before embedding.
IgnoreRule@ignore(doc: Document) -> boolPrune files or directory subtrees during traversal.
SearchConfig@config(index: FaissIndex) -> voidConfigure index parameters, filters, and callbacks programmatically.
VectorFilter@filter(id: int, doc: Document) -> boolProgrammable faiss::IDSelector predicate evaluated during FAISS search.
Reranker@rerank(hit: SearchHit, query_text: string) -> floatRescore candidate FAISS hits using document fields and query text.
RestGet..RestOptions, RestHandler, CliCommand, CliOption@"/path/:param" / @"cmd" / @"--opt"(exchange: RestExchange) -> voidStandard lmcode_std_v3 REST and stateless CLI interfaces.

Exit codes

CodeMeaning
0Indexing, search, REST server/client command, or bytecode execution succeeded.
3CLI usage error (CLI_USAGE envelope), bytecode load error, schema mismatch, ONNX model check failure, failed assert_true/AuditRule, or --readonly policy refusal.
