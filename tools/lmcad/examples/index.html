lmcad examples

lmcad is a native solid-modeling host for lmscript with rendering and CAD export. Browse rendered examples and run each source as a quickrun script. These pages are regenerated from the public lmcad repository at fe18cf967b.

Start with get started to learn how solo and trio quickruns work.

  • Box Volume: Build one box, assert its volume, and render a 320 × 240 PNG. Quickrun source
  • Loop Row: Use a range loop to place seven boxes and render the result. Quickrun source
  • Still Life: Render a box, sphere, and cylinder together in one lit scene. Quickrun source
  • Mug: Revolve a profile into a hollow mug and join a curved handle. Quickrun source

Source and releases: github.com/lmctl-ai/lmcad.
