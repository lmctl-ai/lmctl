n8n

n8n is an independent, from-scratch workflow runtime for n8n-style JSON graphs built with LMScript, LMCode, and an lmcode-go HTTP host. It validates linear workflow and connector schemas, resolves whole-field JSON expressions, and executes bounded JSON POST requests tested offline with lmmock.

Quick reference

npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm run demo
npm test
./build/lmflow-host --lmcode-schema --json

input input(name: string) -> Json Load the validated workflow or connector JSON document inside the LMCode program
credential credential(id: string, field: string) -> string Look up a secret field from the external credentials JSON file without exposing it in workflow JSON

json_put json_put(obj: Json, key: string, value: Json) -> Json Return a JSON object with key set to scalar Json value (preserving string, number, or bool types)
http_post_json http_post_json(url: string, body: Json) -> HttpResponse Send a bounded 10s, 1 MiB application/json POST request with redirects disabled
workflow_fail workflow_fail(message: string) -> void Abort workflow execution with a structured run-phase error message
