lmprobe reference

CLI commands, flags, the 63 probe_* lmcode host functions, standard REST and CLI interfaces, and exit codes for lmprobe.

Exit codes

CodeMeaning
0Command, GraphQL query, edit preview/apply, or bytecode execution succeeded.
1No results matched (pass --exit-zero-on-no-match to return 0 instead).
Other non-zeroUsage, load, or runtime error; details are in the lmprobe.result.v1 error payload or on stderr.
