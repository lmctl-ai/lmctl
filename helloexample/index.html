lmctl hello examples

One minimal, single-member teamfile per provider — the connectivity check behind lmctl hello <provider> -p "...". Each is fetched, seeded, and sent your prompt in one command.

  • claude.lmctl — lmctl hello claude -p "hi"
  • codex.lmctl — lmctl hello codex -p "hi"
  • agy.lmctl — lmctl hello agy -p "hi"
  • kimi.lmctl — lmctl hello kimi -p "hi"

Looking for a real, multi-member team to try instead of a one-off check? See the template library, or read how a teamfile works.
