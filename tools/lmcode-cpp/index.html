lmcode-cpp

Overview

Experimental. lmcode-cpp is a C++17, standard-library-only header for loading, verifying and executing lmscript bytecode inside a host application.

Start with the tutorial, use the user guide for API and format details, or give the skill page to an assistant writing host bindings.

Install by copying include/dslvm.hpp into your project or pinning the SDK source commit. There is no compiled library or third-party dependency. The standard function schema is included by each Registry, so hosts do not register standard functions.
