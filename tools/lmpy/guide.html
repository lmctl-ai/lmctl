lmpy API guide

This page summarizes how LMScript programs call the lmpy host. The checked-in schema and API reference are the complete source of operation names, options and result fields.

Overview

lmpy runs compiled LMScript LMCode bytecode in a native executable. Use cli="lmpy" and install="github:lmctl-ai/lmpy@latest" to bind compilation and execution to the same released schema.

Host declaration

p = _lmcode_ cli="lmpy" install="github:lmctl-ai/lmpy@latest";
let x = mat("1 2; 3 4").solve(vec(5.0, 11.0));
out.close("known solution", x, vec(1.0, 2.0), 0.000000000001);
out.put("solution", x);
end _lmcode_

Numerical operations

The host includes dense and sparse linear algebra, probability distributions, random sampling, optimisation, least squares, roots, quadrature, differential equations, interpolation and special functions.

Data and models

Operations cover typed frames and arrays, regression and time series, signal analysis, spatial neighbours and graphs, and machine-learning estimators. File inputs are read by the native executable using the documented formats.

Errors and checks

Use out.check for boolean conditions and out.close for numeric comparisons. A failed assertion exits unsuccessfully; successful output includes the result values and check summary.
