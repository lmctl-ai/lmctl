lmplot

lmplot is gnuplot packaged as a single self-contained executable and LMScript host with embedded DejaVu fonts and a deterministic PNG/SVG rasterizer. It renders 2D and 3D plots, surfaces, contours, heat maps, fits, and dashboards without X11, Cairo, or libgd.

Quick reference

npm install -g @lmctl-ai/lmctl
lmplot --version
lmplot --lmcode-schema --json
lmplot gnuplot -e "set terminal png size 800,500; set output 'sin.png'; plot sin(x) lw 2"

Run in the browser

lmplot also builds to WebAssembly. The browser demo runs all 45 standalone examples inside the page. gnuplot, the lmcode virtual machine and the 13 Plot functions are one fixed host, lmplot.wasm (4.6 MB), written once as systems code in C and C++. Each example is application code: a few kilobytes of lmcode bytecode the page loads at run time, so a new plot never needs a new wasm build.

  • In the browser, plot.png(file, w, h) writes file.svg with gnuplot's svg terminal (LMPLOT_PNG_AS=svg). The PNG option uses lmplot's own rasterizer and fonts. 84 or 85 of the 92 example PNGs (depending on the platform the native build ran on) are byte-identical to the native binary's; the rest are 3D views that differ in a few pixels because each libm rounds sin and cos differently.
  • Each run gets a fresh WebAssembly instance in a Worker, with the example's data files in an in-memory file system. The compiled module is reused, so a typical example runs in 30 to 250 ms.
  • The examples are compiled ahead of time by lmscript, which also evaluates the lmscript code around each _lmcode_ block. Build everything from an lmplot checkout with the command below; the guide has the details.
scripts/build-web.sh build-site
