lmhtml API

Overview

lmhtml 0.7.3 is a native host for link and CSS audits, structural page diffs, shared-template extraction and safe HTML rewrites. It also converts Markdown, generates chapter indexes and builds static note sites.

Install and run

Use Node.js 24.15 or newer with the published lmscript package. A DSL declaration with cli="lmhtml" install="github:lmctl-ai/lmhtml@latest" downloads the platform release, checks its SHA-256 and compiles against its embedded schema.

lmhtml --version
lmhtml --dsl-schema
lmhtml --dsl-schema --json
lmhtml --dsl-signatures
lmscript audit.lms build/audit.dslb
lmhtml --dsl build/audit.dslb

--dsl-schema prints a summary, --dsl-schema --json prints the compiler schema bytes, and --dsl-signatures prints canonical host signatures. The full member list is available from the released binary; the following summary is copied from lmhtml 0.7.3.

Host behavior and limits

Directory loads can filter relative paths with include and exclude globs. Link checks classify local pages, assets, anchors, external URLs, special schemes and paths outside the site root; they do not fetch external URLs. Structural diffs ignore whitespace, comments, attribute order and data-* attributes. Template extraction finds shared subtrees and inserts slot markers. Saves are atomic and confined to the working directory; use --dry-run before rewriting pages.

The host accepts bytecode version 5. It has no execution budget or allocation cap, so run only trusted bytecode. HTML saves require valid UTF-8 and can normalize wrappers, tag casing, attribute quoting and optional elements.

Markdown and plain-content commands

Markdown input uses CommonMark with GFM tables, task lists, strikethrough and autolinks. Raw HTML is disabled by default. Index generation is deterministic; --check reports drift without writing. A trusted site template can use title, summary, path, content and toc placeholders.

lmhtml index notes
lmhtml index notes --check
lmhtml mdcheck notes
lmhtml site notes build/notes --template shell.html
lmhtml lint --stats --json pages
lmhtml normalize pages
lmhtml clean page.html --check
