tree-sitter-lmcode

tree-sitter-lmcode is the Tree-sitter grammar and C external scanner for the standalone lmcode language inside _lmcode_ blocks. It parses typed fn declarations, @NAME annotations, implements clauses, qw/qi/qf and %json literals, FIFO heredocs, ${...} splices, and $return assignments.

Quick reference

git clone https://github.com/lmctl-ai/tree-sitter-lmcode.git
cd tree-sitter-lmcode
npm install --prefix /tmp/ts-cli tree-sitter-cli@0.27.1
export PATH="/tmp/ts-cli/node_modules/.bin:$PATH"
tree-sitter generate && tree-sitter test --rebuild
