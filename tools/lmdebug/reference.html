lmdebug reference

Complete command-line subcommand and flag reference, domain schema contexts and methods (lmdebug, net, sys, proc, detect, shark), standard lmcode_std_v3 REST and CLI interfaces, and exit codes for lmdebug.

Exit codes

Exit codeCategoryMeaning
0SuccessCLI subcommand, dry-run plan, or _lmcode_ bytecode program succeeded and all assertions passed.
1Operation errorDirect CLI diagnostic or subcommand failed at runtime.
2Usage errorInvalid CLI argument, unknown flag, or non-integer LMDEBUG_MAX_MEMORY_MB value.
3Host / VM errorBytecode load failure, schema mismatch, unhandled VM runtime exception, or exceeding the 4096 MiB memory limit.
4Contract failureAn application assertion (assert, assert_eq) failed inside an _lmcode_ script.
5Policy refusalMutation permanently refused by safety policy (e.g., write-only sysctls vm.drop_caches or vm.compact_memory, or signaling PID 1).
6Plan driftThe fresh plan_id computed during --apply did not match the --if-match sha256:<64hex> digest.
