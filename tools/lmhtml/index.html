lmhtml

lmhtml is a native host for auditing links and CSS names, comparing HTML documents, extracting templates, applying shared-page edits, converting Markdown and producing plain content for agents. This page is the quick reference for lmhtml 0.7.6; scripts reach it through an _lmcode_ block and run_lmcode, and the native commands need only the binary.

Install and run

npm install -g @lmctl-ai/lmctl
lmscript --check audit.lms
lmscript audit.lms
lmhtml --version
lmhtml --lmcode-signatures

A block that declares cli="lmhtml" install="github:lmctl-ai/lmhtml@latest" lets lmscript download the release binary and compile against its embedded schema.

Minimal example

p = _lmcode_ cli="lmhtml" install="github:lmctl-ai/lmhtml@latest";
let d = html.parse("<main><h1 id=\"top\">Hello</h1><a href=\"#top\">Top</a></main>");
let h = d.select("h1");
$return.title = h.at(0).text();
$return.links = d.links().len();
end _lmcode_
r = run_lmcode(p);
require(r.ok, json_stringify(r));
println(json_stringify(r));
lmscript audit.lms
{"ok":true,"result":{"title":"Hello","links":1}}

Host protocol and native commands

CommandEffect
lmhtml --versionPrint the version.
lmhtml --lmcode-schema [--json]Print the schema summary, or the compiler schema JSON.
lmhtml --lmcode-signaturesPrint all 305 canonical signatures: host API plus the 226-signature lmcode_std_v3 catalog.
lmhtml [--dry-run] --lmcode FILE [FILE ...]Run compiled program files; this is what run_lmcode calls.
lmhtml md2html IN.md [OUT.html] [--template FILE] [--allow-html]Markdown to HTML.
lmhtml index DIR [--order FILE] [--check]Generate or check DIR/index.md.
lmhtml mdcheck DIRCheck Markdown notes and their links.
lmhtml site DIR OUT [--template FILE]Build a static note site.
lmhtml lint [--stats] [--json] [--config FILE] [--compare BEFORE] PATHSCount plain-content violations.
lmhtml normalize [--check] PATHSRewrite pages as plain content.
lmhtml clean URL-or-file [--base URL] [--markdown] [--check]Extract main content for agents.

Exit codes: 0 success, 2 usage, 3 load or runtime error, 4 application failure.
