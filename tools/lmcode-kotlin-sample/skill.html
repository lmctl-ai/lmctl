lmcode-kotlin-sample skill

Use lmcode-kotlin-sample as a verified blueprint for embedding lmcode-java (vendor/lmcode-java) in a Kotlin (JDK 21) host application with schema discovery, R49 rule entries, dry mode, and LMCODE_RETURN framing.

Purpose

Demonstrate a complete, byte-pinned Kotlin (JDK 21) host application that exposes a 45-signature Shop/Ledger domain to DSLB v6 bytecode and passes the shared sample suite.

When to use it

Use lmcode-kotlin-sample when learning how to bind Kotlin (JDK 21) domain objects, overloaded methods, operators, R49 rule entries, and LMCODE_RETURN result envelopes with lmcode-java (vendor/lmcode-java).

Install

Clone lmctl-ai/lmcode-kotlin-sample and run ./test.sh with Kotlin (JDK 21), Python 3, Node 24.15 or later, and @lmctl-ai/lmctl 0.2.444 or later.

Commands

git clone https://github.com/lmctl-ai/lmcode-kotlin-sample.git
cd lmcode-kotlin-sample
python3 scripts/sync.py check
mvn package -DskipTests
./test.sh
./bin/lmcode-kotlin-sample --version
./bin/lmcode-kotlin-sample --lmcode-schema --json
./bin/lmcode-kotlin-sample --lmcode-signatures
./bin/lmcode-kotlin-sample --lmcode sample-suite/bytecode/001-literals.dslb

Inputs and outputs

  • Input: compiled .dslb v6 bytecode files from sample-suite/bytecode/, embedded sample.dsl.json schema, and optional LMCODE_INVOCATION_FILE manifest.
  • Output: print trace lines, entry NAME = VALUE lines, tagged host_summary JSON diagnostic, and terminal LMCODE_RETURN_BEGIN / END frame.
  • Locks: sdk.lock and suite.lock pinning every vendored SDK and corpus byte by commit SHA and SHA-256.

Safety rules

  • Verify sdk.lock and suite.lock before building so vendored SDK and corpus files never drift silently.
  • Preserve raw byte strings across Ledger.note and JSON diagnostics without lossy UTF-8 replacement.
  • Check LMCODE_INVOCATION_FILE dry mode before seeding or mutating external state so dry runs remain side-effect-free.

Worked examples

schema = load_schema(schema="sample-suite/sample.dsl.json");
program = _lmcode_ schema;
  ledger.record(shop.total());
  $return.balance = ledger.balance();
end _lmcode_
r = run_lmcode(program, {command:[ARGV[0], "--lmcode", "$DSLFILE"]});
require(r.ok, "sample host execution failed");
