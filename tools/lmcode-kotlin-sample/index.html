lmcode-kotlin-sample

lmcode-kotlin-sample is the idiomatic Kotlin reference Shop and Ledger host built on the vendored lmcode-java SDK and passing the canonical sample suite. It demonstrates Kotlin SAM lambda bindings, byte-exact VmString handling, R49 @item and @total rule entry dispatch, and LMCODE_RETURN framing.

Quick reference

git clone https://github.com/lmctl-ai/lmcode-kotlin-sample.git
cd lmcode-kotlin-sample
python3 scripts/sync.py check
mvn package -DskipTests
./test.sh
