azuresim

azuresim is a single-binary local Azure emulator on 127.0.0.1:4577 that runs Blob and Queue Storage in-process without Docker, Java, or an Azure account.

Quick reference

Start azuresim on loopback port 4577 in open mode or with SharedKey and Bearer token enforcement, then connect lmazure, Azure SDKs, or curl.

azuresim --version
azuresim serve
azuresim serve --port 4577 --data-dir ./data
azuresim serve --auth enforce --auth-config auth.json
curl -f -X PUT "http://127.0.0.1:4577/devstoreaccount1/demo?restype=container"
Command or endpoint Default Purpose
azuresim serve | start 127.0.0.1:4577, in-memory Run the foreground loopback Azure Blob and Queue Storage emulator.
--port <port> 4577 Override the loopback TCP listening port.
--data-dir <path> in-memory Persist containers, blobs, and queues across restarts.
--auth open | enforce open (AZURESIM_AUTH) Run in permissive open mode or enforce SharedKey/Bearer authentication and storage policies.
--auth-config <file> AZURESIM_AUTH_CONFIG JSON file defining accounts, SharedKeys, Bearer tokens, and allow/deny storage rules.
/devstoreaccount1 & /devstoreaccount1-queue account devstoreaccount1 Base URL paths for Azure Blob Storage and Azure Queue Storage requests.

Runnable LMScript example driving azuresim on 127.0.0.1:4577 through lmazure and the shared lmcloud schema:

p = _lmcode_ cli="lmazure" install="github:lmctl-ai/lmazure@latest";
  @"/azuresim/:container/:blob"
  fn get_blob(x: RestExchange) -> void implements RestGet {
    x.send(cloud.object_get(x.param("container"), x.param("blob")));
  }

  cloud.set_endpoint("all", "http://127.0.0.1:4577");
  cloud.bucket_create("demo-c");
  cloud.object_put("demo-c", "hello.txt", "hello from azuresim");
  cloud.queue_create("demo-q");
  cloud.queue_send("demo-q", "msg-1");

  rest_config("prefix", "/v1");
  let out = rest_cli(str_split("/v1/azuresim/demo-c/hello.txt", " "));
  print(out);
end _lmcode_
r = run_lmcode(p);
assert(r.ok, "azuresim client run failed");
