lmmol

lmmol documents and specifies lmmol.com, a cross-referenced biomedical knowledge graph of proteins, clinical trials, diseases, genes, and Gene Ontology terms.

Quick reference

Query the no-auth JSON browse layer directly over HTTPS with curl or any HTTP client, or bootstrap an LLM agent from llms.txt.

curl -s https://lmmol.com/llms.txt
curl -s https://lmmol.com/index.json
curl -s https://lmmol.com/nodes/protein/P38398.json
Endpoint or pathMethodDescription

https://lmmol.com/index/list/TYPE/root.jsonGETShard count and shard list for TYPE (protein, trial, disease, gene, go)
https://lmmol.com/index/list/TYPE/N.jsonGETShard N containing up to 1000 id and name pairs

https://lmmol.com/index/disease/MONDO_ID.jsonGETBacklink index returning all proteins and trials linked to a Mondo disease
https://lmmol.com/index/gene/SYMBOL.jsonGETBacklink index returning all proteins linked to a gene symbol
https://lmmol.com/index/clinvar/gene/SYMBOL.jsonGETClinVar clinical significance associations from a gene to diseases
https://lmmol.com/index/clinvar/disease/MONDO_ID.jsonGETClinVar clinical significance associations from a disease to genes

Retrieve all proteins and clinical trials connected to hereditary breast carcinoma (MONDO_0016419):

curl -s https://lmmol.com/index/disease/MONDO_0016419.json | jq '{proteins: (.proteins | length), trials: (.trials | length)}'
