Files and processes

Write and read a temporary file, then run a process as an argument array without a shell.

Script: files-processes.lms

path = temp_file();
write_file(path, "first line\nsecond line\n");
lines = read_lines(path);
println(f"lines={lines.len()} last={lines[1]}");
result = system(["node", "-e", "process.stdout.write('process-ok')"]);
println(f"process={result.stdout}");
remove_file(path);

Run it

lmscript examples/files-processes.lms

Output

lines=2 last=second line
process=process-ok
