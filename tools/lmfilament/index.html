lmfilament

lmfilament is a native host for the lmscript _lmcode_ statement that embeds Google Filament 1.78.1 (material compiler, engine, geometry tools) in one static executable. It builds headless scenes on the Filament noop backend and writes preview pictures with its own CPU rasterizer; it does not produce Filament pixels.

Install and run

npm install -g @lmctl-ai/lmctl
lmctl autorun https://raw.githubusercontent.com/lmctl-ai/lmfilament/main/examples/ball-stick.lms
lmscript --check scene.lms
lmscript scene.lms

The host binary is downloaded on demand through install="github:lmctl-ai/lmfilament@latest". The facts on this page were checked against lmfilament 0.3.21 (Linux x64 and arm64, glibc 2.35 or newer).

Minimal example

mkdir("build");
prog = _lmcode_ cli="lmfilament" install="github:lmctl-ai/lmfilament@latest";
let mat = fil.material("bakedColor", "material {\n    name : BakedColor,\n    requires : [\n        color\n    ],\n    shadingModel : unlit,\n    culling : none,\n    featureLevel : 0\n}\n\nfragment {\n    void material(inout MaterialInputs material) {\n        prepareMaterial(material);\n        material.baseColor = getColor();\n    }\n}\n");
let s = fil.scene();
s.skybox(0.1, 0.125, 0.25);
s.camera(45.0, 0.0, 0.0, 3.0, 0.0, 0.0, 0.0);
let tri = fil.triangle();
s.add(tri, mat);
let frames = s.render_frames(2);
s.render_png("build/triangle.png", 800, 600);
lmcode_return_put("filament", fil.version());
lmcode_return_put("frames", frames);
lmcode_return_put("vertices", tri.vertex_count());
lmcode_return_put("renderables", s.renderable_count());
lmcode_return_put("package_bytes", mat.package_size());
end _lmcode_
r = run_lmcode(prog);
if (!r.ok) { println(r.stderr + r.stdout); }
assert(r.ok);
println(r.result);
