lmhtml

Overview

lmhtml is a native host for auditing links and CSS names, comparing HTML documents, extracting templates, and applying shared-page edits.

Install and run

Use the latest binary from Releases. For source builds, follow the setup and build steps in the README. Install Node.js 24.15 or newer for the published compiler.

lmhtml --schema
lmhtml --schema --json > lmhtml.dsl.json
lmhtml --dsl-signatures
npx --yes --package=@lmctl-ai/lmctl -- lmscript audit.lms build/audit.dslb
lmhtml --dsl build/audit.dslb [more.dslb ...]

--schema prints a compact human-readable summary; --schema --json prints the embedded compiler input byte-for-byte. --dsl-signatures prints the bound host signatures. Multiple bytecode files run in order against the same embedded schema; all files are loaded and verified before execution. Use --dry-run to report saves without writing.

Output and exit codes

Successful execution prints one JSON line: {"ok": true, "result": null}. Exit 0 is success, 2 is usage or compilation failure, 3 is bytecode load or host runtime failure, and 4 is an application-level report failure. Reports are informational unless the script calls report.fail_if_any().

Host behavior

  • html.load_dir(dir, include, exclude) filters relative paths; hidden files are included, directory symlinks are not followed, and returned paths are sorted.
  • link_kind classifies internal pages/assets, anchors, external URLs, special schemes and paths outside the root. External URLs are not fetched.
  • html.diff normalizes whitespace, comments, attribute order and data-* attributes.
  • html.write_template reports common subtrees and inserts slot markers in a sample template.
  • html.save writes atomically within the working directory; use --dry-run before a real rewrite.

Limits and troubleshooting

The CLI accepts bytecode v5 and schema v2. Only the current bytecode version is read. The VM has no execution budget or allocation caps, so run trusted bytecode. HTML saving expects valid UTF-8; unsupported legacy encodings are refused. Serialization may normalize wrappers, tag casing, quoting and optional elements. If compilation reports an unknown member, retrieve the schema JSON from the same host version and compile against it. If a save fails, check that the destination is under the working directory and inspect the host error.
