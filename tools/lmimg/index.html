lmimg

lmimg is a native lmcode host for image editing, compositing and procedural graphics from scripts: a static ImageMagick core with original GIMP-style layers, masks, curves, healing and LUTs. It is installed automatically by lmscript and reads and writes PNG, JPEG, TIFF, WebP, GIF, BMP and PNM files.

This page is the quick reference. The latest release is lmimg 0.1.4; it ships the 206-signature lmcode_std_v3 standard library next to its 72 host methods.

Install and run

npm install -g @lmctl-ai/lmctl
lmscript quick.lms            # downloads the lmimg release on first use
lmscript --check quick.lms    # compile the _lmcode_ block against the host schema
lmctl autorun https://raw.githubusercontent.com/lmctl-ai/lmimg/main/examples/animation_wave.lms

The install attribute github:lmctl-ai/lmimg@latest on the block makes lmscript download and cache the release binary. The current release has Linux x64 and arm64 binaries that need dynamic glibc 2.35 or newer; libraries, fonts and codecs are linked statically.

Minimal runnable example

mkdir("images");
prog = _lmcode_ cli="lmimg" install="github:lmctl-ai/lmimg@latest";
let original = img.pattern(440, 260, "x", "y", "0.2", "1");
let edited = original.copy().levels(0.1, 0.8, 0.9);
let panel = img.panel(original, edited, 4);
panel.save("images/comparison.png");
img.assert_close(original.ssim(original), 1.0, 0.000001);
lmcode_return_put("width", panel.width());
lmcode_return_put("height", panel.height());
end _lmcode_
r = run_lmcode(prog);
println(json_stringify(r));
require(r.ok, "comparison failed");

Saved as quick.lms and run with lmscript quick.lms, the program writes images/comparison.png and prints this line:

lmscript quick.lms
{"ok":true,"result":{"width":892,"height":268}}

Host API quick reference

The single context object is img, of type Img. Image edits mutate their receiver and return it for chaining; use copy() first when the original must survive. Coordinates are pixels and RGBA values are 0..1.

Blend and layer modes: over, multiply, screen, overlay, difference, darken, lighten, addition, subtract, divide. Colormaps: gray, heat, viridis, coolwarm.
