lmgh reference

CLI flags, Gh and Report context methods, domain object methods, and exit codes for lmgh.

CLI flags and environment

Flag or variableDescription
--versionPrint the lmgh build version and exit 0.
--lmcode-schema [--json]Print the embedded schema/lmgh.dsl.json bytes.
--lmcode-signaturesPrint sorted canonical host and standard library signatures.
--lmcode FILEExecute a compiled DSLB v6 bytecode file (repeatable for builder parts).
LMGH_GHEnvironment variable selecting a specific gh executable (requires gh >= 2.45.0, < 3.0.0).
LMCODE_INVOCATION_FILEOptional absolute path to a v1 JSON invocation manifest with boolean dry.

Exit codes

CodeMeaning
0Execution or introspection succeeded.
2CLI usage error, retired --first/--last flag, or malformed LMCODE_INVOCATION_FILE metadata.
3Bytecode load failure, schema mismatch, or gh/API runtime failure.
4Application failure (APP_FAIL), including report.fail_if_any() on non-empty findings or unreadable inputs.
