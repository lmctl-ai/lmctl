lmcode-go-sample

lmcode-go-sample is the static, CGO-free Go 1.26+ reference Shop and Ledger host embedding lmcode-go and passing the canonical sample suite. It embeds the exact schema bytes, binds 45 host signatures alongside lmcode_std_v3, dispatches R49 rule entries, and frames LMCODE_RETURN results.

Quick reference

git clone https://github.com/lmctl-ai/lmcode-go-sample.git
cd lmcode-go-sample
python3 scripts/sync-suite.py --check
CGO_ENABLED=0 go build -trimpath -o build/lmcode-go-sample .
./test.sh
