lmdraw reference

Every command-line flag, exit code, host type, method, attribute, limit and standard-library signature of lmdraw 0.2.7, taken from the release binary (lmdraw --lmcode-schema, lmdraw --lmcode-signatures) and the repository script guide. Types in signatures are int, float, string, bool and the host or standard types named here.

Command line

CommandEffect
lmdraw --versionPrints lmdraw and the version number.
lmdraw --lmcode-schema --jsonPrints the exact embedded schema JSON (dsl.schema 2, name lmdraw, functions, types, context). This is the compiler input.
lmdraw --lmcode-schemaPrints the compact summary: the context line, then each host type with its method signatures.
lmdraw --schema [--json]Earlier spelling of --lmcode-schema; prints identical output.
lmdraw --lmcode-signaturesPrints every registered signature, host and standard, one per line and sorted: 253 lines in 0.2.7 (1 context, 46 host methods, 83 standard functions, 123 standard methods).
lmdraw --lmcode FILE [FILE ...]Verifies every compiled program file against the embedded schema, then runs them in order in one process sharing one scene. Each file is at most 16 MiB.

With no arguments or an unknown flag the host prints its usage line and exits 2. Failures also print a JSON result between the lines LMCODE_RETURN_BEGIN and LMCODE_RETURN_END, which run_lmcode parses into its return value.

Exit codes

CodeMeaningObserved result codes
0Success.
2Invalid command line.CLI_USAGE (phase cli)
3Program file load or verification failed, or a host call failed while running.LOAD_BAD_BYTECODE, LOAD_UNBOUND, RUN_HOST (phases load and run)
4Another application failure.

Context and host types

NameKindRole
sceneContext object of type SceneThe one entry point of a block. All constructors and render calls are methods on it.
SceneHost typeThe retained scene: canvas, constructors, loaders, measurement and rendering.
NodeHost typeHandle to one primitive: rect, circle, ellipse, line, arrow, polyline, path, text, image or an imported SVG element.
ShapeHost typeHandle to a labeled diagram shape (box, diamond, cylinder, note, cluster) or a grid cell, with named anchors.
GridHost typeAn invisible rows-by-columns array of cell shapes.
GroupHost typeA container of nodes and groups; also returned by connectors, axes, legends and sequence notation.
GradientHost typeA linear gradient definition referenced as url(#id).

The schema declares no host free functions and no enum types. Options that behave like enums are strings; their accepted values are listed under String options.

Standard library in lmdraw 0.2.7

lmdraw 0.2.7 registers 206 standard lmcode_std_v3 signatures in addition to its 46 host methods. They are available in every block without a declaration. Strings are raw bytes with byte-based lengths and offsets. Collection and Json handles are valid only during the run that created them. The file functions use the process working directory without a sandbox. The current lmcode_std_v3 catalog has 226 signatures; the 20 that 0.2.7 does not ship are listed under REST and CLI interfaces.

REST and CLI interfaces

The current lmcode_std_v3 catalog adds the former lmcode_std_rest_v1 module: 10 standard interfaces, 5 functions and 15 RestExchange methods, for 226 signatures in total. lmdraw 0.2.7 does not register them. The lmscript 0.2.482 compiler accepts a call such as rest_stop() in an lmdraw block, but the 0.2.7 host then refuses the program at load time with code LOAD_UNBOUND and the message that the import is not provided by the host. They become usable in lmdraw blocks when a release synced to the 226-signature catalog is published; the tables below describe the catalog, not lmdraw 0.2.7.
