Still Life

Render a box, sphere, and cylinder together in one lit scene. This page includes the render and a quickrun-ready lmscript source file.

Let an agent build from this example

Copy this prompt into your Lead's terminal to ask an agent to make a related drawing:

Create a compact 3D mounting plate with two clean through-holes, a
visible bevel or rim, and a contrasting material. Render a PNG and
export an STL. Add a volume check or another concrete geometry check,
then report the source, outputs, and verification. Use the lmcad API and
the Still Life example below. Report the source, output artifacts, and
verification.
LMScript DSL: https://lmctl.com/tools/lmscript/skill.html
lmcad API: https://lmctl.com/tools/lmcad/guide.html
Box volume example: https://lmctl.com/tools/lmcad/examples/box-volume.html

Run the example

lmctl quickrun https://lmctl.com/tools/lmcad/examples/still-life.lms

Read the quickrun source. See get started with quickrun teams.

Source from the project

The original example is still-life.lms at fe18cf967b. The published quickrun source adds release installation, local SVG fixtures, or the bundled font needed to run it from a new directory.

Source and releases: github.com/lmctl-ai/lmcad.
