Heatmap Grid

Uses wrapped labels in a colored grid. This page includes the render and a quickrun-ready lmscript source file.

Let an agent build from this example

Copy this prompt into your Lead's terminal to ask an agent to make a related drawing:

Create a drawing inspired by the Heatmap Grid example. Use the lmdraw
API and source links below, compile and render a PNG, and report the
source and verification.
LMScript DSL: https://lmctl.com/tools/lmscript/skill.html
lmdraw API: https://lmctl.com/tools/lmdraw/guide.html
Example book: https://lmctl.com/tools/lmdraw/examples/heatmap-grid.html

Run the example

lmctl quickrun https://lmctl.com/tools/lmdraw/examples/heatmap-grid.lms

Read the quickrun source. See get started with quickrun teams.

Source from the project

The original example is heatmap-grid.lms at main. The published quickrun source adds release installation, local SVG fixtures, or the bundled font needed to run it from a new directory.

Source and releases: github.com/lmctl-ai/lmdraw.
