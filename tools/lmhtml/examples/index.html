lmhtml examples

lmhtml audits HTML links and CSS names, compares page structure, extracts shared templates, and applies verified edits. Browse example results and run each source as an autorun script. These pages are regenerated from the public lmhtml repository at 186d5108b8.

Start with get started to learn how solo and trio quickruns work.

  • Check Links: Classify links and report broken local destinations in a synthetic site. Quickrun source
  • Class Typos: Find undefined and unused CSS classes and IDs across a site. Quickrun source
  • Diff Pages: Compare two pages and report structural changes while ignoring formatting noise. Quickrun source
  • Make Template: Extract a reusable template from markup shared by five pages. Quickrun source
  • Rewrite Nav: Replace shared navigation and footer markup, then verify convergence. Quickrun source
