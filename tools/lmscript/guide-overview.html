lmscript

Overview

lmscript is a small, dynamically typed scripting language and command-line runner for automation: reading and writing files, transforming CSV/JSON/TOML data, running other programs without a shell, and driving lmctl agent workflows. Every script is statically checked and, by default, dry-run before it runs for real, so typos and most mistakes stop the script before it touches anything.

It is not a general-purpose application language: there are no classes, closures or packages from a registry, and scripts run with your full local permissions (no sandbox).

Install

lmscript is part of the @lmctl-ai/lmctl npm package (which also installs lmctl). It needs Node.js 24.15 or later on Linux, macOS or Windows.

npm install -g @lmctl-ai/lmctl

lmscript --version
lmscript 0.2.348

A first look

names = ["Ada", "Grace"];
for (n in names) {
  println(f"Hello, {n}!");
}
