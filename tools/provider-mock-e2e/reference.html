Harness scripts

Script Arguments Description
scripts/prepare.py none (environment: LMSCRIPT_JS required, MOCK_ROOT optional) Download the pinned lmmock release into MOCK_ROOT, write settings.json there, verify lmmock release checksum and compile the no-forced-tool smoke fixture and stock wire handler.
scripts/run.py <provider> --settings <file> --out <dir> Query lminstall status <provider> --json for the installed binary and invoke scripts/probe.py.
scripts/probe.py <provider> --binary <path> --settings <file> --out <dir> Start lmmock exec, run the isolated probe against the LMMOCK_URL it provides, check PROVIDER_MOCK_OK_129 and negative control, and write JSON results.
scripts/wire.py <settings.json> <out dir> Wire-shape probes against the stock llm-api handler.
scripts/cleanup-hermes.py <hermes_home_dir> Verify fingerprint and reap the per-HOME detached Hermes gateway process.

Exit codes

Code Meaning
0 Provider exited 0, returned exact PROVIDER_MOCK_OK_129, passed request audit, and negative control fired properly.
1 Non-zero provider exit, wrong reply text, non-loopback LMMOCK_URL, missing lminstall binary, or failed audit (uncaught Python exception).
2 argparse usage error in scripts/run.py or scripts/probe.py (missing provider, --settings, or --out).
