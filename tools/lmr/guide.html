lmr API guide

Overview

lmr is a native LMScript host that implements a fixed catalog of statistical operations. The C++17 runtime does not require an R installation. Its public schema and operation signatures are embedded in each release binary.

Check the host

lmr --version
lmr --dsl-schema
lmr --dsl-schema --json
lmr --dsl-signatures
lmr --dsl FILE.dslb

Use cli="lmr" to compile against the embedded schema and install="github:lmctl-ai/lmr@v0.5.1" to fetch the v0.5.1 release binary when lmr is not on PATH. The v0.5.1 host schema contains lmr-specific functions; the standard StrList methods come from the LMScript standard library.

Results and errors

The DSL exposes typed result objects. Use out.set to include selected values in the single stdout JSON result, alongside check and failure counts. Non-finite numeric values serialize as JSON null. out.print writes to stderr. Load and execution errors produce a JSON error with a phase, code, and message.

In the native host, process exit codes are 0 for success, 2 for usage errors, 3 for bytecode loading or execution errors, and 4 for failed application checks.

Limits

Limits depend on the native operation; the old R-backed API limits do not describe this host. Keep examples small and check operation-specific errors when increasing input sizes. Read the operation descriptions in the lmr API source for additional limits and supported options.
