lmcurl reference

Complete command-line flag reference, LDAPv3 CLI subcommands, host schema contexts and methods, standard lmcode_std_v3 REST and CLI interfaces, and exit codes for lmcurl v0.1.4.

Host and CLI flags

Flag or commandArgumentsDescription
--versionnonePrint the lmcurl version string and exit 0.
--lmcode<file.dslb>Load and execute a compiled LMScript bytecode program against the embedded schema.
--lmcode-schema[--json]Print a human-readable schema summary, or exact embedded schema JSON bytes when --json is passed.
--lmcode-signaturesnonePrint all 413 canonical context, function, and method signatures (187 host + 226 standard library).
ldap://...[-u dn:pw] [-X METHOD] [-d BODY] [-i]Execute a direct curl-style LDAPv3 URL request (/ping, /bind, /whoami, /compare, /search, /entry/DN, or RFC 4516 search URL).
ldap ping[--host H] [--port P]Send an anonymous Root DSE probe and return {"ok":true,"result":"PONG"}.
ldap bind--dn DN --password PW [--host H] [--port P]Perform an explicit LDAPv3 simple bind and report bind status.
ldap whoami[--bind-dn DN] [--bind-pw PW] [--host H] [--port P]Send an RFC 4532 Who Am I? extended request (OID 1.3.6.1.4.1.4203.1.11.3) and return authzId.
ldap search--base-dn DN [--filter F] [--scope base|one|sub] [--attrs a,b]Search directory entries with filter evaluation and optional attribute projection.
ldap get<dn> [--attrs a,b] [--host H] [--port P]Fetch a single directory entry by Distinguished Name (base-scope search).
ldap add<dn> <json-attrs> [--bind-dn DN] [--bind-pw PW]Create a new directory entry from a JSON object of attribute values.
ldap modify<dn> <json-ops> [--bind-dn DN] [--bind-pw PW]Apply add, replace, or delete attribute modifications from a JSON object.
ldap compare<dn> <attr> <value> [--bind-dn DN] [--bind-pw PW]Execute an RFC 4511 CompareRequest (tag 0x6e) and return {"match":true|false}.
ldap del<dn> [--bind-dn DN] [--bind-pw PW]Delete an entry by Distinguished Name.

Exit codes

Exit codeCategoryMeaning
0SuccessCommand, LDAPv3 operation, or _lmcode_ program succeeded and all assertions passed.
1Operation errorDirect CLI HTTP or LDAPv3 network, bind, or directory operation failed.
2Usage errorInvalid command-line flag, retired flag name, or missing required CLI argument.
3Host / load errorBytecode format mismatch, schema binding failure, unhandled runtime error, or non-Linux platform stub refusal.
4Contract failureAn assertion (assert, assert_eq, Report.assert_all) or test contract failed during execution.
