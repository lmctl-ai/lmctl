deepseek-harness

deepseek-harness (dsh) is an open-source everything-is-a-plugin agent harness powered by Cordis, maintained in lmctl-ai/deepseek-harness for arm64 builds and lmctl provider integration.

Quick reference

Run DeepSeek Harness in headless prompt mode, start the local Web UI on 127.0.0.1:3080, or build from source on x64 and arm64 machines.

dsh --version
dsh --profile headless "Summarize this directory"
npx @deepseek-ai/dsh web --no-open
pnpm install && pnpm run build && pnpm dsh web
Command or variable Usage Purpose
dsh --profile headless dsh --profile headless "<prompt>" Execute a non-interactive one-shot prompt and print the plain-text answer to stdout.
dsh web npx @deepseek-ai/dsh web [--no-open] or pnpm dsh web Start the local Web UI server at http://127.0.0.1:3080.
DSH_HOME DSH_HOME=/path/to/state Isolate DeepSeek Harness configuration and session state to a private directory.
DEEPSEEK_API_KEY & DEEPSEEK_BASE_URL DEEPSEEK_BASE_URL=http://127.0.0.1:PORT/v1 Trusted environment-tier API key and endpoint override.
DSH_TELEMETRY_DISABLED DSH_TELEMETRY_DISABLED=1 Disable outbound telemetry in automated or mock E2E runs.

Runnable headless prompt example using an isolated DSH_HOME and trusted environment-tier endpoint override:

export DSH_HOME="$(mktemp -d)"
export DSH_TELEMETRY_DISABLED=1
export DEEPSEEK_API_KEY="synthetic-mock-key-129"
export DEEPSEEK_BASE_URL="http://127.0.0.1:4567/v1"
dsh --profile headless "Reply with exactly PROVIDER_MOCK_OK_129. Do not call any tools."
