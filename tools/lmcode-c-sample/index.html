lmcode-c-sample

lmcode-c-sample is the reference C11 domain library and C++17 host application demonstrating how to wrap a pure C library with lmcode-cpp. It exposes the 45-signature Shop/Ledger/Money domain alongside the lmcode_std_v3 standard catalog and passes the canonical DSLB v6 sample suite.

Quick reference

git clone https://github.com/lmctl-ai/lmcode-c-sample.git
cd lmcode-c-sample
make test-domain
./test.sh
