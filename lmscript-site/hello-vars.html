Hello and variables

Start with a variable, an argument, and an f-string.

A variable is a name that holds a value. ARGV is the list of words after the script filename, and get(0, "world") uses its first word or the fallback when no word was supplied. An f-string inserts the value inside braces into the sentence.

Script: hello-vars.lms

name = ARGV.get(0, "world");
println(f"Hello, {name}!");

Run it

lmscript examples/hello-vars.lms Ada

Output

Hello, Ada!

Try it: download examples/hello-vars.lms, save it under examples/ in a writable working directory, then run the command above from that directory.
