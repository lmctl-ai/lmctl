lmgallery reference

Reference tables for lmgallery CLI workflows, test flags, manifest schemas, host output conventions, featured host catalog, and exit codes.

Test and maintenance commands

CommandFlagsDescription
./test.sh(none)Validate PNG/GIF headers, CRCs, decoded dimensions, preview size budgets, SHA-256 attribution, cross-host bindings, autorun captions, and local links
./test.sh--networkAlso verify published HTTP links and raw GitHub URLs
./test.sh--runExecute all 50 local composition scripts in fresh temporary directories
./test.sh--urlsExecute all 50 public raw GitHub URLs with lmctl in fresh temporary directories
./examples/render-all.sh(none)Run all 50 compositions in temporary directories and copy outputs to docs/images/
./examples/render-all.sh--only NNRegenerate a single showcase preview by its two-digit number (01 to 50)
python3 scripts/build-readme.py(none)Regenerate README.md, examples/README.md, and docs/ATTRIBUTION.md from catalog.json and showcases.json

Exit codes

CodeSourceMeaning
0test.sh / lmctl / native hostsAll checks or composition blocks succeeded
Nonzerotest.sh / scriptsIntegrity check, link verification, or composition test failed
2test.sh / native lmcode hostUnknown test.sh flag (usage message), or host CLI usage error or metadata flag query
3Native lmcode hostBytecode load error, runtime exception, or memory budget exceeded
4Native lmcode hostApplication assertion or output verification failure
