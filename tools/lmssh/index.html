lmssh

lmssh is a static executable bundling OpenSSH 10.6p1 (ssh, sftp, scp, ssh-keygen) with an embedded LMScript bytecode VM for remote fleet automation and key management. It supports direct OpenSSH CLI invocation, parallel host fan-out, SFTP transfers, SSH CA signing, and standard lmcode_std_v3 REST and CLI interfaces.

npm install -g @lmctl-ai/lmctl@latest
lmssh --version
lmssh ssh -V
lmssh --lmcode-schema
