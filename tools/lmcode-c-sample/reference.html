lmcode-c-sample reference

Reference tables for the lmcode-c-sample (C11 + C++17) type conversions, 45 Shop/Ledger domain signatures, CLI protocol flags, and exit codes.

Host language type conversions

lmcode typeHost representationBoundary rule
intint64_tWrap via unsigned uint64_t arithmetic in C11; never narrow to 32-bit C int
floatdoublePreserve IEEE-754 binary64 values; money(double) rejects non-finite or out-of-range prices
boolint (0 / 1) <-> boolConvert C int 0/1 to dslvm::Value::boolean at the C++ binding layer
stringconst char* + size_tExplicit byte length preserving interior NUL and invalid UTF-8 bytes
Money / Shop / LedgerC struct pointersOwned by sample_domain arena until sample_domain_destroy after body and rule entries finish
voidValue::none()Void C functions return dslvm::Value::none() rather than a null handle
