Node object schema

FieldTypeDescription
idstringStable entity identifier (UniProt accession, NCT ID, MONDO_ID, gene symbol, or GO ID)
typestringEntity type: protein, trial, disease, gene, or go
namestringPrimary human-readable name or study title
search_textstringConcatenated descriptive text indexed for semantic vector search
synonymsarray of stringAlternative names, aliases, or gene symbols
native_xrefsarray of objectCross-references from the upstream source record
outbound_source_linksarray of stringDirect HTTPS URLs to the authoritative upstream database records
attributesobjectType-specific key-value properties such as organism, phase, overall_status, or last_update_year
normalizedbooleanTrue when a disease node resolves to a canonical MONDO_* identifier
edgesarray of objectForward directional links with relation, source ({type, id}), and target ({type, id})
