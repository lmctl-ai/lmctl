Automate repeatable AI work

Turn a repeatable request into an LMScript workflow with team calls, acceptance checks and review steps.

Video description: A brainstorm becomes a script, then a labeled pipeline runs through Work, Review, QA and Acceptance. A green check marks the completed workflow.

The idea

LMScript lets an agent or developer turn a request into a workflow that can call provider sessions or team members, apply acceptance checks and route an independent review. This makes repeatable work executable and inspectable while leaving the goal and acceptance judgment with people.

What ships today

Use lmctl script --check to inspect a script, then lmctl script to run it. Scripts can perform local actions with the permissions of the current user, so review them and run only code you trust.
