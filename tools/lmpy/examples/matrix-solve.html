Matrix Solve

Solve a small linear system and check its known solution. This page includes a preview and an autorun-ready lmscript source file.

Let an agent build from this example

Copy this prompt into your Lead's terminal to ask an agent to complete a related task:

Fit a straight line to a small deterministic dataset with lmpy. Check
the coefficients against their known values and report the source and
verified output. Use the lmpy API and the Matrix Solve example below.
Report the source, output, and verification.
LMScript DSL: https://lmctl.com/tools/lmscript/skill.html
lmpy API: https://lmctl.com/tools/lmpy/guide.html
Matrix Solve example:
https://lmctl.com/tools/lmpy/examples/matrix-solve.html

Run the example

lmctl autorun https://lmctl.com/tools/lmpy/examples/matrix-solve.lms

Read the autorun source. Also see Normal quantile example. See get started with provider runs.
