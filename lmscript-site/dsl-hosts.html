Typed host blocks

Compile native host calls with install declarations for lmdraw, lmcad, and lmhtml.

A host is a separate program that provides extra operations. Its schema describes the calls and types that lmscript can check. A host block is compiled to bytecode, a file of instructions for that host. The install declaration tells lmscript where to get a missing host release; it does not install a general-purpose command on PATH.

The declarations select release binaries and obtain their schemas. The first compile needs an internet connection to fetch an uncached release; later compiles can use the local cache. During script execution, savedsl writes the compiled bytecode in the working directory. The example then runs each bytecode file with the exact host binary used to check that block, and writes any generated assets under build/rendered.

Script: dsl-hosts.lms

if (!file_exists("build")) { mkdir("build"); }
if (!file_exists("build/rendered")) { mkdir("build/rendered"); }
draw = _dsl_ cli="lmdraw" install="github:lmctl-ai/lmdraw@latest";
scene.canvas(480, 270, "#152438");
scene.text(32.0, 76.0, 32.0, "Hello from lmscript", "#f5c16c");
scene.render_png("build/rendered/hello.png", 480, 270, 1);
end _dsl_
savedsl(draw, path_join(Directory, "hello.dslb"));
draw_run = system ${dsl_cli(draw)} --dsl ${path_join(Directory, "hello.dslb")};
require(draw_run.code == 0, draw_run.stderr);

cad = _dsl_ cli="lmcad" install="github:lmctl-ai/lmcad@latest";
let mat = material();
let block = scene.box(2.0, 2.0, 2.0, mat);
scene.fit_camera(1.2, 1.0);
scene.render_png("build/rendered/block.png", 320, 240);
end _dsl_
savedsl(cad, path_join(Directory, "block.dslb"));
cad_run = system ${dsl_cli(cad)} --dsl ${path_join(Directory, "block.dslb")};
require(cad_run.code == 0, cad_run.stderr);

html = _dsl_ cli="lmhtml" install="github:lmctl-ai/lmhtml@latest";
let doc = html.parse("<!doctype html><title>Example</title><p>Checked</p>");
report.add("example.html", doc.source(), 0, "tutorial example");
end _dsl_
savedsl(html, path_join(Directory, "audit.dslb"));
html_run = system ${dsl_cli(html)} --dsl ${path_join(Directory, "audit.dslb")};
require(html_run.code == 0, html_run.stderr);
println("compiled and ran lmdraw, lmcad and lmhtml");

Run it

lmscript examples/dsl-hosts.lms

The command above compiles and runs all three host blocks. lmdraw writes build/rendered/hello.png, lmcad writes build/rendered/block.png, and lmhtml processes its report entry. lmscript uses the installed host path associated with each compiled block, so you do not need to put downloaded hosts on PATH.
