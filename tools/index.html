Tools

Small command-line tools from lmctl. Each tool has an overview page, a tutorial, a user guide and a skill page written for an LLM that has to use the tool.

  • lmcad — headless CAD, rendering and animation.
  • cpp-dsl-sdk — embed the C++ bytecode runtime in a native host.

Pages are plain HTML. Source: github.com/lmctl-ai/lmctl/tools.
