lmvalkey

lmvalkey is a single-executable Valkey key-value server combining the native RESP protocol engine, an integrated HTTP REST API, and an embedded LMScript bytecode host. It serves unified in-memory data over RESP and JSON REST endpoints while running pipelined _lmcode_ batches and standard lmcode_std_v3 routes.

Quick reference

npm install -g @lmctl-ai/lmctl@latest
lmvalkey --version
lmvalkey --lmcode-schema --json
lmvalkey --lmcode-signatures

assert_eq(valkey.set("user:100", "Alice"), true);
assert_eq(valkey.get("user:100"), "Alice");

let b = valkey.batch();
b.set("item:1", "Apples").set("item:2", "Oranges").get("item:1").get("item:2");
assert_eq(b.exec(), "[\"OK\",\"OK\",\"Apples\",\"Oranges\"]");
