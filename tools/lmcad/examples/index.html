lmcad examples

lmcad is a native solid-modeling host for lmscript with rendering and CAD export. Browse rendered examples and run each source as a quickrun script. These pages are regenerated from the public lmcad repository at aa17ebac6f.

Start with get started to learn how solo and trio quickruns work.

  • Box Volume: Build one box, assert its volume, and render a 320 × 240 PNG. Quickrun source
