lmok reference

CLI verbs, flags, Ts/Tree/Node host schema methods, SAM interfaces, standard REST and CLI interfaces, and exit codes for lmok.

CLI subcommands and flags

Verb or flagDescription
parse [--lang L] FILE|-Print the concrete syntax tree as a single-line S-expression.
query [--lang L] [--pattern] Q FILE...Run a tree-sitter S-expression query or code-shaped --pattern and print 0-based capture ranges.
lint PACK.json FILE|DIR... [OPTIONS]Run a JSON rule pack (--db, --new-since, --baseline, --changed[=REV], --fail-on-new, --sarif, --no-suppress).
check [--lang L] RULES.dslb FILE|DIR...Validate @NODE_KIND annotations against grammar L and dispatch compiled Rule callbacks over files.
ci [--config FILE] [--sarif FILE] [ROOT]Run project rules from .lmok/config.json and exit 1 if findings meet severity_floor.
rules PACK.json... / test PACK.json FIXTURE...List pack rule metadata as JSONL or verify annotated rule test fixtures.
facts [--lang L] FILE|DIR...Extract definitions, references, and edges as JSONL without a database.
index FILE|DIR... [--db PATH]Index file facts and FTS5 trigram source text into SQLite, skipping unchanged files.
symbols PAT / refs NAME / find PAT [--fts]Query stored SQLite symbols (LIKE), references (exact), or source text (literal or FTS5).
findings [--rule ID] [--file P] / status [--init]Read live recorded findings or inspect/initialize the SQLite database status.
outline FILE|DIR... [--budget N] [--db PATH]Print live symbol definitions, optionally ranked by stored reference counts.
metrics FILE... / dup [--tokens N] FILE...Report lines, functions, and max_nesting, or detect duplicate normalized token windows.
serve [--preset NAME] / remote ...Run the caching local REST API server or dispatch commands to LMOK_SERVER.
--lmcode FILE / --lmcode-schema [--json] / --lmcode-signaturesExecute compiled DSLB v6 bytecode or inspect the host schema and signatures.

SAM interfaces and standard REST/CLI interfaces (lmcode_std_v3)

InterfaceAnnotationSignatureRole
Rule@NODE_KIND(n: Node) -> voidCST node visitor dispatched by lmok check for every matching node kind.
RestGet..RestOptions, RestHandler@"/path/:param"(exchange: RestExchange) -> voidStandard lmcode_std_v3 HTTP route handler interfaces (current main; check --lmcode-signatures on a released host).
CliCommand, CliOption@"cmd" / @"--opt"(exchange: RestExchange) -> voidStandard lmcode_std_v3 stateless CLI handler interfaces for rest_cli.

Exit codes

CodeMeaning
0Execution succeeded (lint findings do not fail the run unless --fail-on-new is passed).
1Project quality gate failed in lmok ci (findings met or exceeded severity_floor).
2CLI usage error, unknown --lang, rule-pack format error, or missing SQLite DB on a read verb.
3Input or lmcode error: unreadable file, invalid query pattern, unreadable or corrupt DB, or LOAD_UNBOUND rule kind in check.
4Stdout write failure or new findings detected under lint --fail-on-new.
