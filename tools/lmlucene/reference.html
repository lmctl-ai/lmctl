lmlucene reference

CLI options, host functions, Lucene domain types, SAM callback interfaces, standard REST and CLI interfaces, and exit codes for lmlucene.

CLI flags and subcommands

Command or flagDescription
lmlucene --versionPrint the lmlucene version string and exit 0.
lmlucene --schema / --cli-schemaPrint the cli.schema.v1 JSON contract describing the run operation.
lmlucene --lmcode-schema [--json]Print the embedded lmcode/lucene.dsl.json schema summary or exact JSON bytes.
lmlucene --lmcode-signaturesPrint sorted canonical signatures for all domain and standard catalog bindings.
lmlucene --lmcode FILE.dslbExecute a compiled DSLB v6 bytecode program and emit the JSON return envelope.
lmlucene run --program FILE.dslb [--dryrun] [--readonly]Run or dry-validate a compiled bytecode program (--readonly refuses execution because bytecode may write).
lmlucene run --input-json JSON / --input-file FILESupply the run operation parameters as a JSON object or JSON file.

SAM callback interfaces and standard REST/CLI interfaces

InterfaceSignatureRole
TokenTransform(token: string) -> stringSAM interface wired via rule_analyzer(entry_name) to transform tokens during analysis.
FieldWeight(stats: CollectionStats) -> floatSAM interface wired via searcher.similarity_rule(entry_name) to scale BM25 field scoring.
RestGet..RestOptions, RestHandler(exchange: RestExchange) -> voidStandard lmcode_std_v3 HTTP route handler interfaces supporting :param and {param} (current main; the v0.1.19 release predates them).
CliCommand, CliOption(exchange: RestExchange) -> voidStandard lmcode_std_v3 stateless CLI handler interfaces dispatched by rest_cli.

Exit codes

CodeMeaning
0Execution, dry-run validation, or schema introspection succeeded.
2CLI argument usage error or LMScript compilation error.
3Bytecode load error, schema mismatch, runtime Lucene/callback failure, or --readonly policy refusal.
