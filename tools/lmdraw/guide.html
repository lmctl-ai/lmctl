lmdraw API and SVG guide

How lmdraw works and how to think about a scene: the pipeline from script to PNG, the retained scene model, attributes, diagram building blocks, text, SVG input, frames and limits. This guide describes lmdraw 0.2.7.

Overview

lmdraw is a native host for retained 2D scenes. An lmscript file computes the content in plain lmscript, and an _lmcode_ block bound to lmdraw creates vector and text nodes, loads a restricted SVG subset, updates SVG-style attributes and writes PNG files. The host is a single self-contained executable with the rasterizer and the Noto Sans and Noto Sans Math fonts compiled in; on Linux only the system glibc is linked dynamically.

Coordinates use CSS pixels with the origin at the upper left, x increasing right and y increasing down. Numeric coordinates must be finite and within plus or minus 1,000,000 pixels. Text y coordinates are baselines. A scene starts with scene.canvas(width, height, background) or scene.load_svg(path, id).

From script to PNG

  1. The block is declared with p = _lmcode_ cli="lmdraw" install="github:lmctl-ai/lmdraw@latest"; and ends with end _lmcode_. The install declaration lets lmscript download the release binary into its tool cache when it is missing.
  2. lmscript asks the host for its schema (lmdraw --lmcode-schema --json) and type-checks the block against it. Every method name, overload and argument type is checked before anything runs.
  3. r = run_lmcode(p) writes a private compiled program file and runs the host on it (lmdraw --lmcode FILE). The host verifies the program against its embedded schema before executing.
  4. The host keeps a retained scene of nodes while the block runs, writes each PNG atomically, and returns a result envelope. run_lmcode hands it back as a map: ok and result on success, or ok false with phase, code, message, line and column.
mkdir("images");
p = _lmcode_ cli="lmdraw" install="github:lmctl-ai/lmdraw@latest";
scene.canvas(640, 360, "#152438");
let card = scene.rect(36.0, 36.0, 568.0, 288.0, "#1f344b");
card.set_attr("stroke", "#6fbdb4");
card.set_attr("stroke-width", "2");
scene.text(72.0, 148.0, 38.0, "A retained scene", "#f5f8fb");
scene.render_png("images/card.png", 640, 360, 2);
end _lmcode_
r = run_lmcode(p);
require(r.ok, json_stringify(r));

Several blocks can run in one host process and share one scene: create a builder with lmcode_build(["lmdraw", "--lmcode"]), add each block with b.add(p, ["$DSLFILE"]), and call run_lmcode(b). This builder form resolves the command name lmdraw on PATH, so the executable must be on PATH; the result then carries one entry per block and a parts count. A block may define typed functions, for example fn mark(x: float, y: float) -> void, and may be created inside an outer lmscript function.

Retained nodes and attributes

Constructors return Node, Shape, Group or Gradient handles. set_attr(name, value) updates a node using SVG attribute names, and the host validates geometry values and the string-valued attributes below. Group.add attaches a node or group. A node or group may have only one parent, and group cycles are rejected. Group.set_attr accepts the same presentation attributes as Node.set_attr.

A node is a retained handle and can be updated between renders. A canvas call or a load of a different SVG starts a new scene generation; handles from an earlier generation produce an error if reused.

Diagram building blocks

Flowcharts, sequence diagrams, state machines and other hand-positioned diagrams use labeled shapes and connectors. All layout stays explicit: the host never routes or fits anything the script did not ask for.

scene.box draws a rounded rectangle with a centered, measured, wrapped label; an empty label draws none. One overload centers the box at float coordinates, the other centers it on a named anchor of another shape such as a grid cell. scene.diamond is a labeled decision diamond. scene.cylinder is a labeled datastore whose height must exceed 20 pixels. scene.note is a folded-corner annotation with a top-left label. scene.cluster is a labeled group box drawn behind its children, which keep their explicit positions. Shapes carry a 2 pixel stroke unless the stroke is none. Shape.set_attr styles the shape body but not the label text; Shape.cx and Shape.cy return the center.

Each shape exposes the named anchors n, s, e, w, ne, nw, se, sw and c. scene.connector draws an edge between two anchors, between raw coordinates, or between a point and an anchor. Routing is straight, elbow (one deterministic mid-run bend, vertical first for tall runs and horizontal first for wide runs) or curve (a cubic S-curve along the dominant axis). The start and end markers accept none, arrow, dot or diamond; dash is none or a dash list such as 6 5. A nonempty label is drawn at 13 pixels in the edge color at label position 0 to 1 along the path, plus a pixel offset.

scene.grid covers an extent with an invisible array of cell shapes separated by gaps; grid.cell(col, row) returns a cell whose anchors position boxes and connectors. Cells render nothing until given a fill or stroke. scene.lifeline, scene.message, scene.activation and scene.self_message draw sequence-diagram notation: a dashed vertical lifeline, an arrowed solid or dashed message with a centered label, an activation bar and a 60 pixel self-loop.

let slots = scene.grid(60.0, 60.0, 480.0, 240.0, 2, 3, 20.0, 20.0);
let order = scene.box(slots.cell(0, 0), "c", 120.0, 44.0, "order", "#1e3247", "#4a6a88", 8.0, 14.0);
let gate = scene.diamond(300.0, 120.0, 130.0, 70.0, "in stock?", "#1e3247", "#f5c16c", 13.0);
scene.connector(order, "e", gate, "w", "straight", "none", "arrow", "none", "#8fb4d9", 2.0, "", 0.5, 0.0, 0.0);

Axes and legends

scene.axes creates a group with horizontal and vertical axes, evenly spaced tick marks and numeric labels for both ranges. scene.log_axes draws logarithmic axes with major decade ticks and minor ticks at 2 to 9 times each decade: the 10-argument overload uses a logarithmic x axis and a linear y axis, and the 12-argument overload selects log x and log y independently. scene.legend draws a rounded legend box, or none for the background, with colored line swatches and measured labels from 1 to 16 newline-separated labels and matching comma or space separated colors. These are lightweight plot helpers; curve sampling and fitting are done in the script.

Text and gradients

Noto Sans Regular and Bold and Noto Sans Math Regular are embedded; the math face is a per-glyph fallback for arrows, relations and common mathematical symbols. Text is UTF-8 and covers Latin, Greek and Cyrillic; complex-script shaping and bidirectional layout are not implemented. scene.measure_text(text, size, bold) returns a width in pixels. Text may contain newlines, each line stepping the baseline by 1.2 em, and the six-argument scene.text overload wraps at word boundaries to a pixel width, up to 256 lines. Custom TrueType fonts can be loaded from assets/fonts/ with scene.load_font.

scene.linear_gradient creates a linear gradient, then Gradient.stop adds at least two color stops with offsets from 0 to 1. Script-created gradient coordinates are fractions of the painted object's bounds from 0 to 1. Assign a gradient with a local url(#id) fill or stroke.

let gradient = scene.linear_gradient("warm", 0.0, 0.0, 1.0, 1.0);
gradient.stop(0.0, "#f5c16c");
gradient.stop(1.0, "#6fbdb4");
let panel = scene.rect(24.0, 24.0, 240.0, 120.0, "url(#warm)");

SVG input subset

SVG input files must be direct children of assets/, no larger than 2 MiB, with valid intrinsic dimensions. Loading a document returns the requested id as a retained handle; another call for the same document returns another id without replacing the scene, and loading a different path starts a new scene.

SVG elementsMapped scene content

rect, circle, ellipse, lineMatching geometry node.

The host refuses CSS classes and stylesheets, script and event handlers, DTDs and entities, SMIL animation, foreignObject, filters, and external URLs or files. Only same-document fragment references are accepted. Renderer support for uncommon SVG forms can vary; inspect imported output. Embedded data images are not accepted from SVG input; use scene.image with a PNG data URI.

Frames and animation

Use loops inside the block to update retained attributes and write numbered PNG files. The block language has range, float, str, sin, cos, sqrt, pow, floor, lerp and ease. Convert numeric values to strings before passing them to set_attr. Updating stroke-dashoffset between renders gives a draw-on effect without rebuilding geometry. A fixed ffmpeg frame rate, codec and pixel format make the video encoding repeatable within the same toolchain.

for (i in range(0, 24)) {
  let t = float(i) / 23.0;
  marker.set_attr("cx", str(lerp(140.0, 500.0, ease(t))));
  scene.render_png("images/frame-" + str(i) + ".png", 640, 360, 1);
}

Passing values into a block

${expr} inserts an outer lmscript value as a literal. Integral numbers arrive as int (10.0 becomes 10), so pass computed coordinates as strings, as path or points data, or compute them inside the block. Lists cannot cross into a block; index them outside. Plain lmscript has sqrt and pow but no trigonometric or logarithm functions, so the repository examples carry short series helpers for the outer computations.

Limits and errors

  • At most 10,000 nodes and 1,024 gradients, with at most 128 stops per gradient.
  • SVG input is at most 2 MiB; custom font input is a TrueType file directly under assets/fonts/ and at most 8 MiB.
  • A scene image node is an embedded PNG data URI of at most 1.5 MiB, no larger than 4096 pixels per side and 8,000,000 pixels in total.
  • Program files are at most 16 MiB. Every file passed to one --lmcode call is verified before any of them runs.
  • Canvas dimensions are limited to 4,096 per side and 8,000,000 total pixels. Render scale is an integer from 1 to 4 with scaled output at most 8,000,000 pixels.
  • PNG output must be a direct child of images/ or build/rendered/. Both directories are created on demand and may not be symbolic links; subdirectories and traversal are rejected. Writes are atomic and new files follow the process umask.
  • PNG is the only output format. There is no blur, drop shadow or radial-gradient constructor.
  • Exit 2 indicates invalid arguments, exit 3 a program load, verification or host-call error, and exit 4 another application failure.

The host performs no network access and imposes no instruction budget, so run only scripts you trust. The same binary renders the same bytes on every run; different platforms may differ in the last bits of anti-aliasing. Fix host errors by using valid dimensions, supported SVG features and output paths within the allowed directories. The skill lists the common messages and fixes.
