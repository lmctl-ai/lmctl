Tools

Small command-line tools from lmctl. Each tool has a skill page for LLM agents and documentation for the tasks it supports.

  • cpp-dsl-sdk — Experimental. cpp-dsl-sdk is a C++17, standard-library-only header for loading, verifying and executing lmscript bytecode inside a host application.
  • lmcad — Experimental, latest release. lmcad runs lmscript bytecode as a headless C++ CAD host. It models solids with OpenCASCADE, renders PNG images and APNG animations
  • lmhtml guide — lmhtml is a headless host for scripted HTML inspection and rewriting. Scripts are compiled by lmscript to bytecode and run against the schema embedded in the bi
  • lmscript — lmscript is a small, dynamically typed scripting language and command-line runner for automation: reading and writing files, transforming CSV/JSON/TOML data, ru

Pages are plain HTML. Source: github.com/lmctl-ai/lmctl/tools.
