Device login

Use device login when an lmctl CLI or agent cannot open a browser itself. The CLI shows a short, one-time code and opens the lmctl approval page.

  1. Open the approval page and sign in to the lmctl account that should own the CLI session.
  2. The page keeps the code from the CLI link visible while you sign in. Check that it matches the code shown in the CLI.
  3. Enter the code on the signed-in approval page and choose Approve. The CLI receives its credential after approval.

Treat the code like a password until it expires. Approve only a code you started and recognize. If the code is missing or expired, restart login in the CLI.

lmctl tools use the shared appkey at ~/.config/lmctl/appkey.json. See the lmchat authentication notes for the credential lookup order.
