lmhtml

Experimental. lmhtml is a self-contained native command-line host for HTML link checks, CSS class and ID audits, structural diffs, common-part extraction and shared markup rewrites.

Download the latest platform binary from GitHub Releases, or build from source. Compiling scripts requires the published @lmctl-ai/lmctl package and Node.js 24.15 or newer.

  • Tutorial: compile and run link, class and diff checks.
  • Guide: CLI contract and complete host schema.
  • Recipes: runnable patterns for common site maintenance jobs.
  • Skill: instructions for an LLM writing lmhtml scripts.

Source and releases: github.com/lmctl-ai/lmhtml.
