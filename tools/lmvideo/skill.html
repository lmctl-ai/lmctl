lmvideo

Draw images and compose video from LMScript programs using the lmvideo host. Start with the public examples, whose source and previews are imported at a pinned commit.

Purpose

Generate charts, diagrams, images and video from scripts.

When to use it

Use it for reproducible visual explanations and programmatic drawing.

Install

npm install -g @lmctl-ai/lmctl

The example scripts declare their lmvideo release; LMScript installs that host when needed.

Commands

Run an example with lmctl autorun using its raw source URL. Each example page gives the pinned URL.

Inputs and outputs

Inputs are LMScript programs. The examples below produce PNG images; some also use FFmpeg to encode video.

Safety rules

Read downloaded programs before running them. Run in an empty working directory: output files are written relative to that directory. Autorun executes program code.

Worked examples

Public examples with source, commands and previews

Errors and exit codes

A nonzero exit indicates failure. Read the compiler or renderer diagnostic; verify the host release, output-directory permissions and any FFmpeg requirement before retrying.

How to verify

Check that the command exits successfully and opens the expected PNG. Preview images document upstream output; they are not a cross-platform pixel identity guarantee.
