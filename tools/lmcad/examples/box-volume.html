Box Volume

Build one box, assert its volume, and render a 320 × 240 PNG. This page includes a preview and an autorun-ready lmscript source file.

Let an agent build from this example

Copy this prompt into your Lead's terminal to ask an agent to complete a related task:

Create a compact 3D mounting plate with two clean through-holes, a
visible bevel or rim, and a contrasting material. Render a PNG and
export an STL. Add a volume check or another concrete geometry check,
then report the source, outputs, and verification. Use the lmcad API and
the Box Volume example below. Report the source, output, and
verification.
LMScript DSL: https://lmctl.com/tools/lmscript/skill.html
lmcad API: https://lmctl.com/tools/lmcad/guide.html
Box Volume example:
https://lmctl.com/tools/lmcad/examples/box-volume.html

Run the example

lmctl autorun https://lmctl.com/tools/lmcad/examples/box-volume.lms

Read the autorun source. See get started with provider runs.
