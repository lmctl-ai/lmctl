lmgallery

lmgallery is a showcase of 50 runnable LMScript compositions across 16 native hosts that compute scientific, financial, or engineering results and render visual outputs.

Quick reference

Install lmctl and run any composition directly from its public URL in an empty directory, or clone the repository to run the test suite and regenerate previews.

npm install -g @lmctl-ai/lmctl
lmctl https://raw.githubusercontent.com/lmctl-ai/lmgallery/main/examples/01-oscillator-ode-plot.lms
Command or filePurpose
lmctl URLDownload and execute a self-contained multi-host composition in the current directory
./test.shRun offline checks for image headers, CRCs, size budgets, attribution, and local links
./test.sh --networkVerify published HTTP links and raw GitHub URLs
./test.sh --runExecute all 50 local composition scripts in fresh temporary directories
./test.sh --urlsExecute all 50 public raw autorun URLs in fresh temporary directories
./examples/render-all.shRegenerate all 50 composition preview images (use --only NN for one example)
python3 scripts/build-readme.pyRebuild README.md, examples/README.md, and docs/ATTRIBUTION.md from JSON manifests

Run a two-host composition (lmspace to lmplot) from the command line:

mkdir -p /tmp/kepler-run && cd /tmp/kepler-run
lmctl https://raw.githubusercontent.com/lmctl-ai/lmgallery/main/examples/16-kepler-conservation.lms
ls -la images/
