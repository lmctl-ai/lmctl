Use lmpy from LMScript

lmpy is a native numerical host for LMScript programs. This guide explains how to install a release, run checked computations, and verify their results.

Purpose

Use lmpy for native numerical analysis from LMScript, including arrays, tables, statistics, optimisation, signal processing, graphs and machine learning.

When to use it

Choose lmpy when a task needs deterministic numerical operations available through its API and schema. Use a separate tool when the task requires capabilities outside that API.

Install

Install Node.js and the LMScript compiler. Declare the released host in the program so compilation uses the matching embedded schema.

p = _dsl_ cli="lmpy" install="github:lmctl-ai/lmpy@latest";

Commands

Run an LMScript source file with lmscript. The declaration downloads the matching lmpy release binary when needed.

lmscript normal-quantile.lms

For direct host diagnostics, run lmpy --version, lmpy --dsl-schema --json, or lmpy --dsl-signatures.

Inputs and outputs

Values are passed through the typed LMScript DSL. Host results are JSON values exposed through the program's result object; file operations use the formats and working-directory rules documented by the API.

Safety rules

Read an example's inputs and output paths before running it. Keep generated files in a temporary working directory and use out.check or out.close to validate important results.

Worked examples

The example book includes standalone release-installed scripts for a normal quantile, a least-squares fit, and a matrix solve.

Errors and exit codes

A compile error means the source does not match the installed schema or DSL syntax. A host error reports an operation failure. A failed output assertion exits unsuccessfully and names the failed check; correct the inputs or tolerance, then rerun.

How to verify

Check the host version and schema, compare canonical signatures with the compiler, run an example in a clean directory, and confirm its printed values and assertion summary.
