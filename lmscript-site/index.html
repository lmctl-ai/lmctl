lmscript

lmscript is a small scripting language and command-line interpreter for automating files, data, processes, native tools, and AI teams. A script is checked before it runs; a dry preflight previews effects before the real pass.

Start with the tutorials in order. Each chapter includes a script you can download, a command to run it, and output from the published compiler.

Reading order

  1. Hello and variables — Start with a variable, an argument, and an f-string.
  2. Control flow and functions — Use a function and a loop to compute a result; continue skips one iteration.
  3. Strings and data — Read JSON data, update a list, build a map, and format the result.
  4. Files and processes — Write and read a temporary file, then run a process as an argument array without a shell.
  5. Errors and require — Use require for a condition that must hold; a failed requirement stops the run with an error.
  6. Typed host blocks — Compile native host calls with install declarations for lmdraw, lmcad, and lmhtml.
  7. Driving teams — The default path is offline. Add --live to seed a configured Lead, prompt once, then open its terminal in interactive mode.
  8. Writing a team automation — Build a repeatable workflow from team setup, seeding, prompts, checks, and a final handoff.
  9. Starting with lmctl autorun — Declare a provider role in comments and let lmctl autorun prepare a local script before starting the session.
