lmoffice

lmoffice is a self-contained .NET 8 NativeAOT lmcode host that creates and inspects Word, Excel, and PowerPoint Open XML documents. It embeds dedicated docx, xlsx, and pptx schemas and validates generated packages with OpenXmlValidator without requiring Microsoft Office.

Quick reference

npm install -g @lmctl-ai/lmctl
lmoffice --version
lmoffice docx --lmcode-schema --json
lmoffice inspect report.docx --markdown
Route or contextKey methods or flagsPurpose
lmoffice docxdocx.create(path), heading, paragraph, table, markdown, html_doc, saveAuthor Word (.docx) documents from typed builder calls, Markdown, or html-doc@1 XHTML/CSS.
lmoffice xlsxxlsx.create(path), sheet, set, formula, number_format, bar_chart, sheet_from_csv, saveAuthor Excel (.xlsx) workbooks with 1-based cells, formulas, conditional formatting, and charts.
lmoffice pptxpptx.create(path), slide, title_slide, text, bullet, table, bar_chart, markdown, saveAuthor 16:9 PowerPoint (.pptx) presentations on a 1280x720 canvas or from slide-separated Markdown.
lmoffice inspectlmoffice inspect FILE [--markdown]Validate .docx, .xlsx, or .pptx packages with OpenXmlValidator and return JSON counts or Markdown.
