awssim

awssim is a single-binary local AWS emulator on 127.0.0.1:4566 that runs S3, DynamoDB, and SQS in-process without Java or Docker at runtime.

Quick reference

Start awssim on loopback port 4566 in open mode or with SigV4 and IAM policy enforcement, then connect lmaws or the AWS CLI.

awssim --version
awssim serve
awssim serve --port 4566 --data-dir ./state
awssim serve --auth enforce --auth-config examples/auth.json
curl http://127.0.0.1:4566/_floci/health
Command or option Default Purpose
awssim serve | start 127.0.0.1:4566, in-memory Run the foreground loopback AWS emulator for S3, DynamoDB, and SQS.
--port <port> 4566 Override the loopback TCP listening port.
--data-dir <path> in-memory Persist bucket, table, and queue state across emulator restarts.
--auth open | enforce open (SIM_AUTH) Run in permissive open mode or enforce SigV4 authentication and IAM policies.
--auth-config <file> SIM_AUTH_CONFIG JSON file declaring dummy accessKeyId, secretAccessKey, and IAM Statement policies.
GET /_floci/health anonymous Readiness probe endpoint available in both open and enforce modes.

Runnable LMScript example driving awssim on 127.0.0.1:4566 through lmaws and the shared lmcloud schema:

p = _lmcode_ cli="lmaws" install="github:lmctl-ai/lmaws@latest";
  @"/awssim/:bucket/:key"
  fn get_item(x: RestExchange) -> void implements RestGet {
    x.send(cloud.object_get(x.param("bucket"), x.param("key")));
  }

  cloud.set_endpoint("all", "http://127.0.0.1:4566");
  cloud.bucket_create("hello-awssim");
  cloud.object_put("hello-awssim", "greeting.txt", "hello from awssim");
  cloud.queue_create("awssim-jobs");
  cloud.queue_send("awssim-jobs", "job-1");

  rest_config("prefix", "/v1");
  let val = rest_cli(str_split("/v1/awssim/hello-awssim/greeting.txt", " "));
  print(val);
end _lmcode_
r = run_lmcode(p);
assert(r.ok, "awssim client run failed");
