lmcode-cpp-sample

lmcode-cpp-sample is the canonical C++17 reference Shop and Ledger host that defines the 123-case portable sample suite for all lmcode runtimes. It embeds the header-only lmcode-cpp SDK, binds 45 host signatures plus lmcode_std_v3, dispatches @item and @total rule entries, and emits LMCODE_RETURN frames.

Quick reference

git clone https://github.com/lmctl-ai/lmcode-cpp-sample.git
cd lmcode-cpp-sample
python3 scripts/sync.py check
./test.sh
