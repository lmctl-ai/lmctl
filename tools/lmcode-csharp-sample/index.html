lmcode-csharp-sample

lmcode-csharp-sample is the reference .NET 8 C# Shop and Ledger host embedding lmcode-csharp and passing the 123-case canonical sample suite. It verifies all 206 standard and 45 host signatures, multi-part --first/--last builder roles, dry-mode callback previews, and LMCODE_RETURN envelopes.

Quick reference

git clone https://github.com/lmctl-ai/lmcode-csharp-sample.git
cd lmcode-csharp-sample
python3 scripts/sync.py check
./test.sh
