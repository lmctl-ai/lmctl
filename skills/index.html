lmctl skills

Provider-agnostic guides an LLM can read to use a tool. Skills are plain HTML for humans and agents.

Utilities (LLM-facing)

  • lmchat — a shared file room for LLM agents — lmchat is an append-only shared room where each message is stored as a file.
  • lmsound — text → speech for LLM agents — lmsound converts text to audio files using AWS Polly.
  • lmprobe skill — lmprobe searches codebases and reports files, text matches, definitions, references, imports and call relationships as structured results.
  • lmmail — simple asynchronous mail for LLM agents — lmmail sends durable messages and attachments between globally named mailboxes, with commands for creating, sending, listing and reading mail.
  • lmfeedback — embeddable website feedback, delivered as lmmail mail — Use lmfeedback when a website should collect feedback from its visitors and deliver it to the site's AI owner.
  • lmnote skill — Use lmnote to keep durable named files in the authenticated lmctl user's private notebook.
  • lmsheet skill — Use lmsheet for small, durable spreadsheets in the authenticated lmctl user's private namespace. Data is stored as strings in DynamoDB.
  • lmtext — speech → text for LLM agents — lmtext transcribes audio files with AWS Transcribe, complementing the text-to-speech tool lmsound.
  • lmfin — a lightweight local finance CLI for LLM agents — lmfin is a local command-line tool for financial data, analysis and valuation using public market sources.
  • lmbio skill — Use lmbio when an agent needs deterministic local computational-biology results with machine-readable JSON.

lmctl orchestration

  • lmctl Lead skill — Administer one team, delegate concrete work, verify results, and keep project knowledge durable.
  • Claude Code lmctl Lead skill — Run an lmctl team from Claude Code using the same verified delegation and review contract as any provider.
  • opencode lmctl Lead skill — Run an lmctl team from opencode using the provider-independent command contract.
  • lmctl — Team Lead skill (basic) — Use the everyday Coder → Reviewer → Lead loop with a seeded .lmctl teamfile.
  • lmctl — Team Lead skill (advanced) — Inspect session state, preserve knowledge, and replace sessions deliberately when recovery is necessary.
  • lmscript workflow skill — This guide explains how to author parameterized lmscript workflows that users can download, configure and run with lmctl.
  • lmctl — Meta-Lead skill — Coordinate several team Leads by inspecting progress and sending concrete, self-contained tasks.
  • Skill: Team Lead workflow — Delegate, review, arbitrate disagreements, and escalate unresolved decisions.
  • Skill: Durable memory — Keep portable project decisions and operating context in committed durable-memory/ files.

New tool skills live in the tools catalog. Hosted utilities require an authorized account; deployment availability and permissions must be checked with the operator.
