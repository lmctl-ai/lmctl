Chapter 03 · Java + TeaVM

Categories become measured shapes.

A band scale maps categories to evenly spaced bars. A linear scale, nice ticks, grid lines, and a zero baseline complete this small chart primitive.

Starting the TeaVM application…

How it works

BarChart accepts ordinary Java records and renders to either backend. This chapter uses SVG; no chart-specific JavaScript library or generated SVG string is involved.

List<BarChart.Bar> bars = List.of(
    new BarChart.Bar("Mon", 34, "#61d6c5"),
    new BarChart.Bar("Tue", 52, "#ffcb6b"));
BarChart chart = new BarChart("Weekly activity", bars);
chart.render(new SvgGraphics(container, 960, 540));
