lmcad

Overview

lmcad is an experimental native CAD host that models OpenCASCADE solids, renders PNG and APNG images, and exports STL and OBJ meshes.

Download the latest release for Linux x64 or Linux arm64. Confirm the binary with lmcad --version and lmcad --lmcode-schema --json. For source builds, use the OCCT build instructions; they build OpenCASCADE 8.0.1 into a reusable prefix before configuring lmcad.
