lmweblab reference

Complete reference for lmweblab lifecycle commands, CLI flags, environment variables, lmaws Web APIs, importable recipes, 12-scenario catalog entries, and exit codes.

Lifecycle commands and CLI flags

Command or flag Context Description
all web_stack.lms / scenarios Run up, test (plus phase2 and re-test if requested), and always run down even on failure
up web_stack.lms / scenarios Provision tagged stack resources and write private state under .lmweblab-local/
test web_stack.lms / scenarios Execute lmcurl HTTP contract assertions, XSS escaping checks, and p95 load latency checks
phase2 lmaws/web_stack.lms Attach validated ACM certificate, enable redirect-to-https on CloudFront, and wait Deployed
status web_stack.lms / scenarios Read masked state and live provider inventory without acquiring the lifecycle write lock
down web_stack.lms / scenarios Tear down all run-owned resources in reverse dependency order and verify zero leftovers
--offline All drivers Use deterministic synthetic transport and loopback fixtures at $0.00 cost (default)
--live All drivers Execute against real AWS in us-east-1 using AWS_PROFILE=lmaws and LMWEBLAB_DOMAIN
--phase2 / --acm web_stack.lms / scenario 01 Enable Phase 2 ACM DNS-validated certificate and HTTPS redirection
--run-id RUN_ID All drivers Specify an explicit lowercase hexadecimal run identifier instead of generating a fresh timestamp ID

Environment variables

Variable Default Description
LMWEBLAB_LIVE 0 Set to 1 (together with --live) to authorize live AWS provisioning
LMAWS_LIVE 0 Native lmaws live mutation gate; the drivers set it to 1 for live runs and 0 otherwise
AWS_PROFILE lmaws Required least-privilege AWS profile for live runs; administrator profiles are forbidden
AWS_REGION us-east-1 Target AWS region enforced by native lmaws and OpenTofu guards
LMWEBLAB_DOMAIN example.com Public Route 53 hosted-zone domain name used for site and application DNS records
LMWEBLAB_RUN_ID auto / cafe01 Run identifier used to scope resource names (lmaws-site-<run>) and lmaws_test=<run> tags
LMWEBLAB_WORKER_LIVE_GO 0 Additional confirmation flag (set to 1) required for live execution of Scenario 07 SQS worker

Native lmaws Web stack APIs

Method signature Description
Cloud.web_stack(run_id: string, domain: string, state_path: string) -> Web Open a persistent run-scoped web stack session storing raw provider IDs in state_path
Web.step(operation: string, json_args: string) -> Row Execute a guarded provisioning step (bucket, certificate, distribution, dns_site, compute, dns_app, https, invalidate)
Web.status() -> Rows Return masked resource status and phase timings for the current run
Web.leftovers() -> Rows Query live AWS provider state for any remaining resources belonging to this run
Web.down() -> Row Tear down all owned stack resources in reverse order and assert zero remaining leftovers
Cloud.web_find(run_id: string, domain: string) -> Rows Independent read-only account inventory across S3, CloudFront, ACM, Route 53, and EC2 for run_id
settle(seconds) on a cloud.serverless_stack session Wait and sweep delayed CloudWatch log groups after Lambda teardown before final leftover audit

Importable step recipes (lmaws/recipes/steps.lms)

Function signature Description
web_bucket(opts: map, site_dir: string) -> map Create private tagged S3 bucket with Block Public Access and upload the five static site assets
web_certificate(opts: map) -> map Request ACM certificate in us-east-1, create Route 53 DNS validation CNAME, and wait for issuance
web_distribution(opts: map) -> map Create tagged CloudFront distribution and SigV4 OAC (attaching prepared certificate if present) and wait Deployed
web_site_dns(opts: map) -> map Create Route 53 alias A record pointing to the CloudFront distribution and wait INSYNC
web_compute(opts: map, settings: map) -> map Launch tagged Spot t4g.nano/t3.nano instance with 8 GiB gp3 disk, caller /32 security group, and Python user-data server
web_app_dns(opts: map) -> map Create Route 53 A record (TTL 60) for the Spot instance public IPv4 and wait INSYNC
web_https(opts: map) -> map Update CloudFront viewer protocol policy to redirect-to-https and wait Deployed
web_invalidate(opts: map) -> map Create a CloudFront cache invalidation restricted strictly to the current run distribution

Exit codes

Exit code Component Meaning
0 Drivers and hosts All lifecycle steps, HTTP assertions, teardown operations, and zero-leftover checks passed
1 lmscript driver Lifecycle step or HTTP contract assertion failed (the all driver attempts down.lms before exiting 1)
2 lmcode hosts Invalid CLI syntax or contradictory invocation metadata
3 lmcode hosts Bytecode load failure, safety/ownership/cost-cap refusal, AWS provider error, or HTTP contract failure
4 lmcode hosts Application-level failure tagged APP_FAIL
