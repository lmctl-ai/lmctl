lmplayer

lmplayer is an open-source AI coding agent for scripts, unattended workflows, single-user REST services, and terminal sessions.

Quick reference

Run prompts non-interactively from the command line, inspect models and session metrics as JSON, start the sequential REST service, or open the terminal UI.

lmplayer --version
lmplayer models --json
lmplayer providers list --json
lmplayer run --model "ollama/qwen2.5" "Summarize this directory"
lmplayer run --agent lean --model "ollama/qwen2.5+tools" "Run the test suite"
lmplayer serve --hostname 127.0.0.1 --port 4096
lmplayer session metrics "<sessionID>" --json
Command or feature Usage Purpose
Non-interactive prompt lmplayer "prompt" or lmplayer run --model ID --effort high "prompt" Execute a coding or analysis prompt directly from the CLI or stdin pipeline.
REST service lmplayer serve --hostname 127.0.0.1 --port 4096 Run a single-user HTTP agent service with a process-wide FIFO execution gate.
Background jobs & cron bash tool {background: true}, job tool, cron tool Persist background shell jobs with completion wakeups and schedule 5-field in-memory cron prompts.
Durable-memory compaction lmplayer config set compaction.mode organize Maintain session-owned durable-memory/index.md notes across context compactions.
Session observability lmplayer session ls | tail | report | health | metrics --json Inspect token usage, estimated cost, latency, tool calls, and touched files (session-metrics/v1).
Configuration & models lmplayer config get|set|unset|verify; lmplayer models verify ID Manage ~/.config/lmplayer/opencode.json settings and verify provider model resolution.

Runnable CLI and LMScript orchestration example verifying configuration, and running a headless prompt:

lmplayer config set permission_ask deny
lmplayer config set compaction.mode organize
lmplayer config verify
lmplayer run --model "ollama/qwen2.5" --format json "Reply with READY"
