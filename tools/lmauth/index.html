lmauth

lmauth is a guided, LLM-drivable authorization helper that collects operator tokens and stores them write-only in lmconn without exposing secrets to the caller.

Quick reference

lmscript install github:lmctl-ai/lmauth@v0.1.15
lmauth --version
lmauth --lmcode-schema --json
lmauth --lmcode-signatures
lmauth plan --owner lmctl-ai --repos lmoffice
ItemKindPurpose
plan --owner O --repos RCLI subcommandPrint a fine-grained GitHub token setup recipe for the target repositories.
present --owner O --repos R ...CLI subcommandCollect a token via browser or TTY, verify identity, and store write-only in lmconn.
--lmcode FILECLI flagExecute compiled lmcode bytecode with dry-manifest validation.
fn auth_plan(string, string) -> stringHost functionCreate a repository authorization recipe inside an _lmcode_ block.
fn auth_present(string) -> stringHost functionStart an operator token collection session.
fn auth_collect / auth_verify / auth_storeHost functionsCollect, verify, and store a token in lmconn, returning a nonsecret JSON receipt.
 
program = _lmcode_ cli="lmauth" install="github:lmctl-ai/lmauth@v0.1.15";
let recipe = auth_plan("lmctl-ai", "lmpdf");
let session = auth_present(recipe);
let credential = auth_collect(session);
let verification = auth_verify(credential);
$return = auth_store(credential);
end _lmcode_
