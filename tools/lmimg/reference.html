lmimg reference

Complete reference for lmimg 0.1.4. Signatures are copied from lmimg --lmcode-signatures; parameter names come from the repository README and examples. Where the public documentation does not name a parameter, only its type is shown.

CLI flags

InvocationEffect
lmimg --versionPrint the version, for example lmimg 0.1.4
lmimg --noticesPrint third-party notices: ImageMagick, zlib, libpng, libjpeg-turbo, libtiff, libwebp, stb_truetype and the embedded Roboto font
lmimg --lmcode-schema --jsonPrint the compiler schema as JSON with keys dsl.schema (2), name (lmimg), types (6), functions (0) and context (1)
lmimg --lmcode-schemaSchema output without JSON

lmimg --lmcode FILE [FILE ...]Run compiled bytecode files
--dry-runWith --lmcode: verify bytecode without running image operations

Exit codes and environment

CodeMeaning
0Success
2Usage error (failure frame with phase cli, code CLI_USAGE) or invalid LMIMG_MAX_MEMORY_MB
3Bytecode-load or execution failure with JSON on stdout and a diagnostic on stderr; also exceeding the memory budget, with one stderr line naming LMIMG_MAX_MEMORY_MB
VariableMeaning
LMIMG_MAX_MEMORY_MBTotal memory budget as a positive whole number of MiB; default 4096. The host counts C++ allocations and conservatively charges native image storage.

A host error inside a block reaches the outer script as a map with ok false, phase run, code RUN_HOST, message, line and column.
