Get started with lmcad quickruns

These LMScript files seed a provider team, ask it to create a small CAD model, and leave the Lead's final report in your terminal.

Overview

A quickrun writes a numbered teamfile in your working directory, seeds its provider sessions and runs a task that uses the released lmcad host.

Choose a team

  • lmcad_solo.lms runs one Lead using Claude Sonnet 5.5.
  • lmcad_trio.lms runs a Claude Lead, Gemini Coder and Codex Reviewer. The Lead assigns work to the Coder, passes the result to the Reviewer, then reports their findings.

Install lmctl and configure the listed providers in your local profile. Run these from a working directory where the generated teamfile and CAD files should be saved.

Run a quickrun

lmctl autorun https://lmctl.com/tools/lmcad/lmcad_solo.lms
lmctl autorun https://lmctl.com/tools/lmcad/lmcad_trio.lms

Both scripts ask the agents to render a PNG, export an STL and verify the geometry. Follow the linked lmcad skill to use the released host through the LMScript install declaration, and check the final report for outputs and unresolved findings.
