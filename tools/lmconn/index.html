lmconn

lmconn is a zero-dependency connector CLI and cli.schema.v1 module for AI-agent workflows with an AES-256-GCM encrypted SQLite credential and OAuth2 store. It exposes 56 operations across HTTP, OAuth2, LLM providers, GitHub, Valkey, LDAPv3, SAML 2.0, MCP, ACP, and npm.

Quick reference

curl -L https://github.com/lmctl-ai/lmconn/releases/latest/download/lmconn-linux-x64.tar.gz | tar xz
./lmconn-linux-x64 --version
lmconn --cli-schema --json

# Direct CLI usage
lmconn cred set deepseek api_key --env DEEPSEEK_API_KEY
lmconn http request https://api.github.com/zen
lmconn ldap search --url "ldap://127.0.0.1:3389/dc=example,dc=com?cn,mail?sub?(cn=Alice)"
lmconn valkey set session:1 '{"active":true}' --port 6379 --mode resp

# LMScript cli.schema.v1 import
import "schema/lmconn.cli.schema.v1.json";
r = lmconn.github_repos("lmctl-ai", {limit: 5});
require(r.status == "ok" && r.result.ok, json_stringify(r));
println(json_stringify(r.result));
