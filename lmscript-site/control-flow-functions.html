Control flow and functions

Use a function and a loop to compute a result; continue skips one iteration.

Script: control-flow-functions.lms

fn square(n) { return n * n; }
total = 0;
for (n in range(1, 6)) {
  if (n == 3) { continue; }
  total = total + square(n);
}
println(f"sum={total}");

Run it

lmscript examples/control-flow-functions.lms

Output

sum=46
