lmmagnum reference

Complete reference for lmmagnum 0.2.15: the context object, 7 host types, 58 host methods, 2 host functions, enumerated strings, CLI flags, exit codes and the vendored standard library. Signatures are taken verbatim from the output of lmmagnum --lmcode-signatures (267 lines: 1 context, 85 functions, 181 methods). Argument meanings are described from the usage in the repository examples; the implementation source is not public.

ExitPhaseCodeMeaning

The host prints the result frame as one JSON line between the marker lines LMCODE_RETURN_BEGIN and LMCODE_RETURN_END. run_lmcode turns it into the map it returns: ok and result on success; ok false with phase, code and message on failure.

Standard library (lmcode_std_v3)

lmmagnum 0.2.15 ships the lmcode_std_v3 catalog with 206 canonical signatures: 83 function signatures and 123 method signatures on 16 standard types. The library needs no import and is callable in any lmmagnum block next to the scene context. The result sink functions fill the result field of the run_lmcode envelope.

Standard REST and CLI interfaces (current catalog, not yet in this host)

The current lmcode_std_v3 catalog in lmcode-cpp has 226 canonical signatures. The 20 signatures beyond the 206 that lmmagnum vendors are the former lmcode_std_rest_v1 module: 5 functions and 15 RestExchange methods, together with 10 standard interfaces. lmmagnum does not ship them yet; it picks them up when it syncs its pinned lmcode-cpp SDK and publishes a release. Until then a lmmagnum program that calls rest_route or declares a RestGet handler does not compile against the lmmagnum schema.
