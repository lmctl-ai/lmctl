lmvideo

lmvideo is an lmcode host that draws plots, diagrams, processed images, CPU rendered 3D scenes, rigid body motion and video from short LMScript programs. This page is the quick reference for release v0.1.124: install, host protocol, the main objects, and one complete program.

Install and run

Install the LMScript toolchain once. A program names the lmvideo release it wants in its block header and lmscript downloads that host into its tool cache on the first real run. Video output additionally needs ffmpeg and ffprobe on PATH; still images do not.

npm install -g @lmctl-ai/lmctl@0.2.460
lmctl autorun https://raw.githubusercontent.com/lmctl-ai/lmvideo/main/examples/physics/plinko.lms

# or, with a local file
lmscript --check poster.lms
lmscript poster.lms

Release v0.1.124 has binaries for Linux x86_64 and arm64 (glibc 2.35 or newer), macOS x86_64 and arm64 (13 or newer) and Windows x86_64 (10 or newer). Read downloaded scripts before running them and run in a fresh output directory.

Minimal runnable example

Save as poster.lms and run lmscript poster.lms. It draws on an off-screen Surface, writes build/dot.png and prints the result envelope. It needs no ffmpeg.

# Still image on an off-screen Surface: no video lifecycle needed.
mkdir("build");
prog = _lmcode_ cli="lmvideo" install="github:lmctl-ai/lmvideo@v0.1.124";
let s = surface(160, 100);
let c = s.canvas();
c.clear("#1e3c72");
c.circle(80.0, 50.0, 30.0, paint().color("#ffd166"));
c.text("lmvideo", 12.0, 92.0, font(14.0), paint().color("#ffffff"));
s.png("build/dot.png");
out.print("drew " + str(s.image().width()) + "x" + str(s.image().height()));
end _lmcode_
r = run_lmcode(prog);
println(json_stringify(r));
assert(r.ok);
lmscript poster.lms
wrote build/dot.png (160x100)
{"ok":true,"result":{"output":["drew 160x100"],"file":"build/dot.png","width":160,"height":100,"frames":1,"fps":30,"bytecode_bytes":1253,"instructions":47,"wall_ms":294,"render_calls":0,"phase_ms":{"compose":41.90718,"post":0.000943,"setup":252.409468},"max_frame_ms":0,"max_render_ms":0}}

Timing fields vary between runs. For a video, configure the video object and draw inside its frame loop instead.

# A 2 second clip plus a poster frame. Needs ffmpeg on PATH.
mkdir("build");
prog = _lmcode_ cli="lmvideo" install="github:lmctl-ai/lmvideo@v0.1.124";
video.size(320, 180);
video.fps(30);
video.frames(60);
video.output("build/clip.mp4");
video.begin();
for (f in range(0, video.count())) {
  video.frame();
  let w = float(video.width());
  let h = float(video.height());
  let t = video.t();
  canvas.clear(mix("#0b132b", "#5bc0be", ease(t)));
  canvas.circle(lerp(40.0, w - 40.0, ease(t)), h * 0.5, 18.0, paint().color("#ffd166"));
  canvas.text("frame " + str(video.index() + 1) + "/" + str(video.count()), 20.0, 30.0, font(18.0), paint().color("#ffffff"));
  if (video.index() == video.count() - 1) { video.save_frame("build/clip.png"); }
}
video.end();
end _lmcode_
r = run_lmcode(prog);
if (!r.ok) { println(r.message); }
assert(r.ok);
println("wrote build/clip.mp4");

Host protocol and command line

CommandPurpose
lmscript --check FILE.lmsCompile the outer script and every _lmcode_ block against the cached host schema. Nothing is rendered. Exit 2 on a compile error.
lmscript --dry-run FILE.lmsPrint the plan. The host run is simulated and returns ok true, result null, dry true.
lmscript FILE.lmsReal run. run_lmcode compiles the block, runs it on the host and returns the envelope.
lmvideo --versionVersion line, lmvideo 0.1.124.
lmvideo --lmcode-schema --jsonHost schema JSON, byte identical to schema/lmvideo.dsl.json in the repository.
lmvideo --lmcode-signaturesAll 814 lines: 3 context objects, 164 functions, 647 methods (host plus standard library).
lmvideo --lmcode FILE.dslbRun compiled block bytecode. Normally invoked by run_lmcode, not by hand.
lmvideo demo OUT.pngWrite a built in demonstration picture.
lmvideo render IN.svg OUT.png [--width W] [--height H] [--background COLOR]Rasterize an SVG file directly.
lmvideo render-job DIR [--renderer raster|cycles] [--pass color] [--output OUT.png]Render a scene job saved by Scene3D.save_job.
lmvideo render-job-batch DIR [--renderer raster|cycles] [--pass color] [--output DIR]Render a directory of frame jobs.
lmvideo render-job --capabilitiesPrint job options and bounds as JSON.

Block resultJson, nullable
Block headerprog = _lmcode_ cli="lmvideo" install="github:lmctl-ai/lmvideo@v0.1.124"; ... end _lmcode_
Executionr = run_lmcode(prog); returns ok and result, or ok false with phase, code, message, line, column

The current lmcode_std_v3 catalog has 226 signatures, adding the standard REST and CLI interfaces (rest_config, rest_route, rest_serve, rest_stop, rest_cli, RestExchange and ten handler interfaces). lmvideo v0.1.124 does not ship them; it picks them up when a later release is built against the newer catalog. See the reference page for the verified behavior.

Main objects and functions

videocontext, Videosize, fps, frames, crf, output, then begin, frame once per iteration, end. Readers: count, index, t, time, width, height. save_frame writes the current frame as an image.
canvascontext, Canvasclear, rect, round_rect, circle, oval, line, arrow, polyline, path, text, image, svg, picture; plot and panel builders; diagram nodes (box, diamond, cylinder, note, cluster, connector, lifeline, message); save, restore, translate, scale, rotate, clip_rect; target, redraw, png.
outcontext, Outputprint adds a line to result.output; fail stops the block with code APP_FAIL.
paint(), path(), font(size)functionsFill and stroke style, vector outline, text size. Paint has color, alpha, stroke, stroke_width, stroke_cap, gradient, dash, blur.
font_load, font_catalog, fonts_usedfunctionsLoad a Typeface from a path, or from a URL pinned by a SHA-256, and report fonts. DejaVu Sans is bundled.
surface(w, h), document(w, h), pdf_document(w, h)functionsOff-screen raster Surface with png, svg and pdf export; a recording Document whose finish returns a Picture (png, svg, pdf, skp); a multi-page PDF.
canvas.plot(x, y, w, h)Plottitle, xlabel, ylabel, x_range, y_range, series(name, kind, color), heatmap, quiver, annotate, vline, hline, inset, draw.

svg(text), svg_file(path), template_svg(text)functionsParse SVG for canvas.svg; a template with a render method.
scene3d(), camera3d()functionsScene3D: add, camera, lights, shadows, environment, tonemap, render_image, render_depth_image, render_normal_image, import_gltf, import_obj, export_gltf, save_job. Camera3D: look_at, perspective, ortho, lens, dof.
mesh_box, mesh_sphere, mesh_plane, mesh_cylinder, mesh_cone, mesh_torus, mesh_lathe, mesh_extrude, mesh_text, mesh_loadfunctionsBuild a Mesh3D. scene.add(mesh, color or Material) returns a Node3D with position, rotation, scale, material, visible, keyframe.
material(color, metallic, roughness)functionPBR Material with base_color, metallic, roughness, emissive, transmission, ior, clearcoat, subsurface, texture slots. Textures come from texture_file, texture_from_image and the procedural texture_ functions.
